## 二、变量分类

### 1. 自定义变量

```bash
# 定义 —— 等号两边不能有空格
name=bgx

# 引用
echo $name
echo ${name}        # 推荐:边界清晰

# 查看
set | grep '^name'   # set 列出所有变量(含自定义+环境+函数)

# 取消
unset name
```

**命名规则**

- 字母、数字、下划线;不能以数字开头
- **不能含连字符 `-`**(原文档"横岗"是 OCR 错字,应为"连字符/横杠")
- 区分大小写;建议常量大写、临时变量小写

### 2. 系统环境变量

```bash
export PATH=/usr/local/bin:$PATH   # 自定义变量 → 环境变量
env | grep '^PATH'                  # env 只列出环境变量
```

作用域:**当前 Shell + 其派生的子 Shell**(写入 `~/.bashrc` 等启动文件可永久生效)。

### 3. 位置参数变量

```
$0   $1   $2 …   $9   ${10}   ${11} …
脚本名 第1参数 第2参数 … 双位数必须用 {}
```

### 4. 预定义变量

| 变量 | 含义 |
|------|------|
| `$0` | 当前脚本名(含路径) |
| `$#` | 位置参数的个数 |
| `$*` | 全部参数,作为一个字符串("$1 $2 …") |
| `$@` | 全部参数,**作为多个独立字符串**("$1" "$2" …) |
| `$$` | 当前进程 PID |
| `$!` | 上一个后台进程 PID |
| `$?` | 上一条命令的退出码,**0 表示成功**,非 0 表示失败 |

> `$*` 与 `$@` 不加引号时表现相同;加双引号时差异显现 —— 这一点是面试常考。

## 三、变量赋值方式

### 1. 显式赋值

```bash
ip=192.168.56.11
school="Wuhan HuQuan"
today1=`date +%F`        # 反引号(老语法)
today2=$(date +%F)       # $() 命令替换(推荐,可嵌套)
```

### 2. 弱引用 / 强引用

| 引号 | 是否解析变量 / 命令替换 |
|------|--------------------------|
| `"..."` 弱引用 | **解析**:`"$var"`、`"$(cmd)"` 都会展开 |
| `'...'` 强引用 | 一律按字面量,不展开 |
| 反引号 \`...\` 或 `$()` | 命令替换 |

```bash
school=Iphone
echo "${school} is good"   # Iphone is good
echo '${school} is good'   # ${school} is good
```

### 3. read 从键盘读入

```bash
read VAR                          # 读取一行赋给 VAR
read -p "提示:" VAR               # 带提示
read -t 5 -p "提示:" VAR          # 5 秒超时
read -n 2 VAR                     # 读够 2 个字符即返回
read -s -p "Password:" PASS       # -s 不回显(密码场景)
```

## 四、变量数值运算

Shell **只能直接处理整数**,小数运算需借助 `bc` 或 `awk`。

| 方法 | 示例 | 说明 |
|------|------|------|
| `expr` | `expr 1 + 2` | 操作符两侧必须有空格;`*` 需转义为 `\*` |
| `$(())` | `echo $((5-3*2))` | **推荐**,简洁,支持运算优先级 |
| `$[]` | `echo $[5+2]` | 等价 $(()) |
| `let` | `let sum=2+3; echo $sum` | 适合自增 `let i++` |
| `bc` | `echo "scale=2;6/4" \| bc` | 小数运算,`scale` 控制精度 |
| `awk` | `awk 'BEGIN{print 1/2}'` | 浮点运算 |

```bash
num1=10
num2=3
echo $((num1 + num2))      # 13
echo $((num1 ** num2))     # 1000   ** 是幂运算
echo "scale=4;$num1/$num2" | bc   # 3.3333
```

## 五、变量子串操作

设 `url=www.sina.com.cn`:

| 语法 | 含义 | 结果 |
|------|------|------|
| `${#url}` | 字符串长度 | 14 |
| `${url#*.}` | 从左**最短**删除匹配 | sina.com.cn |
| `${url##*.}` | 从左**最长**(贪婪)删除 | cn |
| `${url%.*}` | 从右**最短**删除 | www.sina.com |
| `${url%%.*}` | 从右**最长**(贪婪)删除 | www |
| `${url:0:5}` | 从下标 0 起取 5 个字符 | www.s |
| `${url:4}` | 从下标 4 起到末尾 | sina.com.cn |
| `${url/sina/baidu}` | 替换**首次**匹配 | www.baidu.com.cn |
| `${url//n/N}` | 替换**全部**匹配 | www.siNa.com.cN |

记忆:`#` 在键盘 `$` 左,代表"从前删";`%` 在 `$` 右,代表"从后删";单个为最短,双个为最长。

## 六、变量替代

| 语法 | 当 var 未定义 | 当 var 为空(`""`) | 当 var 有值 |
|------|---------------|--------------------|--------------|
| `${var-default}` | 用 default | **保留空值** | 用 var 值 |
| `${var:-default}` | 用 default | **用 default** | 用 var 值 |
| `${var=default}` | 用 default 并赋值 | 保留空值 | 用 var 值 |
| `${var:=default}` | 用 default 并赋值 | 用 default 并赋值 | 用 var 值 |
| `${var?msg}` | 抛错 msg | 保留空值 | 用 var 值 |
| `${var:?msg}` | 抛错 msg | 抛错 msg | 用 var 值 |

> 带冒号 `:` 的版本把"未定义"和"空字符串"视作同等情况处理。

## 七、变量自增 (易错点)

```bash
i=1
let x=i++   # 后置:先取值给 x → 再自增  → x=1, i=2
j=1
let y=++j   # 前置:先自增 → 再取值给 y → y=2, j=2

let i++     # 直接对变量自增,i 自身 +1
```

**关键点**

- 后置/前置 `++` 都会让原变量 +1;差异在表达式返回值。
- 原文档"对变量值不会产生任何影响"是错误的(指 `let x=i++` 后 i 自身确实变为 2)。

## 八、原文档错误订正

| # | 原文 | 问题 | 正确写法 |
|---|------|------|----------|
| 1 | "不能使用横岗命名" | OCR 错字 | "不能使用横杠(`-`)" |
| 2 | `echo $变量名 env\|grep Name` | 把两条独立命令拼成一行 | 分两条:`echo $VAR` 与 `env\|grep VAR` |
| 3 | `disk_free3="df -Ph \| grep ... awk ..."` | 这是字符串赋值,不会执行命令 | 应使用 `$()`:`disk_free=$(df -Ph \| grep '/$' \| awk '{print $4}')` |
| 4 | `${变量名-新值}` 释义"变量没有被赋值" | 表述不严谨 | 应明确"未定义"和"空字符串"的差别(见上表) |
| 5 | "let x=i++ 对变量值不会产生任何影响" | 错误结论 | i 自身会 +1,只是表达式的返回值是 i 自增前的值 |
| 6 | OCR 形如 `echo \(((num1+num2))\)` | 渲染错误 | 实际应为 `echo $((num1+num2))` |
| 7 | "$0 脚本文件名 $*$ ..." | 渲染错误 | `$0` 脚本名,`$*` 所有参数,`$@` 所有参数,`$#` 参数个数,`$$` 当前 PID,`$!` 后台 PID,`$?` 上条命令返回值 |
