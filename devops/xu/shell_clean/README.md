## 三、跨章节常见错误模式(原文档统计)

| 错误模式 | 出现频次 | 例子 |
|----------|----------|------|
| 方括号 `[ ]` 内缺空格 | 高 | `[-z "$x"]` ✗ → `[ -z "$x" ]` ✓ |
| `=~` 后缺空格 | 高 | `=~^[0-9]+$` ✗ → `=~ ^[0-9]+$` ✓ |
| 双引号包裹 awk 单引号 | 中 | `awk "...{print $2}..."` 中 `$2` 会被 shell 提前展开 |
| `wc -1` 与 `wc -l` | 中 | OCR 数字 1 / 字母 l 混淆 |
| 括号嵌套错配 | 中 | `$(($i+$num)]` ✗ → `$(( i + num ))` ✓ |
| `$$` 与 `$?` 混淆 | 低 | `$$` 是 PID,`$?` 才是返回值 |
| 嵌套循环复用同名变量 | 低 | 见 10 篇主机存活检测 |
| 文档表格 / 代码块语法被 OCR 破坏 | 高 | 大量 `\(((...))\)` 噪声 |
