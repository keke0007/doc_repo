# 2.Shell脚本是什么

1.系统命令的堆积

2.特定的格式 + 特定的语法 + 系统的命令 = ⽂件

3.不会⼿动搭建或者执⾏某些程序，那么⼀定学不会Shell

# 1.脚本的基本格式

```shell
shell> vim /tmp/test
#!/bin/bash
echo "Hello world" 
```

运⾏脚本

```txt
# chmod 755 /tmp/test
# /tmp/test 
```

# 2.脚本的执⾏⽅式

1.直接使⽤bash解析器执⾏脚本

```txt
# bash /tmp/test 
```

2.给脚本添加执⾏权限,然后使⽤./运⾏

```txt
# chmod 755 /tmp/test 
```

```txt
# ./tmp/test 
```

没有执⾏权限会提示权限不⾜

# 3.Shell脚本的特性

bash	shell 特性

1.命令补全和⽂件路径补全,	如果写错⽆法补全			table

2.命令历史记忆功能history

3.别名功能alias、unalias

4.常⽤快捷键ctrl+u,k,a,e,l,c,z,d,w,r,y

5.前后台作业控制bg,fg,jobs,screen

6.输⼊输出重定向	>,>>,1>,2>>,&>,cat	<

7.管道	|将前者命令的标准输出交给后者命令的输⼊	tee

8.命令排序

; 没有逻辑关系,⽆论分号前⾯的命令执⾏是否成功都执⾏后者命令

&&		前⾯执⾏成功,	则执⾏后者

||		前⾯执⾏不成功,	则执⾏后者

9.shell 通配符

*	匹配任意多个字符

?	匹配任意⼀个字符

[]	匹配括号中任意⼀个字符a-z,0-9,A-Z,a-Z

()	在⼦ shell 中执⾏(cd	/boot;ls)	(umask	077;	touch	file1000)

{}	集合	touch	file{1..9}

\	转义符
