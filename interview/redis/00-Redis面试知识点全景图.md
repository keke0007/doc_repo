## 九、关键关联关系记忆口诀

| 关联组 | 关联关系 |
|--------|---------|
| **单线程 ↔ 原子性** | 单线程是因,setnx/Lua/事务原子性是果 |
| **持久化 ↔ 阻塞** | fork 瞬间阻塞、大 Key 让 fork 更慢、AOF 重写也阻塞 |
| **主从 → 哨兵 → 集群** | 演进关系:可用性递增,运维复杂度递增 |
| **缓存击穿 ↔ 分布式锁** | 互斥锁是击穿的标准解,而锁本身又是 Redis 应用 |
| **布隆过滤器 ↔ 缓存穿透** | 拦截非法 key 的最佳工具 |
| **过期策略 ↔ 淘汰策略** | 过期是被动清理,淘汰是内存满时主动清理 |
| **大 Key ↔ 多个问题** | 影响持久化 / 慢查询 / 阻塞 / 集群迁移 / 网络 IO |
| **Hash 槽 ↔ 集群规模** | 16384 槽设计是带宽和集群规模的折衷(节点 ≤ 1000) |

### 2. 持久化
- Redis 的持久化机制是怎样的?(RDB + AOF + 混合持久化)
