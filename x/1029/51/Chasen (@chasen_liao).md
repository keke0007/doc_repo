# Chasen (@chasen_liao)

最近想要转AI产品经理，那这几个skills千万不能错过了！🔥  
  
翻了一圈 [skills.sh](http://skills.sh) 和 𝕏 上的推荐，按 PM 从想法到上线的流程挑了 10 个，安装量都是今天在 [skills.sh](http://skills.sh) 上现查的  
  
1. grill-me  
丢一个想法或方案进去，它顺着决策树一路追问，问到你答不上来为止，写 PRD 之前先被它拷问一遍，漏洞基本就露出来了  
  
140 万次安装  
  
npx skills add mattpocock/skills --skill grill-me  
  
2. to-prd  
把聊过的上下文和代码库现状直接整理成结构化 PRD，配套的 to-issues 再把 PRD 拆成能开工的任务  
  
35 万次安装  
  
npx skills add mattpocock/skills --skill to-prd  
  
3. prototype  
  
交互或逻辑拿不准，就让它做个用完即扔的可交互原型，几个 UI 方案能来回切着比  
99 万次安装  
  
npx skills add mattpocock/skills --skill prototype  
  
4. customer-research  
  
分析访谈记录、问卷、客服工单，还会去 Reddit、G2、Hacker News 挖用户原话，整理成痛点和用户画像  
11.5 万次安装  
  
npx skills add coreyhaines31/marketingskills --skill customer-research  
  
5. mom-test  
  
用户访谈专用，照着《The Mom Test》教你怎么问，别聊你的点子，聊对方的生活和真实行为，这样问出来的才是真话  
  
npx skills add wondelai/skills --skill mom-test  
  
6. last30days  
  
任何话题都能把最近 30 天 Reddit、𝕏、YouTube、HN 上的讨论拉下来做调研，GitHub 6.5 万星  
  
npx skills add mvanhorn/last30days-skill --skill last30days  
  
7. competitor-profiling  
  
丢几个竞品网址，它去抓首页、定价、功能页，再翻 G2、Product Hunt 的评价，出一份格式统一的竞品档案  
9.4 万次安装  
  
npx skills add coreyhaines31/marketingskills --skill competitor-profiling  
  
8. prioritization-frameworks  
  
RICE、ICE、Kano、MoSCoW 等 9 个优先级模型，公式、适用场景、模板全有，它反复强调一句，排的是问题不是功能  
  
npx skills add phuryn/pm-skills --skill prioritization-frameworks  
  
9. pre-mortem  
上线前先假设项目已经失败，倒推风险，再分成上线前必须解决、上线后跟进、持续观察三档  
npx skills add phuryn/pm-skills --skill pre-mortem  
  
10. metrics-review  
  
Anthropic 官方 knowledge-work-plugins 里的，拉产品数据看趋势，找能落地的结论，做周报复盘刚好  
  
npx skills add anthropics/knowledge-work-plugins --skill metrics-review  
  
有一说一，skill 也别一口气全装，pm-skills 的作者自己都说每个仓库挑五到七个常用的就够了，skills要精选适合自己的
