# 小能猫 (@n7wb1l)

AI 时代的反向代理与治理天花板！专为 AI Agent 与 MCP 服务器打造的下一代智能网关：Agentgateway 🤖🌐  
  
在多 Agent 协作、LLM API 聚合调用以及 Model Context Protocol（MCP）爆发的时代，传统的 API Gateway 面对复杂的 Agent 间通信、工具联邦和意图流转往往显得力不从心  
  
Agentgateway（agentgateway/agentgateway）在 GitHub 上收获了 5.4k+ Stars！它是一款基于 AI 原生协议（MCP & A2A）构建的开源代理网关，为 Agent 到 LLM、Agent 到工具、Agent 到 Agent 的全链路通信提供开箱即用的安全防护、可观测性与精细化治理  
  
👥 【适用人群】  
  
AI 应用架构师与后端工程师：需要统一管理多模型提供商、做成本预算控制与智能路由的企业技术团队  
  
多 Agent & MCP 生态极客：正在构建复杂多智能体协作、频繁挂载各类外部工具与数据源的开发者  
  
云原生与安全运维专家：对 LLM 安全护栏（Guardrails）、细粒度 RBAC 权限控制和全链路 OpenTelemetry 观测有强需求的团队  
  
🎯 【核心 6 大 AI 原生杀手级特性】  
  
1️⃣ 统一 LLM 网关（LLM Gateway）： 提供 OpenAI 兼容的统一 API 路由至各大主流模型（OpenAI、Anthropic、Gemini、Bedrock 等），内置预算开销控制、提示词丰富、负载均衡与故障转移机制  
  
2️⃣ MCP 专属网关（MCP Gateway）： 轻松将 LLM 连接至工具与外部数据源；支持工具联邦（Tool Federation）、stdio/HTTP/SSE/Streamable HTTP 传输协议、OpenAPI 集成及 OAuth 认证  
  
3️⃣ A2A 智能体间通信网关（A2A Gateway）： 启用安全的 Agent-to-Agent 协同，支持能力发现（Capability Discovery）、模态协商（Modality Negotiation）与任务联合  
  
4️⃣ 大模型推理智能路由（Inference Routing）： 针对自托管模型通过 Kubernetes Inference Gateway 扩展实现智能路由，决策依据涵盖 GPU 利用率、KV 缓存、LoRA 适配器及队列深度  
  
5️⃣ 多层安全护栏（Guardrails）： 内置正则表达式过滤、OpenAI 审核、AWS Bedrock Guardrails、Google Model Armor 以及自定义 Webhook 的多层内容安全过滤  
  
6️⃣ 企业级安全与极致可观测性： 支持 JWT、API 密钥、OAuth 认证，基于 CEL 策略引擎的精细化 RBAC 权限控制、限流、TLS 加密及全套 OpenTelemetry 指标、日志和链路追踪
