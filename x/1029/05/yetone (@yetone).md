# yetone (@yetone)

可能大家都知道，我平时都用 Herdr 进行 Vibe Coding，出门在外的话，会在手机上用 uu 远程控制家里的电脑。但是通过远程来控制电脑中的 Herdr，需要不停放大缩小，以及文字和图片输入和查看图片输出都颇痛苦，整个操作体验不够 mobile native，所以我一直想着做一个手机端的 Herdr 客户端，然后就做出来了（目前只适配了 Claude Code）  
  
但是出门在外要打通内网需要一个 relay server，我心想 Alma 一直以来都自带端到端加密的 relay server，那我就把这个功能合并到 Alma iOS App 内部了。  
  
也就是说，现在 Alma iOS App 内部其实集成了一个完整功能的 Herdr 客户端，甚至还有远程桌面的功能。甚至还会自动判断你是否在同一个局域网中，如果是的话自动切换到内网连接，速度更快更丝滑，另外 relay server 也是端到端加密的，以后有时间打算把这个 Alma relay server 开源出来让大家自己搭建自己的 relay server！  
  
反正我舒服了😌
