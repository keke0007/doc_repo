# 北衡 (@xoyif63862452)

真没想到！coding agent 写业务逻辑越来越顺，界面却还经常停在「能用就行」。  
  
jakubkrehel/skills 把界面手艺收成一套 agent skills：排版、颜色、无障碍、布局、文案。MIT，GitHub 约 8.3 千星。  
  
以前这些散在博客和设计杂志里；现在一条 npx skills add，就能塞进 Claude Code、Cursor 一类工具。  
  
核心能力：  
better-interface：一次过 accessibility / layout / writing / typography / color / polish  
better-ui：圆角、光学校准、阴影、图标状态、动效给到具体数值  
better-typography：字阶、间距、换行、截断、标点  
better-colors：调色板、语义 token、格式转换、对比度  
better-accessibility：键盘焦点、ARIA、表单、读屏，对齐 WCAG 2.2  
better-layout：分组、对齐、阅读顺序、响应式与翻译预留  
interface-review：对着 branch / PR / 未提交改动做界面回归  
  
真正值钱的是把「界面手感」写成可安装技能，而不是再堆一篇设计文章。  
做产品界面、又天天用 coding agent 的人，值得留下。
