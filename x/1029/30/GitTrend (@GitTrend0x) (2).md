# GitTrend (@GitTrend0x)

Pi 插件圈又燃爆了 🔥  
  
jonaslsaa 的 OptChat 无限记忆、fabric-runtime 的 Fabric 可编程运行时、Pringled 的极简扩展全家桶、acoyfellow 的 write-judge 改测试判官、KouzakiUmi 的毛茸茸搭子呜咪……全网玩家把 Pi 玩成了下一代「永不失忆的大脑 + Agent 操作系统 + 顺手工具箱 + 代码纪律委员 + 赛博宠物」:  
  
1️⃣ jonaslsaa/pi-optchat（[github.com/jonaslsaa/pi-o…](https://github.com/jonaslsaa/pi-optchat)）  
  
照着 Victor Taelin 的 OptChat 配方，每个 profile 一条无尽对话，用摘要树代替压缩；还能派后台子 Agent，导入 Claude Code、Codex、ChatGPT 历史。  
“对话永不压缩，记忆永不断片”！  
  
2️⃣ fabric-runtime/pi-fabric（[github.com/fabric-runtime…](https://github.com/fabric-runtime/pi-fabric)）  
  
给 Pi 一个 fabric_exec 工具，在隔离沙箱里用 TypeScript/Python 编排工具、MCP、子 Agent 和工作流；README 称用它的 Agent 在 ARC-AGI-3 拿下 25 个环境全通关。  
“一个工具，撬动整个 Agent 军团”！  
  
3️⃣ Pringled/pi-extensions（[github.com/Pringled/pi-ex…](https://github.com/Pringled/pi-extensions)）  
  
一套大多不到 300 行、零依赖的小扩展：Claude Code 风格 diff、上下文/花费状态栏、后台任务防卡死、文件回滚检查点、浏览器里逐行批注反馈。  
“小而美，装上就回不去了”！  
  
4️⃣ acoyfellow/write-judge（[github.com/acoyfellow/wri…](https://github.com/acoyfellow/write-judge)）  
  
每次 edit/write 落地前先问一句：这次改动是不是在删测试、削弱断言？小决策模型判概率超过 0.5 就拦下，逼 Agent 说清理由。  
“想靠删测试让 CI 变绿？门都没有”！  
  
5️⃣ KouzakiUmi/pi-furry-partner（[github.com/KouzakiUmi/pi-…](https://github.com/KouzakiUmi/pi-furry-partner)）  
  
一只蹲在 Pi 输入框旁的毛茸茸「呜咪」：想事情托下巴、改文件敲键盘、跑命令举放大镜，等你拿主意会歪头，等久了还会打盹，中英双语。  
“写代码不再孤单，终端里也有毛茸茸搭子”！
