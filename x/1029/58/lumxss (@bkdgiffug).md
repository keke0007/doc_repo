# lumxss (@bkdgiffug)

管理服务器和数据库，不用再开一堆窗口了。  
  
Navop 是一款 Rust 开发的开源桌面工作台，把 SSH、SFTP、终端、数据库管理、服务器监控和 RDP/VNC 集成到一起，支持 MySQL、PostgreSQL、Redis、MongoDB、Oracle、ClickHouse 等。  
  
它还加入了 AI 辅助 SQL 和终端分析。虽然不一定能替代专业客户端，但日常运维、远程管理会方便不少。  
🔗 ：[github.com/feigeCode/navop](https://github.com/feigeCode/navop)
