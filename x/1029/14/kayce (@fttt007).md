# kayce (@fttt007)

Anthropic 招聘经理 Felix 宣布：自己团队不再做传统编程面试了。  
  
原因很简单——Claude 在那些小 React 题、算法题上已经比绝大多数候选人强，这类面试提供的信号基本归零。真正有影响力的工程师，也不是靠刷题刷出来的。  
  
更关键的变化是：AI 把“执行成本”打下来之后，新人不再被资历死死卡住。  
  
他看到比较新的工程师，正在超越那些写代码可能更强、工龄更长的人。饥饿感（主动性和野心）开始打败工龄。  
  
给没有话语权、没有社会资本的工程师的建议：  
  
1. 盯业务目标，而不是只盯 backlog。理解公司/你老板的老板真正想达成什么，把自己挂到能创造价值的方向上。  
2. 提出激进想法。想如果做成了能大幅提升目标实现概率的点子，要敢想。  
3. 周末直接做出来。用一个能跑的原型绕过写 PRD、找人对齐、等资源的传统流程。  
4. 一次只讲清楚一个好点子。别把一堆想法塞进一个原型里，否则好点子会被埋掉。  
5. 善用你的新鲜视角。做产品时你更懂外部用户；做基础设施时你还没被“这不可能”的既有认知束缚。  
  
他举了自己在 Notion 的例子：新人能发现老员工早就习以为常的问题。也提到 Anthropic 内部，两位相对新人一个周末做出了 Claude Code 的图形界面原型，大约 8 天后就公开上线，反响很好。  
  
作者自己招人时，现在更看重简历和作品集里有没有体现品味、同理心和有原则思考的小原型，而不是传统算法题。  
  
一句话：执行变便宜之后，有饥饿感并且愿意动手的人，机会比以前大得多。
