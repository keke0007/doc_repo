# LanfAI (@Huahuazo)

刷到个猛的开源Skill，画流程图架构图不用再死磕Figma了。  
  
推荐个 GitHub 项目：Diagram Design，直接让 Claude Code、Codex、Cursor 帮你出专业级图表。  
  
1、内置 45 种图表类型，流程图、架构图、时序图、甘特图、思维结构图都能整。  
  
2、能读网站的配色和字体，品牌风格自动对齐。  
  
3、Mermaid、[draw.io](http://draw.io) 这些图表可以导进来，重新排版设计。  
  
4、生成独立 HTML + SVG 文件，浏览器直接打开，图片也能导出。  
  
最痛快的是，框不用自己拖、线不用自己拉、配色不用自己调，跟 AI 说想画什么就完事！  
  
安装命令：  
npx skills add cathrynlavery/diagram-design  
GitHub： [github.com/cathrynlavery/…](https://github.com/cathrynlavery/diagram-design)
