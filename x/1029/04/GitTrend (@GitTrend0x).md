# GitTrend (@GitTrend0x)

Jev 应用分享又燃爆了 🔥  
  
kaucap08 的 1.2 万次简历匹配实验、bit-cook 的 X 垃圾信息过滤器、ondata 的 VisiData 判断插件、TheAIMogul 的树莓派 JevCam、hasanzaman22 的思考力度路由……全网玩家（均为社区第三方项目）把 TypeSafe 的 Jev 决策模型玩成了下一代「AI 猎头 + 评论区清道夫 + 表格判官 + 会说话的监控 + 省钱调度员」:  
  
1️⃣ kaucap08/jev-job-matching（[github.com/kaucap08/jev-j…](https://github.com/kaucap08/jev-job-matching)）  
  
独立实验：400 个真实岗位 × 30 份虚构简历，共 12,000 次评估，约 197 秒、花费约 0.17 美元，人工核对的 100 个岗位里 Top3 命中 96 个（作者自测）。  
“1.2 万次匹配，不到两毛钱”！  
  
2️⃣ bit-cook/Jev-X-Blocker（[github.com/bit-cook/Jev-X…](https://github.com/bit-cook/Jev-X-Blocker)）  
  
本地优先的 Chrome 扩展，用 Jev 判断模型做 X 帖子和评论区的语义过滤，规则用大白话写，看得懂黑话和 emoji 暗语，隐藏的内容随时能原地恢复。  
“评论区淘金，从此不用亲手捞”！  
  
3️⃣ ondata/vd-jev（[github.com/ondata/vd-jev](https://github.com/ondata/vd-jev)）  
  
VisiData 插件：对一列文本的每个单元格提封闭式问题，把是非概率、固定标签或有序打分连同置信度写回成新列，默认用 Jev，也可换 OpenRouter 上的其他决策模型。  
“终端表格里，每一格都有判官”！  
  
4️⃣ TheAIMogul/jevcam（[github.com/TheAIMogul/jev…](https://github.com/TheAIMogul/jevcam)）  
  
树莓派 4 + 红外摄像头，用大白话告诉它要找什么，每秒问一次 Jev 画面里有什么，目标一入镜就放「电台 DJ 式」大喊警报，还附带工地 PPE 安全监测应用。  
“一句话，教会摄像头盯人”！  
  
5️⃣ hasanzaman22/jev-effort-router（[github.com/hasanzaman22/j…](https://github.com/hasanzaman22/jev-effort-router)）  
  
Claude Code 插件：每发一条提示词，先问 Jev 要多少思考、风险多大，再用最低够用的 effort 跑；简单问题走 low，调试、高风险改动走 high 或 xhigh，模型不换。  
“该省的 token 一个不多花”！
