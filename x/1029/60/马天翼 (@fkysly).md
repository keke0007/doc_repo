# 马天翼 (@fkysly)

Manus 最新的文章《用 Manus 改造 Manus，AI Native 组织改造的实践和思考》里实践跟我最近的实践经验非常相近。  
  
而我最新认为字节一句话更能精准描述 AI Native 这种感受：Context Not Control。  
  
过去是完全靠人去指导 AI 干活，试图通过严格限定的要求让 Agent 照葫芦画瓢。  
而现在随着模型能力越来越强，应该放手让 Agent 去探索，避免人的认知能力限制了 Agent。应该把更多的精力花在优化 Agent 会用到的研发流程和工具链上，把“供应链”做好，把资料、信息都接给 Agent。  
人类主要是在关键节点、关键选型、关键约束上给 Agent 提供信息。  
  
这一点，类似于团队管理技能，特别是一些技术型管理者，容易陷入细节管理（微观管理），也就是恨不得手把手指导 Agent 该怎么做。但是，好的管理者，应该是设定目标、调度资源、跟踪进度、鼓励探索，而不是微观管理团队成员干活的细节，这对 Agent 也是一样。
