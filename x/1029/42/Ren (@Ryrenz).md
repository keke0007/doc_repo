# Ren (@Ryrenz)

📥 收藏党的视频笔记神器来了，Video Fetcher to Markdown 丢一个视频链接，就吐出一份完整的 Markdown 笔记。  
  
Video Fetcher to Markdown 是给 Claude Code、Codex 用的 skill，YouTube、TikTok、Instagram、X、Vimeo、Facebook 都能处理，不需要任何 API 密钥。  
  
看完一个教程视频，过两天就忘，想回头找某句话只能拖进度条找半天。用它之后，YouTube 视频直接读字幕，其他站点在你自己电脑上用 Whisper 转写，转录全文、作者信息、章节、实际语言、来源链接都整整齐齐放进一个 Markdown 文件，丢进 Obsidian 知识库就能搜。  
  
不到三分钟的短视频，它还会抽帧拼成一张缩略图总览，画面里的字也不会漏。  
  
工具本身是中立的，哪些视频能下载、能不能转存，是使用者自己要把握的事。  
  
视频看过，终于不再等于白看。
