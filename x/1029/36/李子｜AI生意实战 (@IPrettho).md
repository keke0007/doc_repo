# 李子｜AI生意实战 (@IPrettho)

我把几个机器人的记忆搬进了一个 Obsidian 库，这样换 Agent 就不用再从头开始了！！！这个方法我敢相信世界上只有一个人知道，就是我自己  
  
Grok Bot、Meta Muse、ChatGPT dots、Hermes bots，我都想试试，但不想每换一个，就重新给它讲一遍我的项目、偏好，以及那些我已经解释过的事情  
  
所以，我把它们的记忆、日志和工作流放在同一个库里。就是一些属于我自己的普通文件，我能直接阅读，也能自己修改  
  
每个机器人都收到同样的指令：回答前先读相关文件，再把新信息存进去。健康机器人更新健康文件夹，项目机器人更新各自的项目文件夹，带日期的日志保留历史  
  
试用新的 Agent 时，让它指向同一个库，给它同样的指令。它可以接着另一个机器人留下的上下文继续做，记忆正在变成把用户锁在某个 Agent 服务商里的东西。这就是我正在尝试的避开方式，这应该是所有人都应该避免的方式，不能让这些数据未来成为数据工厂盈利的工具
