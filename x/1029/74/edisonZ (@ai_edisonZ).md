# edisonZ (@ai_edisonZ)

普通人想转行做 AI，到底要学什么？大公司的 AI 面试，又会问到什么程度？  
  
选课程、找教程之前，可以先翻翻面试题。看看自己感兴趣的工作，具体会考哪些知识、要求解决什么问题，再决定把时间花在哪里。  
  
比如：AI Agent 和普通聊天机器人有什么区别？怎样让 AI 查资料、调用工具、记住任务进度？它答错了、执行失败了，又该怎么处理？  
  
我整理了 10 个 GitHub 面试题库和学习手册，覆盖基础概念、Agent、RAG、项目实践和系统设计。刚开始了解这个方向，也可以从基础问题读起。  
  
📚 先看中文，了解要学什么
