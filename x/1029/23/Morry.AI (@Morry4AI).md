# Morry.AI (@Morry4AI)

最近发现一个很适合做「知识可视化」的 Skill：diagram-design。  
  
已获得近 6 万 Stars。  
  
实测 7 天，它的核心作用很简单：  
  
把长文、流程和关系，设计成一张专业美观的的视觉图表。  
  
对我这个内容创作者来说，diagram-design 主要会被我用在 3 个地方：  
  
01｜制作文章里的专业配图  
  
写 AI 教程、工具介绍或者复杂概念时，可以把其中最难解释的部分直接做成视觉图表。  
  
比如：  
工作原理 → Flowchart  
产品发展 → Timeline  
系统组成 → Architecture  
产品对比 → Quadrant / Radar  
  
文字负责讲观点，视觉图表负责讲关系。  
  
另外，它还可以建立自己的 Diagram Style Guide。  
  
把品牌色、字体和视觉规则固定下来，让生成的图保持统一的个人风格。  
  
——  
  
02｜制作 PPT / 分享演示素材  
  
做 PPT 经常会遇到一个问题：  
  
有一堆文字，但不知道应该怎么把它视觉化。  
  
可以直接把某一页想表达的内容交给 diagram-design，让它判断应该用什么结构来呈现。  
  
它支持 45 种 Diagram，从流程图、时间线到架构图、象限图等基本都有。  
  
把内容说清楚，剩下的交给 AI 来画。  
  
生成以后，可以直接作为 PPT、课程或者分享演示里的核心视觉素材。  
  
——  
  
03｜把长内容压缩成一张适合传播的图  
  
一篇几千字的文章，真正值得读者记住的，可能只有一个核心模型、一条流程或者几组关系。  
  
可以让 diagram-design 把这些内容重新提炼，做成一张独立图表。  
  
比如：  
一篇 Agent 教程  
→ 一张「Agent 工作原理图」  
  
一篇 AI 工具对比  
→ 一张「工具定位象限图」  
  
一套内容创作方法  
→ 一张「AI 内容工作流」  
  
这些图既可以放进原文，也可以单独拿出来发 X、小红书、公众号，或者作为文章被引用时的截图素材。  
  
——  
  
另外，我觉得它也特别适合这些场景：  
  
● 学习一门复杂的新知识  
● 梳理项目和工作流程  
● 做工作汇报  
● 整理课程和学习笔记  
● 解释一个复杂机制  
● 把长文字变成一张容易看懂的图
