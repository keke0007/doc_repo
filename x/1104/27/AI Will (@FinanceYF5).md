# AI Will (@FinanceYF5)

现在最值得做的创业方向，很多其实已经明显到摆在桌面上了。  
  
Greg Isenberg 一口气列出 39 个想法：围绕 AI Agent、数据、机器人和个人 AI，把已经验证过的商业模式重新做一遍。  
  
完整清单👇  
  
1. 企业数据版 Zestimate：估算一家公司数据对 AI 实验室值多少钱  
  
2. Agent 版 Google Analytics：查看哪些 Agent 访问网站，以及它们想找什么  
  
3. 一人公司版 Y Combinator：投资带着一支 Agent 团队创业的独立创始人  
  
4. Agent 版 Okta：管理每个 Agent 的身份和权限  
  
5. 企业数据版 Marie Kondo：清理数据，让 Agent 真正用起来  
  
6. Agent 版 FICO：Agent 花钱前先查看信任评分  
  
7. Agent 版 Geico：为 Agent 犯下的昂贵错误提供保险  
  
8. Agent 版 Datadog：看清 Agent 执行任务的每一步  
  
9. Agent 版 Twilio：为 Agent 提供电话号码和短信服务  
  
10. Agent 版 Upwork：按任务雇用 Agent，而不是自由职业者  
  
11. AI 版 ESPN：像报道大型比赛一样报道每次模型发布  
  
12. 机器人训练版 Shutterstock：拍摄自己做家务的视频并获得报酬  
  
13. AI 数据版 Credit Karma：查看、修改或删除 AI 掌握的个人信息  
  
14. AI 诈骗版 Norton：保护父母免受伪造语音和邮件欺骗  
  
15. Agent 购物版 PayPal Buyer Protection：Agent 买错东西时负责处理  
  
16. AI 版 Geek Squad：为家庭和小企业安装、配置个人 Agent  
  
17. 私有 AI 版 Dell：为不愿使用云服务的企业提供盒装 AI  
  
18. 二手 GPU 版 Carfax：购买前先查看 GPU 健康报告  
  
19. 闲置 GPU 版 Airbnb：出租没有使用的算力  
  
20. AI 模型版 Rotten Tomatoes：用真实评价替代跑分榜  
  
21. Skills 版 G2：帮助用户找到最适合 Agent 的 Skills  
  
22. AI 记忆版 Dropbox：把一个 Agent 对你的了解迁移到其他 Agent  
  
23. 实体产品版 Canva：用 AI 完成设计，并直接生产出来  
  
24. 个人 Agent 版 ADT：当 Agent 做出越权行为时及时报警  
  
25. 机器人版 Hertz：搬家、大扫除或办活动时临时租一台机器人  
  
26. 互联网创业版 Harvard Business School：系统教授如何建立线上业务  
  
27. Agent 版 Workday：入职、管理和停用数字员工  
  
28. 个人肖像版 Getty Images：安全授权自己的脸和声音给 AI 使用  
  
29. 老年人版 Meta Muse：为高 LTV 的垂直人群定制个人 AI  
  
30. Agent 版 Google Ads：付费成为 Agent 优先推荐的答案  
  
31. Agent 版 Loom：自动回放 Agent 完成任务的全过程  
  
32. Agent 版 Plaid：让 Agent 获得银行、航空公司和商店的授权访问  
  
33. Vibe Coding 应用版 Jiffy Lube：快速修复 AI 写出的故障应用  
  
34. 数据集版 Ancestry：追踪训练数据到底来自哪里  
  
35. 人类创作内容的“有机认证”：证明内容确实由真人制作  
  
36. 创业者版 Strava：记录每周真正发布了什么  
  
37. 会砍价的 Honey：让 Agent 直接替用户谈价格  
  
38. 个人 Agent 平台版 SEMrush：分析 Muse 等平台上的流量与竞争  
  
39. Agent 版航空里程：专门为 Agent 设计忠诚度和奖励计划
