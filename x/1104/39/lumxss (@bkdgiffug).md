# lumxss (@bkdgiffug)

Agent 只会聊天还不够，真正拉开差距的，是能不能接上外部工具。  
  
有人整理了一份 Hermes 集成清单，这 3 个方向值得看看：  
  
1️⃣ Obsidian：打通知识库  
  
让 Agent 读取、编辑指定目录里的笔记，还能利用反向链接梳理知识。建议先开放专用目录，别直接把整个 vault 交出去。  
  
2️⃣ Reddit：收集真实用户反馈  
  
适合观察用户对产品的吐槽、需求和使用体验，但内容有噪声，也有广告，不能直接当成可靠结论。  
  
3️⃣ InsForge：给编程 Agent 配后端  
  
开源后端平台，提供认证、数据库、文件存储和边缘函数，可通过 MCP 或 CLI 接入，减少重复搭建基础设施的工作。
