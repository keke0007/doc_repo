# 阳阳 (@tantanyuli)

一直想搭一个自己的“第二大脑”，可不少方案要么收费，要么数据得搁别人服务器上，怎么办？  
  
claude-obsidian 换了个思路：让 Claude Code 直接帮你打理本地的 Obsidian 知识库。  
  
文章、PDF、会议转录这些资料丢进去，Agent 就会自动阅读、提取信息、建立关联，再整理成一套彼此连接的 Markdown 笔记。  
  
比较有意思的是，冲突内容它不会强行合并，遇到不同观点会明确标出来，方便之后自己判断。  
  
所有内容都是普通 Markdown，数据留在本地，知识库完全由自己掌控。
