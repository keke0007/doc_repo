# Ren (@Ryrenz)

🎓 兄弟们，斯坦福 CS329Z「Engineering AI Agents」有中文自学教程了：cs329z-chinese。  
  
19 讲中文教程加 4 个实战练习，Markdown 源文件和离线网页版都有。  
  
想系统学 Agent，最难的往往不是没资料，而是英文课件、论文、配套代码散在各处，看两讲就断了。  
  
cs329z-chinese 围着这门课的公开材料，把大模型、RAG、工具调用、记忆、多 Agent 协作和安全防护按顺序串成一条线；练习从零搭一个 Agent 开始，再到设计评测、做课程项目和读论文，还专门写了 HW1 和第 5 讲配套代码的阅读指南。  
  
网页版能搜索、有目录、分深浅主题，还有一个单文件 offline.html，下载下来路上也能看。  
  
要说明的是，这是独立整理的学习资料，不是斯坦福官方中文版，原课程和论文的权利归各自作者。  
  
会写 Python、调过 API，又想转 Agent 的，这份可以直接开读。
