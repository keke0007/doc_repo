# Viking (@vikingmute)

超级好的文章，《如何与 AI agent 协作》 as of October 2026，作者在 AmpCode 工作，里面没有啥复杂的大道理，核心思想就是大模型现在非常强大，不需要那么多约束和规则，充分相信他的能力，并且给予适当的规则即可。摘抄几条都短小精悍但是深得我心 看了好几遍  
  
1 用最新 最强的模型，差的模型让你反复浪费时间 时间也是成本  
  
2 别再担心 AI 会写出 slop ，它的能力已经够强大，即使有些冗余，也不重要  
  
3 告诉大模型你到底要什么 别告诉它具体要怎么做  
  
4 让 agent 能看见整个流程，这个说的非常好，整个流程应该都对 agent 可见 能给多少给多少 减少幻觉 E2E 生产日志 部署 等等 多给它权限  
  
5 要证据，要大模型给你 E2E，对比数据 截屏等能证明它完成了，写到 agents.md 中作为验收条件 代码风格等等不要管了  
  
文中还有很多条很多条，每条都很好，都值得拿出来好好念一遍，大家要好好看看
