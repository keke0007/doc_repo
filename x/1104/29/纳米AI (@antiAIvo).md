# 纳米AI (@antiAIvo)

如何从零手写一个Agent？整了一套 Agent 教程，共18 篇  
  
Claude Code、Codex 这些编码 Agent  
内核其实就是一个循环：  
模型请求工具，代码执行，结果放回对话，直到模型不再请求  
  
这套教程从100 行代码开始  
用 Python 一层一层往上加：  
工具、权限、上下文管理、Skills、  
接入聊天软件、定时任务、MCP、子 Agent、计划、记忆。  
  
每一课都有能直接跑的代码  
每一课末尾都对照主流 Agent 在这一块是怎么做的  
  
最后 7 篇，拿亲手写过的这 11 个零件当尺子  
逐个拆解 Claude Code、Codex、Pi、Grok Bot、  
DeepSeek Harness、OpenClaw 与 Hermes  
看它们各自做了什么取舍  
  
整理完最大的感受是：  
主流产品的分歧，大多集中在一个问题上：  
安全这一层，交给提示词，还是交给代码
