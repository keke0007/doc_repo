# 纳米AI (@antiAIvo)

想学会如何用 AI Agent 写代码？  
最好的免费教程之一，是斯坦福这门课  
CS146S The Modern Software Developer  
  
讲师 Mihail Eric 不是学院派教授  
斯坦福 NLP 组出身，做过 Alexa AI 科学家  
自己创办过 YC 的 AI 编程工具公司，所以这门课非常实战  
  
大致学习路线：  
先用 200 行写一个 Claude Code 式的 Agent  
再学提示、spec 驱动开发、MCP、Skills  
然后是 CLAUDE.md、AGENTS.md、hooks  
怎么让代码仓库 agent-ready  
AI 代码审查、安全、后台异步 Agent  
最后讲 AI 原生团队怎么协作  
  
嘉宾很硬  
Claude Code 作者 @bcherny  
Cursor 的 @leerob 、Replit CEO @amasad  
还有 Cognition、Factory、Semgrep、Cloudflare 的一线负责人  
  
我的理解：  
这门课教的是怎么用好、管好 Agent  
从零实现只在第 1 周做入门，重心在工程实践  
  
如果你想反过来，看清 Agent 内部是怎么造出来的  
循环、工具、权限、上下文、记忆、子 Agent  
可以配合我的「从零手写 Agent」一起看  
[github.com/aa1143/NamiAge…](https://github.com/aa1143/NamiAgent)
