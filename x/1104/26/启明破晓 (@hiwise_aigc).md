# 启明破晓 (@hiwise_aigc)

卧槽，GitHub 上挖到一个真香的开源笔记工具：EdgeEver！  
  
有点想把 Obsidian 换了。最吸引我的不是它能记笔记，而是笔记能直接给 AI Agent 用！  
  
几个亮点👇  
• 原生支持 MCP，AI Agent 可以直接读写笔记  
• 支持 Markdown、网页剪藏，X、小红书内容也能收藏  
• 多端实时同步，离线也能写  
• 支持 Docker 私有部署，数据自己掌控  
• Cloudflare 免费额度内就能跑，不用买服务器  
  
想想以前笔记存进去记本就吃灰，现在能直接变成 AI 的知识库，让 Agent 帮你整理、检索、更新。  
当然，实际同步体验和稳定性还得自己折腾验证。  
  
兄弟们，你们现在用 Obsidian、Notion，还是已经让 AI 接管笔记了？😂
