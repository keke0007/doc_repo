# Mr Panda (@PandaTalk8)

怎样学习深度学习  
1. 先学习数学基础：深度学习需要掌握线性代数、微积分、概率统计等数学知识，因此先学好这些基础知识是必要的。  
  
2. 学习机器学习：深度学习是机器学习的一个分支，因此了解机器学习的基本概念和算法是深度学习的基础。  
  
3. 学习Python编程：大部分深度学习框架都是基于Python编程语言开发的，因此学会Python编程是深度学习的必要条件。  
  
4. 学习深度学习框架：常见的深度学习框架有TensorFlow、Keras、PyTorch、Caffe、Theano等。选择一门框架学好，并熟练掌握其API。  
  
5. 学习深度学习模型：深度学习模型有很多种，例如卷积神经网络（CNN）、循环神经网络（RNN）、递归神经网络（Recurrent Neural Network）、生成对抗网络（GAN）等。选择一种模型开始学习，逐渐扩展到其他模型。  
  
6. 动手实践：深度学习需要大量的实践训练，可以通过解决实际问题或参加竞赛来提高自己的能力。
