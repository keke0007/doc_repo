# Chuck Bass (@ChuckBass14291)

Anthropic 核心技术团队成员兼 Claude Code 创作者 Boris Cherny 演讲  
  
《Mastering Claude Code in 30 minutes》  
  
看完 Boris 的分享，最深的两点启发：  
1. 开发者从“编码员”演变为“Tech Lead / 调度指挥官”：  
你不再需要逐字手写样板代码，你的核心价值变成了制定清晰规范（CLAUDE.md）、设计验证闭环（测试与自动化工具）、把控全局方案（Think first before coding）。  
  
2. AI 工具的终局不是取代现有基础设施，而是无缝融入现有生态：  
Claude Code 没有尝试再造一个笨重的专属 IDE，而是以终端 CLI、Git、MCP、Unix 管道的方式，寄生在工程师最熟悉的工作流中。生态越开放、越无侵入，爆发力越强。
