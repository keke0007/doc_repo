# 李富贵 (@shenxiankk)

总算有人把「看美剧学英语」整成 AI Skill 了！  
  
GitHub 上冒出一个开源项目 gbro-series-vocab，你只要给出剧名和集数，比如《绝命毒师》S02E03，AI 就会自动去搜这一集的字幕或剧本，挑出 50 个值得学的词汇、俚语和地道口语表达。  
  
它还能自动生成 Anki 记忆卡片和 Markdown 词汇笔记，音标、中文释义、剧中原句和翻译都给你配齐。  
  
Claude Code、Codex 都能用，不需要额外的 API Key。  
  
往后看美剧，先花 10 分钟把单词过一遍，再接着追剧，学英语轻松多了！
