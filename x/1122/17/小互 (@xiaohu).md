# 小互 (@xiaohu)

最近一直在给企业做 AI 化改造，发内容少了  
做的几乎是全流程的改造很费劲  
  
最愁人的是企业的各种数据对接和企业知识库的搭建  
  
因为收集好的数据和文档清洗好清洗，但是如何能和真实业务匹配、互相关联，交叉对比是个非常大的难题  
  
试了很多开源方案都不是很理想，直到我发现这个🧵...  
  
lumimax 一个面向 Agent 的企业级知识库  
  
它会把资料先「编译」成互相链接的知识，再拿来问，可以作为企业的AI知识大脑  
  
能把零散、超长、跨模态的资料变成一张能推理、能查证的“知识大脑”  
  
我用英伟达 6 个季度共 40 份财报、10 篇 RAG 论文实测了几天  
  
它能做什么：  
  
· 跨文件提问，一问查几十份文档  
· 答案带出处，点开就是原文段落  
· 冲突检测，找出不同文件对不上的说法  
· 知识图谱、增量更新  
· 通过 MCP 给 Codex、Claude 等 Agent 调用
