# Gk (@0xGky)

微信聊天记录，如今已经能直接拿去给 AI Agent 用了。  
  
wx-cli 读得出 Mac 本机里存的微信数据，Claude Code、Codex、Cursor 借此就能检索聊天记录、查看联系人和群聊、把图片和语音提取出来，新消息也能实时监听。数据默认只保留在本机。  
  
有意思的地方，是自带一套 Agent Skill，往后直接问就行：  
  
“上周和某客户聊了什么？”  
“把今天所有群聊整理成日报。”  
“哪些事情答应别人了但还没处理？”  
眼下支持的环境是 Apple Silicon Mac + 微信 4.1.7 以上，只有第一次提取数据库密钥这一步，得先把 SIP 关掉才行。
