# 陈发财 (@Chenfacai0)

想要成体系地学 Agent 开发，网上教程却散落各处、缺乏章法，Stanford 的公开课质量虽高，可纯英文啃下来速度实在慢。  
  
cs329z-chinese 将 Stanford CS329Z《Engineering AI Agents》的公开材料重新编排，做成一套中文教程，包含 19 讲正文外加 4 个动手练习。  
  
开篇先讲大模型，随后依次延伸到检索增强（RAG）、工具调用、Agent 记忆、多 Agent 协作，收尾落在评测与安全，脉络与课程原顺序一致。  
  
GitHub 链接：[github.com/wanghao-SunSky…](http://github.com/wanghao-SunSky/cs329z-chinese)  
  
练习环节涵盖从零构建一个 Agent、设计评测方案、课程项目以及论文实践，第一次作业和第 5 讲配套代码还额外附有导读。  
  
项目既有在线阅读的网页版，可搜索、能切换深浅色主题，也提供单文件离线包，断网时用浏览器打开照样能看。  
  
作者给出的建议是先从前 4 讲读起，再配合第一次作业上手练。具备 Python 基础、调用过 API 的人，拿它作为 Agent 入门正合适。
