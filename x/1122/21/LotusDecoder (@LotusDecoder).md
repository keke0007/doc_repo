# LotusDecoder (@LotusDecoder)

这几天在看  
  
《[physicstravelguide.com/about/](https://physicstravelguide.com/about/)》  
  
认为可以补上《学习之道》《如何阅读一本书》之外的一块，对于，陌生硬核知识，如何快速建立手感。  
  
其中一个重要学习误区是，“新手把终点顺序当成自己的起点”  
很多教材的编写和学习顺序，是专家学者整理出来的终点顺序，是山高我为峰后，专家自身对知识体系的高度抽象。  
  
而新手是需要起点顺序，  
1. 对单个知识点，先用一个形象类比建立一种直观粗糙的认识，  
2. 随后去操作一个具体事例，  
3. 然后在具体事例中加深理论和细节的学习，  
4. 循环 1-3 ，和多个知识点之间建立深度和广度的联系。  
5. 最后才是高度抽象，对学科各个层级建立一种框架式的认知。
