# 山景城小路 (@Zen_with_AI)

agent 代码越改越聪明，但学到的新东西总在记不住怎么办？Google 这篇论文把学的新东西也存下来。  
Self-Improvement Memory 给 agent 配个记忆库：每次改动，记下根本原因、选了哪个修改、为什么选、预测和实际结果。  
下一轮提议器和选择器先读记忆再动手，换模型换任务也能接着用了就。  
10 组实验里 9 组胜出，平均 +2.36 分。代码能留下来，改代码的教训该留下来。
