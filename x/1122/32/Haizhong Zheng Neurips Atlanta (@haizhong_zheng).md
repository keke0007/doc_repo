# Haizhong Zheng  Neurips Atlanta (@haizhong_zheng)

这个 JD 和我最近跟朋友聊的东西很像。Training 这边很多 design space 其实已经比较饱和了，不管是 infra 还是算法，大框架基本都定下来了。现在更多是在现有技术上不断调优，或者尽量 scale environment 和 data，把训练效果再往上推。  
  
但 agent 这边，尤其是 harness evolution 和 long-horizon agent runtime，design space 还很大，远没有被解决。JD 里的 Harness Kernel、Managed Runtime、Evaluation & Evolution，感觉现在还没有相对统一的solution。
