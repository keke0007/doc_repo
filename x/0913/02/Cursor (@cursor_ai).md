# Cursor (@cursor_ai)

Introducing Projects, a new way of working in Cursor.  
  
Rather than creating a chat for every task, you work with a coordinator agent in a single, persistent thread.  
  
Like @bot, your agent is always on, proactively manages work with subagents, and improves over time.

---

Projects can set reminders, run scheduled tasks, follow PRs to fix CI issues, watch Slack for bug reports, and more.

![🎥 Video](<Cursor%20(@cursor_ai).assets/image-01.jpg>)

---

Agents inside a project share memory and generated artifacts like plans and demos. These files automatically sync across your device and the agents' computers.

![🎥 Video](<Cursor%20(@cursor_ai).assets/image-02.jpg>)

---

Available in beta and rolling out starting today.
