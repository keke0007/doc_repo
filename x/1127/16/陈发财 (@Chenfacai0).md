# 陈发财 (@Chenfacai0)

新闻中几乎天天都在提 3 纳米、先进封装、光刻机，可要真正把一颗芯片如何制造出来讲清楚，不少人其实说不明白。  
  
《半导体制造概论》是一本开源入门读物，它跟随一片晶圆从沙子起步，依次经过晶圆厂、测试与封装，最终成为一颗芯片。  
  
全书共 25 章，繁重的物理推导大多略过，重点放在工艺流程、专业术语以及工厂一线的实战经验上，每章都设有术语框与经验框。  
  
GitHub：[github.com/chenwei810/Sem…](http://github.com/chenwei810/Semiconductor_Manufacturing_Introduction)  
  
我个人最想先读的是「几纳米到底是什么意思」那一章，这个问题被问过太多次了，难得有人从工艺角度认真讲解一遍。  
  
附录还汇总了术语总表和晶圆厂的现场行话，原文为繁体中文，另有英文、日文、韩文版本。  
  
如果只想快速了解，读第 0、1、11、14 这四章就足够了；做软件固件的、准备入行的，书中也分别配了一条阅读路线。
