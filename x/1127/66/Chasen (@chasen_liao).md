# Chasen (@chasen_liao)

推荐所有想入门 RSI、搞清楚 Agent 到底怎么自我改进的朋友，去看看 Awesome RSI 的这篇文章，真的讲得非常非常清楚  
  
没有上来就堆一串论文和算法名，而是先把那些经常混在一起的概念拆开  
  
我们说一个 Agent 在“自我改进”，它到底改了什么？  
  
是模型参数，还是提示词、上下文、长期记忆、技能，甚至是运行它自己的那套代码？  
  
上下文和记忆有什么区别，记忆又为什么不等于技能？文里都分别讲清楚了  
  
然后再往下看，谁负责改、什么时候改、新版本怎么继承旧版本，以及靠什么反馈判断改进有没有用  
  
这些问题理顺之后，再看不同的 RSI 方法，就不只是记住几个缩写，而是能看懂它们到底在做什么、区别在哪里  
  
肥肠推荐👇
