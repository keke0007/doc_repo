# RicoUI (@ricouii)

开源我的 Vibe Coding 工作流 Skill - Vibe Workflow  
在最近几个项目迭代后，我确定了目前的 1.0 版本，内置了 9 个文档模板，按需调用。  
  
GitHub：[github.com/ricocc/vibe-wo…](http://github.com/ricocc/vibe-workflow)  
  
它做的事情其实很简单：把你这个项目的设计规范、开发约定，以及开发流程这些标准，梳理为规范化的文档。  
  
之后不管是设计、开发，还是让 AI 审查改动，它都能沿着同一套成熟的规则走，而且每一步都能复查、留痕。  
  
老实说，这也是我自己开发中的经验，我试用过不少很全能的 Agent Skill，但是绝大多数场景里，我并不需要一个非常复杂、全面的开发 Skill。Skill 越庞大，过多的指引就越容易干扰 Agent 本身的思考和能力；  
  
另外就是，我根本记不住那么多命令。开发过程中，大多数命令其实都不会主动去用。  
  
我更希望自己来决定搭配什么 Skill 干活，而不是被一套庞大的系统绑住。所以我把这个工作流设计得很克制，它只专注干好一件事。  
  
最简单的启动方式：  
  
vibe-workflow  
  
或者直接说：  
  
按 Vibe Workflow 整理项目开发文档。  
  
如果 AI 能读取项目文件，把工作流目录提供给它，让它从 SKILL.md 开始即可。  
  
普通聊天助手的话，把相关规则、模板和项目资料给它就行。它会检查现有文档、整理内容，并按需补齐缺项。
