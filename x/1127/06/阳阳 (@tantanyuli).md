有个开源项目叫 SolidCraft，能让 AI 亲手摆弄 CAD，直接做出还能继续编辑的参数化工程模型。  
  
靠 MCP，它能干这些事：  
• 新建零件、调参数  
• 把机械结构拼装起来、检查几何体  
• 输出 STEP、STL 这类工程文件  
• 兼容 Claude Code 与 Codex 接入
