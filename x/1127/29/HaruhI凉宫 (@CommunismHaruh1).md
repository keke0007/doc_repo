# HaruhI凉宫 (@CommunismHaruh1)

卧槽！这次更新真的大成功！  
  
我开发的 AI 自动化 CAD 绘图 Skill——OMNICAD，正式迎来 V1.2 版本！  
  
经过大量开发、实机测试和反复纠错，这次不仅进一步完善了自动绘图能力，还成功解决了不少此前困扰我们的技术问题。  
  
最重要的是，我们终于迈出了支持 AutoCAD LT 版本的第一步！  
  
此次更新内容：  
  
· 新增 AutoCAD LT 实验性兼容支持  
· 修复 CAD 启动及图纸切换问题  
· 新增超时保护、故障熔断与检查点机制  
· 完善机械、土木、建筑、食品工艺、车间布置五大专业验收体系  
· 强化尺寸、闭合、流向及 PDF 比对检查  
· 支持新旧版本并行安装及回滚  
· 43 项离线测试全部通过  
  
完整版 AutoCAD 2023 也已通过多项实机验收！  
  
我们正在逐步解决一个 AI 自动绘图领域的核心问题：  
  
不仅要让 AI 知道怎么画，更要让 AI 知道自己画得对不对。  
  
当然，AutoCAD LT 目前仍处于实验性兼容阶段，欢迎使用 LT 的朋友参与测试！  
  
另外，向大家汇报一下其他两个 Skill 的开发进度：  
  
· SolidWorks Skill：V0.8，已初步实现复杂机械装配、爆炸图、自动验收与故障恢复，目前正在攻克二维工程图问题。  
  
· Revit Skill：V0.2，已初步跑通建筑建模流程，正在完善基础自动化能力。  
  
按照目前的开发进度，SolidWorks Skill 将优先完成 V1.0 并开源发布，随后继续推进 Revit。  
  
最终，我希望将这三套 Skill 全部整合起来，让 AI 能够自主调用不同的工程软件，完成跨软件的自动化制图与建模！  
  
作为一名大二学生，我还有很多东西需要学习，也非常感谢各位开源前辈和网友们的支持与反馈。  
  
OMNICAD 后续仍将保持每周更新！  
  
项目完全开源，感兴趣的朋友可以拿去折腾，安装方式也非常简单！

懒人安装方法：  
  
甚至不需要你自己研究代码，也不需要手动配置复杂的环境。  
  
直接把下面这个 GitHub 链接丢给 Codex：  
  
[github.com/Haruhi764/Omni…](https://github.com/Haruhi764/OmniCAD-Skill)  
  
然后告诉它：  
  
“请完整阅读该项目的 README 和 SKILL.md，自动检查我的 AutoCAD 版本及运行环境，按照官方说明完成最新版 OMNICAD Skill 及所需组件的安装配置，并执行基础绘图测试，确认能够正常使用。”  
  
剩下的交给 Codex 就行！  
  
如果你已经安装了 V1.1，也可以直接让 Codex 帮你升级至 V1.2。  
  
使用 AutoCAD LT 的朋友请注意，目前仍为实验性支持，需要按照项目说明主动启用。
