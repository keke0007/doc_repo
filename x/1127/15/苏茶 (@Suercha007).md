# 苏茶 (@Suercha007)

做AI落地的看过来了，企业知识库作为企业业务AI化的第一步，至关重要！分享13个常用的知识库构建和问答的框架和工具。  
  
很多朋友问我知识库怎么做，其实知识库和业务场景是强绑定的，不同场景，不同类型的文档，对应的解析、持久化、构建方法甚至召回的逻辑都不一样，不能一概而论！  
  
不过市面上通用的RAG框架和工具，对自研知识库体系是有所帮助的，我们可以借鉴其中的分析和召回理论，针对性的去优化。  
  
1、WeKnora（腾讯，3.8 万星）：RAG 查询、Agent 干活、Wiki 整理三种模式共用一套知识库，飞书、企微、Confluence 直接同步。  
[github.com/Tencent/WeKnora](http://github.com/Tencent/WeKnora)  
  
2、RAGFlow（9.5 万星）：1.0 版能把文档编译成 Wiki、图谱、时间线、Skill 七种产物，还有四档思考深度的 Agentic RAG。 [github.com/infiniflow/rag…](http://github.com/infiniflow/ragflow)  
  
3、语析 Yuxi（7.8 千星）：多租户企业智能体基座，Milvus 混合检索加可选 Neo4j 图谱，带沙盒执行和命令审批。  
[github.com/xerrors/Yuxi](http://github.com/xerrors/Yuxi)  
  
4、MaxKB（2.3 万星）：界面最像传统企业软件，上手最快，注意它是 GPL 协议。  
[github.com/1Panel-dev/Max…](http://github.com/1Panel-dev/MaxKB)  
  
5、PipesHub（4.2 千星）：权限感知的企业搜索，连 50 多个系统，同一份上下文既能给人答也能通过 MCP 喂给自己的 Agent。  
[github.com/pipeshub-ai/pi…](http://github.com/pipeshub-ai/pipeshub-ai)  
  
6、PageIndex（4.1 万星）：不建向量索引，给文档建一棵可推理的目录树让模型顺着找。  
[github.com/VectifyAI/Page…](http://github.com/VectifyAI/PageIndex)  
  
7、LightRAG（4.1 万星）：轻量图谱增强，速度是卖点，换了 embedding 模型会直接拒绝启动。  
[github.com/HKUDS/LightRAG](http://github.com/HKUDS/LightRAG)  
  
8、GraphRAG（微软，3.7 万星）：社区检测加多层摘要，全局性问题答得好，代价是慢和贵。  
[github.com/microsoft/grap…](http://github.com/microsoft/graphrag)  
  
9、RAG-Anything（2.5 万星）：图片、表格、公式都当一等公民处理的多模态 RAG。  
[github.com/HKUDS/RAG-Anyt…](http://github.com/HKUDS/RAG-Anything)  
  
10、PixelRAG（1.1 万星）：直接把页面渲染成图再理解，绕开 PDF 和 HTML 解析这一整层。  
[github.com/StarTrail-org/…](http://github.com/StarTrail-org/PixelRAG)  
  
11、Graphiti（3.3 万星）：实时知识图谱，边聊边更新。  
[github.com/getzep/graphiti](http://github.com/getzep/graphiti)  
  
12、graphify（15.4 万星）：Claude Code 里敲一下，整个文件夹变成知识图谱，官方说比直接读原文件省 71.5 倍 token。  
[github.com/Graphify-Labs/…](http://github.com/Graphify-Labs/graphify)  
  
13、llm_wiki（2.2 万星）：把一堆文档变成互相链接的 Wiki，而不是一堆向量。  
[github.com/nashsu/llm_wiki](http://github.com/nashsu/llm_wiki)
