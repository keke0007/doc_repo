# Robin | Robotics Data (@Zhibin992)

晚上看了一眼GitHub热榜，n8n居然开源了个人agent助手，这个曾经ai工作流的顶级工具也开始做agent了。另外有不少设计类、视频类skill上了热门。  
  
1、nod：这是n8n的agent项目，一个带真实浏览器的开源个人 Agent，能帮助处理发票、准备会议、取消订阅，本地运行能支持换模型。  
  
2、diagram-design：一个给 Claude Code、Codex、Workbuddy 等agent用的交互式图表设计skill，内置了52 种图类型，能输出 HTML+SVG形式的图表。  
  
3、AFFiNE：堪称下一代知识库，融合文档、白板与数据库，据说是可替代 Notion 和 Miro 的本地优先方案。  
  
4、autoclip：能一键把长视频剪成短视频的桌面工具，自动生成字幕、封面和平台文案，适配抖音小红书等。  
  
5、open-code-review：这是阿里内部验证过的混合架构代码审查工具，规则引擎 + LLM Agent，支持多语言安全规则。
