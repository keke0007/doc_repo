# 苏茶 (@Suercha007)

Agent的常见概念。  
  
1. ReAct 循环：Agent 先判断需要什么信息，采取行动，再根据结果决定下一步，Agent本质就是一个循环。  
  
2. 工具调用：模型选择外部工具并给出所需参数，由程序执行调用，再把结果返回给模型使用。  
  
3. 记忆：Agent 保留和调用信息的能力。短期记忆维持当前任务的上下文，长期记忆让信息可以跨任务保存，并在需要时取回。  
  
4. 任务规划：Agent 把一个目标拆成多个可执行的步骤，确定哪些要先做、哪些可以同时做，并根据进展调整计划。  
  
5. 反思：Agent 回头检查自己的行动或输出，判断是否符合目标，再根据发现的问题修正做法或答案。  
  
6. 多智能体：多个 Agent 通过分工、交换信息和协调行动，共同完成一项任务。  
  
7. MCP 协议：MCP（模型上下文协议）是 AI 应用连接外部工具和数据源的开放协议，让不同服务可以按统一方式接入。  
  
8. 工作流与 Agent：两者的主要区别在于谁决定下一步。工作流按预先设计的步骤和分支运行，Agent 则能在执行过程中根据目标和反馈选择下一步。  
  
9. Skill（技能）：把完成某类任务所需的方法整理成一套可复用的说明，供 Agent 按需加载。Skill 还可以附带脚本、模板或参考资料。
