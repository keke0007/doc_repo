# 我的 Agent 总在犯同一个错，直到我给它装了一层会长大的记忆

用 EverOS Cloud 把踩过的坑变成 Agent 下次能直接调的经验

## 一、一个月，同一个坑踩了好几遍

我现在每天都会发 X 引用帖，每条都配一张涂鸦图。这套流程是交给 Agent 跑的：读原帖、写提示词、调模型生图、加水印、存草稿

听起来很省事，实际上这一个月我踩过的坑能写满一页：

- 生图提示词里不能出现品牌名和人名，不然直接被判敏感，白跑一趟
- 图上不能让模型乱加口号和数字，不然跟原帖事实对不上
- 图超过 5MB 上传会失败，得先压成 JPEG
- Python 发长请求老是断，换成 curl 才稳
- 电脑一断网后台任务就被杀，得放进 screen 里跑

每一条都是真金白银换来的。最让我头疼的是，这些经验全散落在聊天记录里。换一个 Agent、开一个新会话，它就像失忆了一样，我又得从头讲一遍，讲漏一条，就白花一次生图的钱

那段时间我一直在想，Agent 能力已经够强了，缺的其实是一个地方，能把它做过的事、踩过的坑存下来，下次开工前先翻一翻

## 二、EverOS Cloud 是干什么的

这两天我试了 EverOS Cloud，做的正好是这件事

一句话概括：它是给 AI 产品用的记忆层。你的 Agent 每做一次任务，它就帮你把过程和经验存下来，下次遇到类似任务，Agent 能直接调出来参考

它的官方说法是让团队做过的工作，成为下一次任务可以调用的经验。我自己的理解更直白，就是帮 Agent 写一本越来越厚的工作手册

光看介绍没意思，我直接拿自己这套配图流程实测了一把

## 三、实测：我把五个坑喂给了它

第一步：用中文把规矩告诉它

我用一段很口语的中文对话，把上面五条坑一次性讲给它。写入接口基本是秒回，大概 6 秒以后，这段话就被整理成了能搜到的记忆

整理得比我自己写的还规整，比如它记下的是：「图片若超过 5MB 则上传会失败，需先转换为 JPEG 格式，质量设置为 88」

顺手还给我生成了一份画像，写着我「从事制作 X 引用帖配图的工作」，有点被看穿的感觉

第二步：换个问法去搜

我故意不用原话，问它「图片太大怎么办」「后台任务老是断怎么办」，都能精准捞回对应的那条。混合检索每次不到 100 毫秒

最让我意外的是，我用英文问了一句 why did my image generation request fail，它照样把中文记忆找了出来

第三步：看它能不能自己总结出 Skill

这是我最想验证的。我把两次真实的生图过程录了进去：一次是提示词带了品牌名被拒，一次是图上被模型乱加了口号和数字，两次最后都改好了

大概一分半钟以后，后台多了两个 Case，还自动提炼出了一个 Skill，名字叫「生成合规图像并添加水印」。打开一看是一份带步骤和判断分支的 SOP，里面写着「主动排除文字、数字、品牌标识等审核敏感元素」「若PNG过大（>5MB）→ 转JPEG质量88」

这些就是我踩了一个月才攒下来的规矩，它看两次就记住了

第四步：记错了能不能改

我改了一条记忆的摘要，再搜出来的就是新内容；删掉一段经历，它连带提炼出的事实也一起没了。每个操作都是一个接口调用，几十毫秒的事

也说说不完美的地方

- 第一次录 Agent 过程我格式没写对，一个 Case 都没生成，照着官方 MCP 的写法重录才成功
- 它的 Skill 只总结了出过错、又被修好的步骤，curl 和 screen 那两条因为过程里没报错，就没进 Skill
- 智能检索（agentic）效果更准，但一次要 5 秒左右，日常用混合检索就够了

## 四、我最看重的五个能力

1. 经验能自己变成技能

每跑完一次任务，整个执行过程会被记成一个 Case。同类 Case 攒多了，系统会从中提炼出可复用的 Skill

实测里它就是这么把我的配图规矩变成 Skill 的，以后不用我再手动维护一份注意事项文档

2. 业务资料能直接接进来

文档、邮件、PDF、表格、PPT 都能丢进去，转成可检索的记忆

比如品牌方发来的活动 Brief、客户邮件里提过的要求，接进去以后，Agent 写稿时能自己查到规则，回答有依据，不用我每次复制粘贴一大段背景

我拿这次活动的 Brief 试了一下，问它「发文时能不能放邀请码」，它直接翻到了 Brief 里对应的那条规则

3. 给现有流程加记忆，不用重搭

接入方式是 API：任务开始前检索相关上下文，任务结束后把经验存回去，原来的工作流基本不用动

以前想给 Agent 加记忆，得自己搭向量库、写检索、处理去重，一套下来就是个小项目。这些它都包了。用 Claude Code 的话有现成插件，也可以走 MCP 接入

4. 记忆看得见，也管得了

这是我最看重的一点

Memory Bank 里能直接看到它到底记了什么，用户画像、经历过的事、提炼出来的 Skill，都能按时间和类型翻。记错的可以纠正，过时的可以删，还能给每条记忆打分

记忆这种东西，如果是个看不见的黑盒，越堆越多，我是不敢放心交给 Agent 用的

5. 云端和自托管，同一套 API

Cloud 和自托管版用的是同一套 API，自托管版是开源的，记忆还能导出成 Markdown

个人或者小团队先用 Cloud 上手，以后有合规要求，再迁到自己的服务器，代码不用重写

## 五、团队用起来是什么样

如果你的团队有 SOP，我觉得这是最能发挥价值的场景

把 SOP 和过去的处理经验放在一起，新同事或者新 Agent 接手类似任务时，能看到以前是怎么处理的、哪里容易出错。有一点我很认同：它只提供参考，正式流程要不要调整，还是由团队审核决定

AI 负责记住，人负责拍板，这个分工很舒服

## 六、怎么开始

- Cloud 有免费版，注册不用绑卡，几分钟就能接上
- 用 Claude Code 的可以先装插件，最快能体验到效果
- 建议先挑一个你最常重复的任务接进去，跑几轮，再去 Memory Bank 看看它记下了什么
