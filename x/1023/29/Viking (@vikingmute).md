# Viking (@vikingmute)

推荐 Matt Pocock 做的的一个网站，AI Coding Dictionary  
  
[aicodingdictionary.com](https://aicodingdictionary.com)  
  
用大白话解释 AI coding 术语的词典 并且做成了可交互的关系图  
AI coding 领域现在术语爆炸 很多词被用得模糊 好多营销话术 这个站点把核心概念拆成短小和非常准确的解释 而且这些词还是非常新的 里面好多词我都没有听说过  
  
比如我视频中搜索的 software factory / dark factory / 以及 AFK （away from keyboard） 都非常长知识
