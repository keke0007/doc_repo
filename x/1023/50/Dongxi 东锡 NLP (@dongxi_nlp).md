# Dongxi 东锡 NLP (@dongxi_nlp)

Agent 这件事，已经变得非常刻板和无聊。  
  
在 “Agent +” 这个场景中，会搭 Agent 这个能力最不重要，更重要的反而是对具体场景业务的熟知。  
  
换句话说，AI engineer 在现在这个语境下，已经与 AI 没有什么关系了，当然也不值什么钱。  
  
在 AI 领域工作的年轻人，更应该去靠近模型的地方：训练，量化，推理，或者去参与到 AI 基础设施到建设中去。
