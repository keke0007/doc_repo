# Bojie Li (@bojie_li)

非常赞同，我觉得 agent 开发就像 C 和 Python 一样，属于基本技能。  
  
我甚至还有个暴论，编译原理、操作系统、计算机体系结构，这三门计算机本科最硬核的课，将逐渐让位于 agent、LLM、infra 三门核心课（这也是我翻译《图解大模型》和写 agent/infra 两本书的原因）。  
  
传统软件，工程师接触的是编程语言，代码跑在编译器和运行时上；软件是在操作系统上跑的；操作系统又是基于体系结构。LLM 时代，工程师接触的是 token，agent 跑在 harness 上；agent 是在 LLM 上跑的；LLM 又是跑在 infra 上的。
