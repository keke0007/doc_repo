# 旺旺 (@TiagerBao)

Google 开源了一个 Agent，能直接操作安卓手机，连 App 测试都能自己跑。  
  
项目叫 ARTEMIS。  
  
通过 MCP 接入 Claude Code、Codex、Cursor 等工具，就能让 AI：  
  
自动点击、滑动、输入，跨 App 完成任务  
测试登录、页面跳转等完整流程  
自动抓取截图、Logcat 日志，辅助定位 Bug  
生成测试报告，支持执行回放  
  
提供两种模式：  
  
Flash：约 3–5 秒执行一步，适合日常操作。  
Pro：多 Agent 协作，带计划、执行检查和结果验证。  
  
项目公布的 AndroidWorld 测试完成率超过 99%。  
  
最实用的是：以前写完 App 还得自己拿手机反复点，现在可以把这部分工作交给 Agent。  
  
目前主要支持 Android，iOS 还在规划中。  
  
GitHub：[github.com/google/artemis](https://github.com/google/artemis)
