# 头雁 (@alacheng)

又一家RL环境/AI数据类公司获得大额融资，Labelbox刚刚完成E轮融资，筹集超过 1 亿美元。这家应该算把  
RL环境 + 企业家RSI agent + 物理世界AI数据  
结合在一起的一家公司。  
  
Labelbox拥有超过400家客户，其中包括90%以上的美国领先人工智能实验室。该公司在2026年实现了盈利，同时保持着超过五倍的年增长率。  
  
他们看到的机会是，随着人工智能模型能够执行越来越复杂的任务，下一个挑战是如何让它们从经验中学习，并在真实环境中可靠地执行任务。  
  
Labelbox 通过两款核心产品应对这一挑战：Horizo n 为前沿人工智能实验室提供强化学习环境和评估基础设施；Recursion Managed Agents 则使企业能够部署大量智能体，这些智能体可在现有业务应用程序中运行，并在每次运行中不断改进。比较有特色的就是他们这个企业级RSI agent，如果和RL环境结合起来，这想象空间还挺大。对国内类似企业是有价值的参考。  
  
他们的愿景是“不久的将来，每家公司都将运行能够从自身工作中学习的人工智能系统。要实现这一目标，需要在每个层面进行创新，从沙箱基础设施和代理框架到训练后的强化学习。Labelbox 将这些层面整合到一个平台上，而这笔资金将使我们能够进一步推进每个层面，从而使前沿实验室和企业能够构建每次运行都不断改进的人工智能，”

Horizo：面向前沿人工智能的强化学习环境，Horizo n 提供强化学习环境、专家反馈和评估基础设施，帮助人工智能实验室训练和改进前沿模型。其环境模拟了编码、研究和其他高要求任务中复杂的多步骤工作，使模型能够进行练习、获得性能反馈并通过强化学习不断改进。Labelbox 与领先的人工智能实验室和超大规模数据中心合作开展训练后项目。  
  
递归管理Agent（RSI Agent）：递归管理Agent使企业能够在其团队已使用的应用程序中部署大量 AI 代理。代理可以根据日程安排、警报、工单和其他触发器启动工作，跨工具协调，并根据预定义的标准评估其输出。每次运行都会为代理提供信息，帮助其改进处理未来任务的方式。Labelbox 内部已在工程、研发、产品、销售、市场营销和财务等多个职能部门部署了 50 多个智能体。本月初，该公司向企业客户开放了递归管理型智能体服务，将其持续改进的方法扩展到人工智能研究实验室之外。
