# 南晚Nanwan (@snwiki238337)

Anthropic 宣布把旗下制定的智能体技能开放标准 Agent Skills，正式捐赠给 Linux 基金会旗下的 Agentic AI Foundation。  
  
这是继去年他们把模型上下文协议 MCP 捐出去之后，又一次把自家的核心标准送入中立开源机构。  
这个东西吧其实我们大部分人都用过，就是 skill。  
  
Anthropic 最早在做 Claude Code 时发现，模型虽然什么常识都知道，但在面对真实企业业务时，极度缺乏那种程序性知识，也就是我们常说的步骤、规范、流程。  
  
从 2025 年底他们把它做成开放标准后，生态扩张得非常夸张，目前包括 ChatGPT、Cursor、GitHub Copilot、VS Code 等超过 70 个主流智能体平台都已经原生集成了该标准。  
  
全网发布的公开 Skills 突破了 100 万个，累计安装量更是接近 2.8 亿次。  
这次捐赠不仅包括了 Agent Skills 的商标和 Logo，还把独立的 GitHub 组织和 [agentskills.io](http://agentskills.io) 独立域名完整交由 AAIF 托管。  
  
至于对于该标准的后续的维护等等的，是由来自 Anthropic、Google、OpenAI 等多家大厂的工程师将以独立个人身份共同担任核心维护者。  
  
推进标准规范的正式提案流程和安全防护指南，确保没有任何单一商业公司能够独家把控这个格式的走向。
