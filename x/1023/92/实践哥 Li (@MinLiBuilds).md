# 实践哥 Li (@MinLiBuilds)

😲 厉害了，大模型像人脑那样学习！  
今天，MemOS 团队发布 MemT-1.0，一款拥有原生记忆架构的基础大模型。  
众所周知，模型一般在训练结束后锁死权重。想让它记住经验，只能靠Harness，塞长上下文、挂 RAG、向量数据库，或者写外部的 Memory 和 Skill。  
  
🔥 MemT 这次，直接把记忆搬进了 Transformer 的计算过程里。  
它在模型内部并联了一个可以持续演化的动态记忆矩阵。每次交互结束，模型都会像人脑一样，通过写入、擦除、遗忘三个门控机制，更新这个记忆矩阵。  
最有意思的地方来了： 基础模型权重不变，随着使用，模型内部的动态记忆矩阵不断重塑，看起来就是模型越用越聪明。  
  
🤔 论文里的几组实测数据值得关注：  
① 越长越有优势、体积恒定：在 Nano 版上，无论历史交互是 128K 还是 1M Token，单会话记忆矩阵永远只占 40 MiB。相当于一张高清图的大小。在 128K 历史下，端到端推理速度比全上下文提升 1.86 倍，持久化存储暴降 66 倍。  
② 长文本优势明显：到了 256K 历史下，端到端推理速度直接提升 3.99 倍，首字延迟（TTFT）稳定在 100ms。  
③ 把经验变成“肌肉记忆”：在 SWE-bench Verified 编程实验中，把过往修 Bug 的流程经验写进这个记忆矩阵后（不占上下文），Coding Agent 连续三次全部通关（pass^3）的稳定性从 54.0% 飙升到 62.8%。  
  
🚀 他们是怎么做到的？ 整个训练过程，基础模型冻结不动，团队训练了一个超轻量 Hyper Memory（超记忆参数），Nano 版约 0.45B，Flash 版约 3.6B。这组权重相当于模型的记忆读写控制器，每次推理过程中会对40 MiB（Nano 版） 的动态记忆矩阵执行读写操作。  
  
最有意思的是这个方向。以前大模型出厂即巅峰，拼命卷算力。现在，这些模型竟然可以自我进化了。  
  
试想一下：如果未来打通了基础模型权重和动态记忆权重的转化，一个 AI 每天工作 8 小时，在自己的记忆矩阵里不断试错、擦除、沉淀，连续干上一年。那时候的它，和刚部署第一天的自己，还会是同一个物种吗？
