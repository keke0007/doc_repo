# mijack (@JayForParking)

把这篇复盘的流程捋出来了——企业 AI 知识库从 demo 到真用起来的八步：  
  
真实问题 → 小范围验证 → 资料核对 → 查询设计 → 业务验收 → 人工接管 → 知识更新 → 持续运营  
  
三个最值钱的点：  
1）签约前先拿真实问题碰真实资料，聊天记录里的半截型号比测试题诚实得多  
2）筛选类需求（哪些产品有这个认证）光靠 RAG 不够，得进数据库  
3）验收必看等待时间——答案准了但 40 秒才出，客服现场直接毙掉  
  
最扎心的一句：资料多不代表有价值，有人持续需要才是。做知识库之前先数清楚「谁反复问、谁一直答、答错代价是什么」
