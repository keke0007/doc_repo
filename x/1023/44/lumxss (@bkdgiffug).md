# lumxss (@bkdgiffug)

USB 打印机接上 NAS，手机也能直接打印了。  
  
cups-web 是一个基于 CUPS 的网页打印工具，适合把家里的 USB 打印机接入 NAS，减少对电脑的依赖。  
  
🖨️ 手机浏览器上传文件打印  
👀 网页查看打印预览  
📄 设置打印份数、双面等选项  
适合家里有 NAS、还在用 USB 打印机的人。具体选项能否生效，还要看打印机和驱动支持情况，建议先用 PDF 实测。  
如果打印机本身支持 Wi-Fi，使用厂商官方 App 可能更简单。  
🔗 [github.com/hanxi/cups-web](https://github.com/hanxi/cups-web)
