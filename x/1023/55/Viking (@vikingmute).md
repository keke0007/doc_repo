# Viking (@vikingmute)

Matt 新的这个 skill 叫 software factory， 软件工厂[github.com/mattpocock/ski…](https://github.com/mattpocock/skills/pull/1316)  
很值得一看了，这是他设计的一个术语，就是说现在在 AI Coding 的场景下，则是把 agent 嵌进一套流水线里，完全没有人的干预 自行完成任务  
  
他设想的流程如下：  
* 有 ticket / issue 作为输入  
* trigger 自动启动任务（比如提出了新的 ticket issue 等等）  
* 有 runner / sandbox 跑 agent  
* 有 orchestrator 协调流程  
* 质量门禁（各种测试）  
* 人类只在关键节点介入  
  
我觉得是非常好的一个设计思路，我现在也在使用类似的流程，这个 skill 还在 PR 中，它目前不是一个可直接运行的系统，而是一个设计术语表加上参考框架，供你可以自行搭建，关键是思路很重要
