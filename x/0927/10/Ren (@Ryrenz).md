# Ren (@Ryrenz)

🏧 Slack、Notion、Linear 那几份月月都要交的订阅费，Macro 能让你一次性省掉。  
  
GitHub 上 4000 多 star，AGPLv3 完整开源、支持自托管，不是那种把核心功能锁在付费版里的「开源」。  
  
小团队最常见的状态是：聊天在一个工具、文档在另一个、任务在第三个、客户资料又在一套 CRM 里，一件事从沟通到落地要跨四个软件，每个都单收一份钱，中间还得靠人来回复制粘贴。Macro 把这几摊东西塞进了同一个界面，邮件、消息、文档、任务和 CRM 共用一张双向关联的图——某条任务是从哪封邮件、哪段对话里长出来的，点一下就跳回去了。  
  
AI 这块它做得挺实在：团队记忆每天定时从对话、邮件和任务里重新梳理一次，再通过 MCP 接口开放出去，你在外面用的 agent 或者别的模型可以直接读；官方说 MCP 工具覆盖了界面里近 100% 的操作，而且不限速率。做这个产品的是一支十五人左右的团队，人在纽约和多伦多，自己内部先用了大概两年才拿出来，另外也过了 SOC 2 Type II。  
  
工具越少，一件事从头跑到尾的路就越短。
