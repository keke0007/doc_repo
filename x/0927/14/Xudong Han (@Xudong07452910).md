# Xudong Han (@Xudong07452910)

Anthropic 的前线工程师分享了一个非常值得个人和团队学习的观察。  
  
以前需要几年、全员投入的代码现代化项目，现在借助 Agent 可能几个月甚至几周就能完成。  
  
但速度上来以后，新的瓶颈开始转向组织本身。代码改得太快，测试、Review、审批和上线流程反而跟不上了。  
  
所以他们总结了一套六步框架。最核心的思路其实很简单——先把什么算「做对了」定义清楚，再让 Agent 大规模动手。  
  
比如提前建立 certificate，把测试、性能、兼容性、安全等验证条件写清楚；再按照改动风险设计 Review 和上线规则。因为 Agent 生成的代码量，很快就会超过人类逐行看 diff 的能力。  
  
我也认同其中的一个实践思路。  
  
AI 把改代码这一步压缩得越短，验证、理解和组织协调的重要性反而越高。  
  
AI Coding 已经从「帮人写代码」，开始进入「怎么管理机器大规模改代码」的阶段。  
  
对于很多工程团队来说，真正要重新设计的可能是整个开发流程了。
