# Y11 (@seclink)

其实判断一个人用 AI 和 用Agent 用到了什么水平，  
最有效的方式就是看它有没有摸到 AI 的边界。  
初阶的人才（包括很多自媒体常露脸的老登），  
会把 AI Agent 描述成法力无边的超神，仿佛什么都能做，  
但是深度实践的人，才会知道当前什么还做不到和做不好的边界。  
  
因此，AI Agent 岗位有几种面试题是必须问的：  
  
1） 问技巧：在实现 AI Agent 开发新应用时，需要注意哪些事情，以避免和减少返工的可能性？  
  
2）问人机关系（边界）：现在什么类别的任务适合人来实现，什么类别的任务适合借助AI Agent 来发挥实现？
