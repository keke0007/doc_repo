# 鸟哥 | 蓝鸟会 (@NFTCPS)

用 Claude Code 搞大项目的注意了——  
  
代码库一大，每次让它探索结构就是一场灾难，文件扫个没完，工具调用堆成山，token 哗哗烧。  
  
有个开源工具叫 CodeGraph，思路很聪明：提前给你的代码库建一张语义知识图谱，Claude Code 直接查图，不用再逐文件瞎扫。  
  
效果说出来有点夸张：  
1️⃣ 工具调用减少 92%  
2️⃣ 探索速度提升 71%  
3️⃣ VS Code 这种巨型项目，十几秒完成代码溯源  
  
它能自动识别函数调用链、类继承、模块引用，改代码前还能帮你分析影响范围，不至于改一处炸一片。  
  
支持 19 种语言、13 个框架路由映射，数据全本地，一条命令装好，保存文件自动同步，基本零维护。  
  
代码量大、常用 Claude Code 重构的，装上去省时省 token。
