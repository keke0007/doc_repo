# huangserva (@servasyy_ai)

安装了这个之后，Claude Code 的体验会完全不一样。  
  
Anthropic 悄悄发布了一个官方插件，叫 claude-code-setup，它基本把 Claude Code 从“还不错的工具”变成了一个真正的 AI 开发环境。  
  
它会扫描你的项目，并推荐：  
  
→ hooks（钩子）  
→ skills（技能）  
→ MCP servers  
→ subagents（子代理）  
→ automations（自动化）  
然后一步一步帮你把这些都配置好。  
大多数人现在用的都是“原生版”的 Claude Code……  
这也是为什么他们的体验会显得有点混乱。  
真正的强大之处，其实来自它周围的生态。  
  
安装方式：  
  
/plugin install claude-code-setup@claude-plugins-official  
  
记得先收藏，免得之后找不到。
