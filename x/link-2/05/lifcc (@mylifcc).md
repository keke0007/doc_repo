# lifcc (@mylifcc)

最近给 Codex 做了两个 skill，一个让它越用越聪明，一个让它一直保持流畅。  
  
codex-retrospective 能让 Codex 定期自己 review 过去几周的会话历史，然后用最小改动去更新 AGENTS.md，还能提炼出真正可复用的小 skill。  
  
codex-fluent 则专门解决另一个痛点：用久了 session 越来越重、启动越来越慢。它强制先做 handoff，再把老 session 安全归档到独立目录，而不是直接删。  
  
两个 skill 配合起来特别合适——一个负责智力进化，一个负责流畅性。
