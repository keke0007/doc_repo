# Joruno (@wsl8297)

推荐一款 GitHub 上开源、功能扎实的跨平台日记应用：Moodiary。  
  
它把日记写作做得很全：文字、图片、音频、视频、绘画都能记；更关键的是支持本地 AI 分析，隐私数据不必上传第三方服务器，记录更安心。  
  
GitHub：[github.com/ZhuJHua/moodia…](https://github.com/ZhuJHua/moodiary)  
  
主要特性：  
- 全平台覆盖：Android、iOS、Windows、macOS、Linux；  
- 多种编辑器：Markdown / 纯文本 / 富文本随心切换；  
- 媒体附件齐全：图片、音频、视频、绘画一篇搞定；  
- 安全防护到位：密码保护 + 生物识别解锁；  
- 智能助手可选：本地 NLP，也支持接入第三方大模型；  
- 足迹地图：在地图上回看你的生活轨迹。  
  
使用方式也很友好：直接下载 Release 安装包即可上手，也支持自行编译。适合重视隐私、又想跨设备持续记录生活的人。
