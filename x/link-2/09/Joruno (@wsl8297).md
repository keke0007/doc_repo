# Joruno (@wsl8297)

团队里最痛的是需求一多就没人跟踪：谁在修、改了哪些文件、能不能进 CI、review 怎么留痕。  
  
Open SWE 是 LangChain 新近活跃的开源异步 Coding Agent 框架，更像是给组织搭内部 SWE agent 的底座。  
  
GitHub：[github.com/langchain-ai/o…](https://github.com/langchain-ai/open-swe)  
  
它适合把自动修复、代码审查、批量 issue 处理接进现有仓库流程，让任务可以排队、执行、回看，而不是停留在“单人聊天助手”的阶段。  
  
核心亮点：  
  
- 面向异步编码任务，不只是一次性问答  
- 适合团队内部排队处理 bug、issue、review 任务  
- 可以把 Agent 执行过程留痕，方便后续审查  
- 更适合工程效能、平台工程、内部开发工具场景  
  
适合想把 AI 编码从个人玩具推进到团队流程的人研究。
