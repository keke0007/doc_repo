# Joruno (@wsl8297)

很多时候觉得 AI 回答不够准，不一定是模型不够强，而是问题没问对。想把 AI 用到位，提示工程（prompt engineering）几乎是绕不开的基本功。  
  
我在 GitHub 挖到一份清单：Awesome Prompt Engineering，把提示工程相关的学习资料、工具和实战案例按体系梳理得很清楚。  
  
从入门指南、系统课程、提示词库到开发工具一应俱全，既包含 OpenAI 官方文档，也收录了吴恩达老师的教程等核心资源。  
  
GitHub：[github.com/brandonhimpfen…](https://github.com/brandonhimpfen/awesome-prompt-engineering)  
  
它不只是给你“现成提示词”照着抄，还整理了 PromptLayer、Promptfoo 等调试与测试工具，方便做版本管理、对比效果、持续迭代。  
  
另外还补齐了论文与社区讨论的入口，想深挖原理、提升提问上限，也有路可走。  
  
如果你想系统练好提示词，或正在做 AI 应用需要把效果打磨到位，这份合集很值得直接收藏。
