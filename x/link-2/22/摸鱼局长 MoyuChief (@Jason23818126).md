# 摸鱼局长 | MoyuChief (@Jason23818126)

安装了这个之后，Claude Code 的体验会立马不一样  
  
Anthropic 悄悄发布了一个官方插件 claude-code-setup，把 Claude Code 从「还不错」升级成了专业的 AI 开发环境  
  
它会自动扫描你的项目，一键推荐并帮你配置：  
  
→ Hooks  
→ 技能  
→ MCP 服务  
→ 子代理  
→ 自动化  
  
然后一步一步、手把手帮你完成所有设置  
  
大多数人还在原生使用，配置经常要花 30-60 分钟，还容易出错  
  
装上之后，配置时间一般可以缩短到 3-5 分钟，体验提升很明显  
  
安装命令（复制即用）：  
/plugin install claude-code-setup@claude-plugins-official  
  
建议收藏，下次就不用到处找了
