# 猪脚饭.Ai (@mnmn94253156337)

用 AI 写代码的人多了以后有一个问题：Claude Code 装了一套 skills，到了 Cursor 里没了，到了 Codex 也没了，每次换工具都要重新来一遍。  
  
skillshare 解决的就是这个事 一个地方管理所有 skills，一条命令同步到所有 AI 工具。  
  
它能做的：  
  
• skillshare sync → 所有 agent 的 skills 全部同步  
• 装新 skill 之前自动扫一遍有没有恶意代码  
• 有 GUI，不用记命令行  
• 一个文件搞定，零依赖  
• 还能团队共享，公司里用同一套 skills  
  
适合所有同时用两个以上 AI 工具的人。如果你是 Claude Code + Cursor + Codex 都装着，这就是你缺的那个螺丝。
