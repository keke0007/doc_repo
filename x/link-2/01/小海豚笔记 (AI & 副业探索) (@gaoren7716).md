# 小海豚笔记 (AI & 副业探索) (@gaoren7716)

很多人现在在学 AI 工程，其实都走错方向了  
  
一上来就 LangChain、Agent、RAG、Vector DB，结果会用一堆工具，但拼不出系统  
  
ai-engineering-from-scratch 这个项目挺"反直觉"的点在于：它不是教你用 AI，而是让你从零理解 AI 系统怎么搭出来  
  
它拆的不是模型，而是整条工程链：  
  
prompt 怎么变成可控输入 context 怎么管理才不会乱 tool call 怎么结构化 memory 怎么设计才不崩 agent loop 怎么收敛 输出怎么稳定成系统行为  
  
核心其实就一句话：AI 工程不是"调模型"，是"控系统"  
  
很多人做 demo 很顺，一进生产就崩，问题通常不是模型不行，而是你根本没有工程结构  
  
这个项目更像是在补一件事：把 AI 从"玩具级调用"拉回"工程级设计"  
  
看完你会发现一件很现实的事：很多所谓"高级框架"，本质只是把复杂度藏起来了，而不是解决了
