# 山景城小路 (@Zen_with_AI)

📐 ML 铅笔手稿 第 13期 📷✏️  
  
上期的问题：Attention 只是"查字典"这一个动作。怎么把它装成一台完整的机器——输入一句话，输出另一句话？2017 年《Attention Is All You Need》给出的答案就是 Transformer。  
  
整机分两半：编码器（encoder）把输入句子变成一组"理解过"的向量；解码器（decoder）一边看编码器的输出，一边逐词生成目标句子。  
  
编码器的一层只有两个零件：多头自注意力 + 前馈网络（FFN），每个零件外面都包一层"残差连接 + LayerNorm"，这样的层堆 N 层（原文 6 层）。  
  
先解决一个 bug：自注意力本身不分先后——"猫追狗"和"狗追猫"算出的权重完全一样。所以词向量进模型前，要先加上位置编码。原论文用的是正弦函数：  
  
PE(pos,2i) = sin(pos/10000^(2i/d))，PE(pos,2i+1) = cos(pos/10000^(2i/d))  
直觉：每个位置得到独一无二的"指纹"，相对位置关系还能被线性变换表达；不用学参数，任意长度都能外推。  
残差连接 + LayerNorm：残差把输入直接加回输出（x + 子层(x)），给梯度一条"直通车"，层堆深了也不塌；LayerNorm 把每层输入的分布拉回稳定，训练才不飘。  
  
前馈网络：FFN(x) = max(0, xW₁+b₁)W₂+b₂，中间层放大 4 倍再压回来。分工很清楚：注意力负责"词与词之间交换信息"，前馈负责"每个位置自己消化"——逐位置独立、参数全位置共享。  
  
解码器多了两样东西：一是 masked 自注意力——生成第 t 个词时只能看前 t−1 个词，softmax 前把未来位置 mask 成 −∞，训练时整句并行、推理时逐词自回归；二是 encoder-decoder 注意力——Q 来自解码器、K/V 来自编码器，决定"生成这个词时该看原文哪里"。  
  
为什么它取代了 RNN？两条：一是并行——RNN 必须按时间步串行，Transformer 训练时整个序列一次前向，GPU 利用率天差地别；二是长距离——RNN 里信息要穿过 O(n) 步，Transformer 里任意两个词的路径长度都是 O(1)，再远的依赖也一步直达。  
  
一句话：Transformer = 位置编码 + 残差堆叠的注意力层 + 前馈网络，用"查字典"代替了"一步步读"。
