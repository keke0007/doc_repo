《Pi 源码精读》第 3 集：正忙时又说一句  
  
你让 Agent 看一个文件，它正在忙。你又补了一句：“回答写成一行就好。”这句话会去哪？Agent 这一次能听到吗？  
  
① 收件箱  
Agent 正忙的时候，你说的话不会马上写进记录本（对话），而是先放进收件箱排队。放进去的那一刻就存了档。只要存储在磁盘上，程序崩了，排队的话也还在。  
  
② 插话和追问  
发消息时，你可以选两种方式：  
· 插话：想让 Agent 这一轮就听到。如果它这一轮还要用工具，工具一做完，插话就写进记录本，下次问模型时它能看到。  
· 追问：等这一轮答完再说。这一轮回答完，追问才写进记录本，单独开始新的一轮。  
注意，插话只是“有机会就赶上”：插话以后这一轮不再用工具，它也只能等到下一轮。不特别说明，就按追问处理。  
  
③ 为什么不马上写进记录本？  
模型已经拿着记录本去想回答了，这时写进去，它这一次看不到；可它的回答会排在你这句话后面，看起来像回答过，其实没看到。先进收件箱，等到要再问模型之前再写进去，排在这句话后面的回答，就都是看过它的。  
  
记住一句话：Agent 正忙时，你的话先进收件箱，等时机到了再写进记录本。
