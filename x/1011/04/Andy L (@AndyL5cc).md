# Andy L (@AndyL5cc)

很多人可能从一开始，就用错了 Claude。  
  
最近看到一段 30 分钟的深度实操视频，才发现高手调教 Claude，靠的根本不是提示词玄学。  
  
总结 5 条核心经验：  
  
1. 结构化： 用 XML 分隔规则、角色和数据，别把指令揉成一坨。  
2. 做减法： 及时删除旧模型遗留的限制，别让过时的 Prompt 拖后腿。  
3. 善用工具： 复杂计算交给代码，喊一万遍「务必准确」也没用。  
4. 给足上下文： 告诉 AI 不同选择的收益和代价，而不只是下命令。  
5. 建立闭环： 生成→评估→修复，比一个巨型 Prompt 更灵活可靠。
