# 流程起点前移，电话轮不再默认是编程  
  
与 5 月版本相比，最明显的变化是招聘沟通通常会先进行，时长约 15 到 30 分钟。候选人几乎都会被问到为何选择 Anthropic，多数通话还会谈到 AI 安全。转介绍沟通可以短至 15 分钟；管理方向的通话约 30 分钟，并会问到团队规模，以及候选人是否仍在写代码。  
  
此后路径并不统一。有的流程会先安排在线测评，有的则从招聘通话直接进入约 45 分钟的电话面试。电话轮现在既可能是编程，也可能是系统设计，两者出现频率大致相当。编程仍多在 CodeSignal 的笔记本环境中进行，且没有自动补全，招聘方常提醒准备并发相关内容。系统设计则可能是审阅已有设计文档、找出问题并回答追问，也可能是开放式设计。另一个变化是：候选人通常要到轮次开始时，才知道自己会遇到哪一道题。  
  
# 现场循环加入仓库协作，工具规则因岗位而异  
  
线上面试通常为 4 到 6 轮，包括一两轮编程、多数流程中的一轮系统设计、项目深挖、文化面试，以及招聘经理面试。项目深挖常见形式是短汇报加问答。技术轮在前，随后是文化面试，最后才是招聘经理。  
  
更值得注意的是现场中的 AI 工具安排。7 月到 10 月已有候选人报告，部分循环会出现 Claude Code 编程轮：在浏览器 IDE 里面对一个代码仓库和已有的 pull request，允许使用 Claude Code 和网页搜索，邀请函会事先说明这一点。Safeguards 团队在 10 月则出现过另一种安排：候选人需要自己编写 agent 循环，而不是直接使用 Claude Code。原文因此建议，除了明确允许使用 Claude Code 的轮次外，其他轮次都要向招聘方确认可用工具、是否提供现成仓库，以及需要提交什么结果。  
  
# 结果反馈减少，考察更接近真实工作  
  
汇总称，近期大多数拒信没有反馈。评论区的补充与此相符：有人在招聘沟通阶段就被问住，也有人走完五轮后仍未得到解释。评论里还出现过更接近实际系统工作的题目，例如搭建多 agent 系统，让模型从研究文献中提出假设。这与正文强调的仓库协作、文档审阅和自己实现 agent 循环，方向相同。
