# Suu (@Suu766)

很多大学生翻墙以后，用 X 的时候还是只会搜“每日大赛”！！？  
  
其实 X 最值钱的东西，很多根本不会主动推到你首页  
  
会搜的人拿 X 找一手消息、教程、机会和真实反馈  
  
不会搜的人，一整天都在看别人搬运过的东西  
  
给大家分享几个我在用的搜索方法

---

1. 先把垃圾内容过滤掉  
  
比如你想搜 AI Agent：  
  
"AI agent" min_faves:100 -filter:replies lang:zh  
  
min_faves:100 = 只看 100 赞以上  
-filter:replies = 去掉回复  
lang:zh = 只看中文  
  
比你直接搜关键词干净太多  
  
中文圈互动普遍低一点，min_faves 可以从 10、20、50 慢慢调

---

2. 想找真实需求，直接搜别人怎么问  
  
比如：  
  
"有没有人用过" Claude  
  
("怎么注册" OR "审核挂了" OR "被拒了") Wise  
  
("求推荐" OR "踩坑") eSIM  
  
这种搜索很好用  
  
因为很多真正的问题，都藏在别人求助、失败、吐槽的帖子里  
  
你做内容的话，这些东西甚至可以直接拿来找选题

---

3. 想研究一个账号，直接锁定他  
  
比如：  
  
from:Suu766 min_faves:50 -filter:replies  
  
只看某个人最近一个月：  
  
from:账号名 since:2026-09-01 until:2026-10-01  
  
拿来研究同行、找爆款、翻一个人以前发过的内容都很好用

---

4. 只搜带图片、视频、链接的帖子  
  
找教程截图：Ollama filter:images  
  
找视频： 论文复现 filter:videos  
  
找 GitHub、网站、文档：AI工具 filter:links  
  
如果你本来就是来找资源的，没必要一条条翻纯文字

---

5. 给搜索加时间  
  
比如只看最近两天：  
  
空投 since:2026-09-17 until:2026-09-19 min_faves:10  
  
很多东西一个月前还有用，今天可能已经不行了  
  
尤其是 AI、Web3、活动、政策这种更新快的东西，时间一定要卡

---

6. 中英文各搜一遍  
  
比如 GitHub Student Pack：  
  
GitHub 学生包 lang:zh  
  
"GitHub Student Pack" lang:en  
  
中文区适合看教程  
  
英文区更容易找到源头、更新和第一批反馈  
  
同一个东西搜两遍，信息差一下就出来了

---

会搜以后，你会发现 X 根本不只是拿来刷帖的  
  
很多所谓的信息差，一直都在搜索框里
