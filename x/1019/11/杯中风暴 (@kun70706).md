# 杯中风暴 (@kun70706)

每次让 Agent 查个数，它都重新写一遍 SQL，口径还每次都不一样。  
  
我用 EverOS Cloud 给数据查询加上记忆：  
每次查询任务记成一个 Case——查了哪些表、口径怎么定、SQL 怎么写；跑顺了的几次，自动提炼成 Skill。  
下次再问"上个月各渠道 ROI"，Agent 先检索 Skill，直接复用验证过的查询逻辑，口径稳定、过程可追溯。  
  
接入很轻：任务前检索相关 Skill，任务后把本次查询沉淀为 Case。  
不用自建记忆基建，Cloud 和自托管是同一套 API，记忆还能查看、纠正、删除。
