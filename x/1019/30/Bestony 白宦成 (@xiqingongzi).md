# Bestony | 白宦成 (@xiqingongzi)

看到大家在讨论 Dify/N8N 之类的工作流类产品，我这周末刚好在天津 GDG 做 N8N 的 workshop。刚好也说说我的看法：  
  
1. Agentic App 很好，但现在远没有快到能 take over 所有；  
2. N8N / Dify 之类的产品在大多数业务场景下依然是好用的。  
3. 相比于全 Agentic 的方案，Workflow + LLM 的方式，反而能让整体方案可能会体验更好和稳定性更好。  
4. Agentic Solution 的方案需要有人来值守，把最后一道关；成本相对更高； Workflow +LLM 的方案算是个中间态，能提供很好的价值。  
5. 对于绝大多数企业来说，先做好 N8N 这种的工作流，处理掉企业内的绝大多数的 Dirty Work ，再去探索 Agentic App 会是更好的解决方案。  
6. 真实世界上的绝大多数业务都还没做好数字化和自动化，直接上智能化容易预期太高出问题。还不如先把数字化和自动化做好，释放人力和精力后再做智能化。不要好高骛远。
