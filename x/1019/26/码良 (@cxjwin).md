# 码良 (@cxjwin)

实操：逼出 AI 专业深度的万金油 Prompt  
  
它的核心是：别让 AI 急着干活，先让它把任务重新定义得更专业（可直接复制使用）：  
"""  
我希望把当前任务做得更深入，而不是简单扩大范围。在开始前请先分析：  
① 该领域最优秀的专家会做哪些我尚未提出要求的工作？  
② 他们会从哪些未经加工的原始数据开始，而非依赖现有汇总？  
③ 他们会使用哪些具体的专业技术、分析方法和工具？  
④ 除了你我的主观判断，有哪些独立证据能证明最终结果正确？  
请基于以上分析，重新设计当前任务。  
"""  
  
这段 Prompt 极适合代码审查、架构设计与故障复盘。
