# Kai (@kqyno7)

人类写的高质量数据快被 AI 榨干了，下一代大模型靠什么继续变强？  
  
最近越来越关注一个方向：RSI（Recursive Self-Improvement，递归自我改进）。  
  
简单说，就是 AI 开始自己教自己。  
  
核心是一个不断循环的飞轮：  
  
① 探索：自己尝试不同解法，生成推理过程。  
  
② 验证：通过数学答案、代码测试等客观标准判断对错。  
  
③ 迭代：从成功的尝试中学习，再挑战更难的问题。  
  
真正的关键不是生成更多数据，而是如何确保生成的数据值得学习。  
  
这也是 RLVR（可验证奖励强化学习）重要的原因。  
  
DeepSeek-R1 已经展示了这条路线的潜力。  
  
不依赖大量人工标注的推理过程，仅通过强化学习和可验证奖励，就能让模型逐步发展出自我反思、纠错和更复杂的推理策略。  
  
OpenAI 的 o 系列同样证明了大规模强化学习在推理能力上的价值。  
  
再看智谱 GLM-5.3。  
  
从 GLM-5.2 到 5.3，基础架构变化有限，但通过 SAO、Slime 和更大规模的 Agent RL，模型在代码和复杂任务上的能力得到明显提升。  
  
这让我反而更期待 GLM-5.5。  
  
如果同一代基础模型，通过更强的后训练就能获得这么大的提升，那么下一步呢？  
  
当然，RLVR 不等于完整的 RSI。模型能否自主发现新问题、可靠验证答案，并持续突破自身能力边界，仍然有很多问题需要解决。  
  
但趋势已经很有意思了：  
  
过去：人类生产知识 → AI 学习。  
  
未来：AI 探索 → 环境验证 → AI 学习 → 更强的 AI。  
  
AlphaGo 通过自我博弈超越了人类棋谱。  
  
大语言模型，会不会也迎来自己的 AlphaGo 时刻？  
  
也许下一轮大模型竞争的关键，不是谁读过更多数据，而是谁更擅长从自己的尝试中学习。
