# Larry  Orbi (@xqliu)

用 agent 写代码，“尽量不 review 代码、放心让它狂奔”，这一步很难，但 Orbi 就是照着这套做的：  
  
· Issue 打 ai-ready，agent 自动接手  
· 每个 issue 独立交付：改代码 + 写测试 + 开 PR  
· 交付后走独立 review（另一个会话审，不是自己审自己），不过就回会话里修  
· orbi status --follow 实时看它干到哪、卡在哪  
  
所以你能按领域抽查，不用逐行盯着代码。  
  
·开源 AGPL-3.0，本地跑 + BYOK：[github.com/orbi-build/orbi](http://github.com/orbi-build/orbi)  
·不想自己搭：Orbi Cloud，[orbi.build](http://orbi.build)
