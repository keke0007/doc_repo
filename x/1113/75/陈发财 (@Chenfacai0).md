# 陈发财 (@Chenfacai0)

把这个项目合集翻完之后，我才意识到 IoT 入门其实用不着四处零散地搜罗案例。  
  
100 天对应 100 个项目，ESP32、ESP8266、树莓派 Pico 全都涵盖在内，每一个项目都附带代码、电路图和说明文档。  
  
内容从基础的传感器读数一直延伸到搭建一个 Web 仪表盘，嵌入式开发里常见的几个方向基本都被覆盖到了。  
  
1⃣ 以 MicroPython 为基础，Python 用户可以直接切入，无需重新学 C  
2⃣ 常用传感器都过了一遍：DHT11、PIR、超声波、气体模块  
  
3⃣ 核心概念不跳步：ADC、PWM、Wi-Fi、WebSocket、蓝牙均有涉及  
4⃣ 场景实用性强：Web 服务器、Blynk IoT、Telegram 通知都有现成方案  
  
5⃣ 支持 Wokwi 仿真，没买硬件也能先在浏览器里跑一遍  
Adafruit、[Hackster.io](http://Hackster.io)、墨尔本 MicroPython 社区都曾推荐过。
