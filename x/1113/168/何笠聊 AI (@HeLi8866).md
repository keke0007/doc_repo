# 何笠聊 AI (@HeLi8866)

是时候和谷歌浏览器说再见了👋！  
  
一位开发者做到了谷歌多年以来未能做到的事情。  
  
他用 Rust 开发了一个浏览器，启动瞬间完成，RAM 消耗减少 10 倍，并自动屏蔽数千个跟踪器。  
  
项目叫 Obscura，用 Rust 写的，专门给 AI agent 和网页抓取用的。  
  
最能打的是：  
  
→ 内存大约 30 MB  
  
→ 页面加载大约 85 毫秒  
  
→ 能屏蔽 3,520 个追踪域名  
  
→ 可按会话换一套浏览器指纹，增加被识别的难度  
  
→ 兼容 Puppeteer、Playwright 和 MCP  
  
→ 能截图、导出 PDF，还能录屏  
  
它是独立的一份二进制，也能直接挂上你的 AI agent 去打开网页、把内容抽出来。  
  
开源引擎是 Apache-2.0，不用花钱。

全球最大的提示词库，现在完全免费开放了！？！  
  
名字叫 [prompts.chat](http://prompts.chat)。  
  
跟网上那些零散的提示词清单不一样，它是目前体量最大的一个，而且一分钱不收。  
  
里面有提示词、技能、工作流和机器人  
  
→ 能按分类搜，直接找到验证过、确认能用的  
  
→ 能存进自己的收藏夹  
  
→ 能提交改进建议  
  
→ 能给好用的条目投票  
  
→ 还能自己部署一套私有库  
  
Claude、ChatGPT、Gemini、Llama 这些模型都能用。  
  
GitHub 上已经 17.6 万星，哈佛和哥伦比亚大学的官网都引用过它。
