# Gk (@0xGky)

一个看 PDF 相当带劲的 Agent Skill：learn-from-materials，它可以把你的几百页资料直接变成一座能互动学习网站。  
  
PDF、Word、网页、PPT、EPUB，通通都能交给它，它会先把材料从头到尾通读一遍、建好知识库，接着再为你生成学习页面。  
  
AI 说出的每一句话，你都能顺着线索查回原始出处。EPUB 能精确到章节、PPT 能精确到第几张、PDF 能精确到页码，不用纠结“这到底是书上原本写的，还是 AI 瞎编的”。  
  
Copilot CLI、Claude Code 以及 Codex 都可以直接装上。
