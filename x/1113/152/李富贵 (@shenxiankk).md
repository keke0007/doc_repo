# 李富贵 (@shenxiankk)

长时间写代码或者做研究的时候，对话上下文动不动就丢，任务状态也很难一直维持住。  
  
Prime Agent 是 PrimeIntellect-ai 推出的开源 Agent，它借助持久化的 REPL 环境，把上下文当成变量来管理，子代理也能像函数那样被调用。  
  
补充提示、记忆和技能说明都被它保存为可以随时更新的状态，于是 Agent 能依据实际证据做小幅度的自我改进。  
  
文件读写、shell 命令、工具调用以及子代理调度全都用代码实现，内置的运行环境是 IPython。  
  
该 Agent 还支持代理之间直接通信、终端断开后任务在后台继续执行、长任务自动压缩、心跳机制定时唤醒，以及只改动补充状态且可以回滚的自我完善。
