# Man ting (@Manorgw)

GitHub 上有个挺硬核的开源项目，叫《网络代理与 VPN 应用详解》。  
  
Clash、Surge、V2Ray、VPN 平时用着，可代理在背后到底怎么跑，一直没弄明白的，这份文档值得翻一翻。  
  
它从代理、隧道、VPN 这些基础原理讲起，再一路讲到 IP/端口封锁、DNS 污染、TCP RST、SSL 连接阻断等网络封锁机制，不少地方还配了图解和实际案例。  
  
想补网络代理底层知识的小白，建议收起来慢慢看。
