# 陈发财 (@Chenfacai0)

CAD 这块阵地，已经被 Agent 拿下了！  
  
有个叫 SolidCraft 的开源项目，能让 AI 亲手摆弄 CAD，直接做出可继续编辑的参数化工程模型。  
  
借助 MCP，它能够做到：  
• 新建零件、调整参数  
• 把机械结构拼装起来、对几何体做检查  
• 输出 STEP、STL 这类工程文件  
• 兼容 Claude Code 与 Codex 的接入  
  
项目免费且开源：
