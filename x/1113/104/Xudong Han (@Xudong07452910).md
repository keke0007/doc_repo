# Xudong Han (@Xudong07452910)

推荐一个挺有意思的开源项目 LearnHarness，感觉可以拿来啃各种难懂的知识。  
  
它会先通过提问摸清你的知识基础，找到理解上的盲区，再用 Agent 规划学习路径，边讲边练，根据你的回答不断调整教学内容。  
  
它的 Memory 设计也很有意思，会把学过的概念和推理关系保存成知识图谱，下次可以接着之前的进度继续学。  
  
用途也挺广，数学、机器学习、编程、物理、经济学、哲学，甚至备考、读复杂的科研论文，都可以拿来试试。  
  
感觉很适合想系统学习一个新领域，又不知道从哪里入手的人，值得收藏研究一下！
