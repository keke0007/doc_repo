# dualface (@dualface)

强规则和工具驱动的 Agent 任务编排系统 [github.com/dualface/kander](https://github.com/dualface/kander) 2.0 已经在路上了。  
  
核心改进：  
  
- 架构改为 client/server 模式，单一项目可以在多个机器上开发，共享同一份任务池，为团队协作提供支持。  
- 引入形式化证明，用于验证复杂的多层状态机。
