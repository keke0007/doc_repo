# 动物园园长 (@weiyux2021)

建议大家都去油管学 AI Agent，真的能打破信息差！  
  
① Jeff Su  
节奏快、实用导向，适合普通人入门。他有大量把 Prompt、AI Agent、工具落地讲清楚的短视频（例如约 10 分钟的 AI Agents, Clearly Explained 播放量很高）。  
  
内容直给，新手跟着做能上手。频道约 190 万订阅，风格轻松实用。  
  
② Andrej Karpathy  
AI 领域真正的大神（前 Tesla AI、OpenAI 等）。他的 LLM 入门/深度讲解视频（1 小时版和更长的 Deep Dive）在圈内刷屏，原理、训练、应用讲得通俗，非技术背景也能跟上。干货密度极高。  
  
③ Tina Huang  
前 Meta 数据工程师/科学家。录有《Building AI Agents In 44 Minutes》《AI Agents Fundamentals In 21 Minutes》等视频，擅长把复杂资料提炼成清晰框架和实操路径，非常适合作为入门第一课。频道约 140 万订阅。  
  
④ Dave Ebbelaar（Datalumina）  
Datalumina 创始人，内容聚焦可落地的 AI 系统工程（生产级 Agent、架构、部署）和 AI 自由职业/创业建议。  
  
实战导向，经验分享多，适合想真正做出系统的人。  
  
⑤ IBM Technology  
IBM 官方频道，覆盖 AI、自动化、DevOps、量子等，常有领域专家讲解。内容广度好，解释相对严谨可靠，像一个小型 AI 知识库。适合建立系统性认知。  
  
⑥ Google Cloud Tech  
Google Cloud 官方频道，更垂直深入（Vertex AI、Agent 相关、NotebookLM、实用工具等）。  
  
如果说 IBM 更“广”，这个更“深”，尤其适合想用 Google 生态落地的人。  
  
⑦ Cole Medin  
强烈推荐做 Agent 实操。重点讲生产级 AI Agent、n8n / LangGraph 全流程构建、本地部署、架构设计。  
  
内容实战、有完整项目和仓库，适合从“会用”进阶到“能做出稳定系统”。在很多“学 Agent 必看”列表里常出现。  
  
⑧ Liam Ottley  
偏商业落地和变现角度。有超长完整指南（如《How to Build & Sell AI Agents》），覆盖无代码/低代码构建、自动化业务、接单卖服务。  
  
适合想把 AI Agent 技能直接变成收入的人。  
  
⑨ Andrew Ng / DeepLearningAI  
Andrew Ng 是 AI 教育与实践的标杆人物。DeepLearningAI 频道有关于 Agentic AI、设计模式（reflection、tool use、planning、multi-agent）的短课程和讲解，质量高、结构清晰。  
  
适合想建立扎实基础并理解“为什么这样设计”的人。  
  
⑩ Nate Herk  
以 n8n + AI Agent 实操闻名，有完整的无代码/低代码 Agent 教程和长视频课程。  
  
非常适合不想先写大量代码、又想快速做出能用的自动化 Agent 的人。  
  
和 Cole Medin、Liam Ottley 互补。  
  
学习建议（快速上手路径）  
  
1.完全新手：Jeff Su + Tina Huang 先建立概念 → 再看 Karpathy 补原理。  
2.想动手做：Tina Huang / Cole Medin / Nate Herk 跟做项目。  
3.想做生意/自由职业：Liam Ottley + Dave Ebbelaar。  
3.想系统扎实：Karpathy + Andrew Ng + IBM / Google Cloud 官方内容。  
  
这些频道大多免费、更新相对及时，能有效打破信息差。  
  
建议先看 1-2 个入门视频确认风格是否适合自己，再深入。  
  
如果有具体方向（比如纯无代码、Python 工程、商业变现），可以再细化推荐。
