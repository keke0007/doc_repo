# 山景城小路 (@Zen_with_AI)

Anthropic 面经：两道题  
  
第一题：Stack Trace  
  
Stack Trace。  
题目给出一组调用栈采样：程序运行时每隔一段时间抓一张快照。要求据此还原每个函数的开始和结束时间。举个例子，三张快照：[main, A]、[main, A, B]、[main, A]。第一到第二张多了 B，说明 B 这时被调用；第二到第三张 B 没了，说明 B 返回了；A 三张都在，起止定不了。思路是比较相邻快照：先找最长公共前缀，没变的是两次采样间没变的调用；前缀之后消失的是返回的函数，新出现的是新调用的函数。逐对比较，拼出每个函数的起止区间。  
  
第二题：Function-cache key 修复 + 持久化  
  
面试会先给你一段现成的缓存代码，一般是一个带缓存的函数或装饰器，里面已经有内存缓存的实现，任务分两步：  
  
第一步是改错。 key 生成函数有 bug，典型毛病是参数没处理全：关键字参数顺序不同、可变参数、默认值、等价调用，算出来的 key 要么撞车、要么该相同的算成了不同。你要读懂代码、找到 bug、把 key 修对。这也是这道题最近还在考的原因。  
  
第二步是扩展成持久化缓存。 进程崩了重启后缓存不能丢。面试级的做法是每次缓存变更都写盘，启动时重放恢复；如果面试官追问，再谈原子写、预写日志、快照这些。  
  
这道题是要“读别人代码、找 bug、再扩展”。
