# Ren (@Ryrenz)

🔨 给想自己造 agent 的朋友翻到一套中文教程 learn-agent，20 章带你从零手搓一个生产级的 AI Agent Harness。  
  
每章一篇文章配一份能跑的 TypeScript 代码快照，README 里记着当前基线 65 个测试文件、429 个测试全部通过。  
  
很多 agent 教程停在“调一次模型、接一个工具”，再往下的权限、记忆、上下文、多 agent 协作，只能自己翻源码猜。learn-agent 从最小的 Agent Loop 起步，每章只加一个能力，一路加到 Worktree 隔离和 MCP，前面章节的行为一个不丢；最后一章把前 19 章的能力塞进同一个 AgentRunner 里一起验证。  
  
教程参考了 learn-claude-code 等公开项目，代码和验收标准是自己写的。离线测试不需要密钥也不需要联网，真要接模型，配好四个 OpenAI 兼容的环境变量就行。  
  
看懂一个 harness 最快的办法，就是亲手搭一个。
