# 旺旺 (@TiagerBao)

还在到处找 Claude 教程？Anthropic 自己把 5 套课程放到了 GitHub，免费开放。  
  
项目已有 2.3 万 Stars，内容从 API 入门一直讲到工具调用和效果评估。  
  
5 套课程：  
  
API 基础：Claude SDK、模型参数、流式输出、多模态  
Prompt Engineering：交互式练习提示词设计  
实际场景应用：复杂任务中的提示词设计  
Prompt Evals：评估提示词效果，验证输出质量  
Tool Use：让 Claude 调用外部工具，接入实际工作流  
  
我更推荐后两部分。  
  
Agent 能调用工具不难，难的是怎么判断它有没有做对，以及修改提示词后效果有没有真正提升。  
  
需要注意，仓库已于 2026 年 9 月归档，部分示例使用旧版 Claude 模型，适合学习原理，实际开发还得参考最新 API 文档。  
  
你觉得开发 Agent 最该先学工具调用，还是先学怎么做 Evals？
