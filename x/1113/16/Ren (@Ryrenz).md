# Ren (@Ryrenz)

🗓️ 又发现一个私人助理神器 Nod：n8n 团队做的，装在你自己电脑上，替你处理 Gmail、日历、Slack 里的杂事，动手前先问你一句。  
  
Nod 上了 Trendshift 日榜，这周几乎一天一版，11 月 12 日一天就从 v0.7.0 更到了 v0.7.1。  
  
以前想让 AI 帮你回邮件、约会议，要么把账号交给某个云端服务，要么自己拿 n8n 拖一整套流程。  
  
Nod 是独立应用，不需要会 n8n。你在应用里、Telegram 或 WhatsApp 上跟它说一句，它去翻 Gmail、对日历、查网页、写进 Notion，真要代表你去做事之前，会先停下来等你点头。在网站上要填密码、验证码、银行卡号时，可以走它的 Vault，这些信息不进模型。  
  
模型自己选，OpenAI、Anthropic、Gemini、OpenRouter 等 20 多家都能接，也能用 ChatGPT Plus/Pro 登录。Nod 本身免费，用 API 的话每个任务花了多少钱都会显示，到了月度上限自动停。macOS 14 以上能装，Windows 11 和 Linux 是预览版。  
  
几点要知道：现在还是研究预览版；应用连接默认走 n8n 托管的连接服务，基本使用数据默认也会共享给 n8n；定时任务只在电脑开着时跑。  
  
AI 替你跑腿可以，拍板这一步还是你说了算。
