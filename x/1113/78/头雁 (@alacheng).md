还有一些类似的小项目，一些最小化机器学习/深度学习相关的研究实现，可以快速学习到这个领域的知识原理：  
  
- minimalRL：minimalRL 是一个用 PyTorch 实现的极简强化学习（RL）算法集合  
[github.com/seungeunrho/mi…](https://github.com/seungeunrho/minimalRL)  
  
- micrograd：纯教学工具，大约 100 行代码实现标量自动微分（autograd），再加约 50 行做一个迷你神经网络库。  
[github.com/karpathy/micro…](https://github.com/karpathy/micrograd)  
  
- nanoGPT：GPT 训练的实际工作原理  
[github.com/karpathy/nanoG…](https://github.com/karpathy/nanoGPT)  
  
- minGPT：Andrej Karpathy 写的一个极简版 GPT 实现，用 PyTorch 重新实现了 OpenAI GPT（Generative Pretrained Transformer）的训练和推理  
[github.com/karpathy/minGPT](https://github.com/karpathy/minGPT)  
  
- tinygrad：tinygrad 是 George Hotz主导开发的一个极简但完整的深度学习框架。  
[github.com/tinygrad/tinyg…](https://github.com/tinygrad/tinygrad)  
  
- llm.c：llm.c 是 Andrej Karpathy 的另一个极简项目，用纯 C/CUDA 实现大语言模型（LLM）的训练，完全不依赖 PyTorch 和 Python  
[github.com/karpathy/llm.c](https://github.com/karpathy/llm.c)
