# 旺旺 (@TiagerBao)

收藏了几百篇文章，半年后想找个知识点，还得重新翻一遍？有人把 Claude Code 做成了个人知识库管理员。  
  
GitHub 上这个开源项目叫 claude-second-brain，把 Claude Code、Obsidian、qmd 和 GitHub 组合到了一起。  
  
主要功能：  
自动整理：丢入文章、PDF、笔记，Claude 提取重点并建立知识关联  
本地搜索：qmd 结合向量检索和 BM25 查找内容  
带出处回答：查询知识库时返回引用，不用重新翻原文  
自动维护：检查失效链接、孤立笔记和知识冲突  
版本管理：通过 GitHub 保存历史记录，支持多设备同步  
  
一条命令初始化：  
npx claude-second-brain  
  
我比较看重它的知识关联和来源追溯。不过 Claude 整理出来的结论也可能有错，重要内容仍得回到原始资料核实。  
  
你更希望 AI 帮你自动整理知识，还是能准确找回几个月前看过的内容？
