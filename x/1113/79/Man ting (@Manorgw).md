# Man ting (@Manorgw)

大模型到底是怎么训出来的？这个开源项目把整套流程都摆到明面上了。  
  
MiniMind用原生PyTorch实现了从预训练到后训练的多种流程，不只教你调用模型，还能直接研究训练代码。  
  
🧠 预训练、SFT、LoRA、DPO  
⚙️ PPO / GRPO、工具调用与Agent强化学习  
💻 代码相对精简，适合边读边跑、动手实验  
项目介绍里提到，64M参数的模型能用较低成本完成训练。不过实际耗时和花费还得看硬件、数据规模和训练配置，宣传数字不能直接照搬。  
要是你想从代码层面弄明白大模型怎么训练，这个仓库值得收着。
