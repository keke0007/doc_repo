# 英俊哥 (@gimcall)

以前程序员想看懂一个陌生的 GitHub 项目，光摸清代码结构就能折腾很久。  
  
现在有了 AI，真没必要再一头扎进代码里瞎摸索。  
  
一个很实用的方法：  
  
第1步：把 GitHub 链接丢给 Claude。  
  
第2步：让 Claude 用 HTML 生成一张项目架构图，先弄清整体结构。  
  
第3步：按照架构图，把项目拆成不同模块，让 AI 一个个解释。  
  
如果不满足于看懂，还想真正掌握，就让 AI 设计一个最小实现。  
  
明确需要写多少行代码，分多少期学完，再自己一行一行敲出来。  
  
这和以前的学习方式完全不一样。  
  
过去得从程序入口往下找，一个函数跳到另一个函数，顺藤摸瓜追半天，最后才能把整个项目拼起来。  
  
现在可以先把全局看明白，再逐步深入，最后亲手实现。  
  
AI 最有价值的地方，不只是帮你写代码，还能帮你更快看懂别人写的代码。
