# 山景城小路 (@Zen_with_AI)

Google 开源插件：大象设计，金鱼评审  
  
Google 开源了一个给 coding agent 用的插件，大象设计，金鱼评审。  
  
大象（Elephant）抱着项目上下文起草设计文档；  
金鱼（Goldfish）评审时看不到之前的对话，只看文档和源码，专门揪那些没说出口的假设和盲点。  
  
支持 Claude Code、Codex、Cursor、Gemini，已有近 1.5 万 star，Apache 2.0 开源。
