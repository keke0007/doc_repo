# Justin3go (@Justin1024go)

暴论：设计SKILL根本没用，用好组件库就够了  
  
一些知名组件库就不推荐了，最近看到的一些小众但很有特色的组件库，手绘纸张、贴纸、黏液、Agent 工作台等等，vibecoding想要做出特色就用这些：  
  
1. Looseleaf：纸张纹理、胶带、手绘图表，还有完整页面区块 [kevintngo.github.io/looseleaf/](https://kevintngo.github.io/looseleaf/)  
2. PlopUI：蓝色马克笔、贴纸头像，按钮按下去还会挤一下 [plopui.com](https://plopui.com)  
3. Inkra：铅笔笔触和淡彩，连日历、地图都带着手绘感 [inkrajs.github.io](https://inkrajs.github.io)  
4. goopUI：会滴落、拉伸的黏液组件，Vue / Nuxt 优先，目前是 [goop.timmcmasters.work/docs/components](https://goop.timmcmasters.work/docs/components)  
5. Solid Glass：克制的玻璃材质，带 Agent 状态、工具步骤和 diff 展示 [deeplethe.github.io/solid-glass/](https://deeplethe.github.io/solid-glass/)  
6. AffectUI：Agent 树、工具调用、审批和 trace；部分付费，图中的 Agent Tree 是 Pro [affectui.com](https://affectui.com)  
7. Prestige UI：React / Tailwind / Motion 动画组件，落地页区块也很丰富，含付费内容 [prestigeui.com](https://prestigeui.com)  
8. BoardUI：主打仪表盘和 AI 工作台，表格、图表、日历到 Agent 聊天都有，整体风格干净克制（含付费组件）[boardui.com](https://boardui.com)
