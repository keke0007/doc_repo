# 旺旺 (@TiagerBao)

Meta 把内部用了 8 年、支撑 1.3 万多个应用的设计系统开源了！  
  
项目叫 Astryx。  
  
不是简单的 UI 组件库，而是一套同时面向开发者和 AI Agent 的设计系统。  
  
主要功能：  
  
》150 多个 React 组件，支持无障碍访问  
》7 套主题，支持深色模式和品牌定制  
》支持 Tailwind、CSS Modules 和普通 CSS  
》提供 CLI、组件文档和现成页面模板  
》支持将组件源码直接导入项目，自由修改  
》AI Agent 可以通过 CLI 获取组件规范，不用猜 API  
  
基于 React 19 和 StyleX，MIT 开源，目前处于 Beta 阶段。  
  
项目地址：  
[github.com/meta/astryx](https://github.com/meta/astryx)  
你们觉得 AI 写前端，最需要的是更强的模型，还是一套规范完整、能直接调用的设计系统？
