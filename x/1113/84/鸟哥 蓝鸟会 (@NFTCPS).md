# 鸟哥 | 蓝鸟会 (@NFTCPS)

牛逼！腾讯刚开源了一个给 Qwen3.8-27B 提速的小模型，叫 DSpine。  
  
它只有5层，一次并行猜16个 token，再交给大模型批量验证。  
  
在办公类 Agent 任务里，输出速度从每秒210个 token 拉到805个，快了3.84倍。  
  
同一测试里，DFlash2 是3.17倍。  
  
Apache 2.0 协议，本地跑 Qwen 的老哥可以直接装上试试。
