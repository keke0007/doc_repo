# AI超元域 (@AISuperDomain)

claude-wiki：让 Claude Code 帮你打造一个能够持续进化的知识库！  
  
它可以将 Word、Excel、PPT、PDF、Markdown、HTML 等文档转换成结构化 Markdown Wiki，通过八阶段流程完成内容提取、校验、消歧、关联、编译和索引。  
  
提问时支持知识库检索、原始文档检索和混合检索，并为事实附上来源标记，确保答案可追溯。  
  
最有意思的是 Dream 机制：分析历史问答，主动发现知识缺口并提出修订，但不会自动合并，必须经过人工审核。  
  
每个 Agent 运行在独立 Git Worktree 和受限权限环境中，还具备成本记录与预算控制。  
  
适合将持续增长的研究资料和项目文档沉淀为可查询、可验证、可迭代的长期知识系统。
