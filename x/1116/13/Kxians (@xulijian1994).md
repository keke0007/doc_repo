# Kxians (@xulijian1994)

发现一个开源项目：LoopX，GitHub 已经 6.6K Stars。  
  
特别适合经常切换多个 AI 编程工具的人。  
  
支持 Codex、Claude Code、OpenCode、Cursor、DSH、Pi 等工具，核心就是让不同 Agent 能够接手同一个项目的任务。  
  
举个例子：  
  
1. 先用 Claude Opus 5.5 做架构设计，确定技术方案。  
2. 换 Codex 负责代码开发，直接接手前面的设计任务。  
3. 最后交给 DSH 跑大规模测试，检查代码质量和功能问题。  
  
LoopX 负责保存整个过程的任务状态、设计决策和交接信息，不用每次换工具都重新解释一遍。  
  
除此之外，还有几个实用功能：  
  
1. 进度保存：关闭会话，第二天还能接着干。  
2. 多 Agent 协作：管理不同 Agent 的任务分工，减少重复劳动。  
3. 人工审批：遇到关键操作，等你确认后再继续。  
4. 自动唤醒：按任务状态和额度决定是否继续执行。  
5. 执行记录：做过什么、下一步干什么，都有据可查。  
  
简单说，AI 编程工具负责干活，LoopX 负责管理任务、进度和交接。  
  
经常混用多个模型、多个编程工具的开发者，可以研究一下。
