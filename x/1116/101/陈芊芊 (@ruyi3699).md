# 陈芊芊 (@ruyi3699)

客户、项目、工时、发票散落在各种工具里，光是把数据同步起来就够喝一壶了。  
  
Ever Gauzy 是一款开源业务管理平台，把 CRM、招聘、人事、库存、项目、工时和开票整合到一块，适合想理顺工作流、压一压 SaaS 开销的小团队。  
  
它基于 TypeScript，支持多租户，能通过 Docker 或 Kubernetes 自托管，数据库支持 PostgreSQL 和 MySQL。  
  
提醒一下，它采用 AGPL-3.0 协议，修改后对外提供服务得留意开源义务。复杂财务或国内合规场景，建议先评估再上生产。
