😱 简直牛逼克拉斯！！  
  
这个项目能让你的 Agent 越用越聪明、越省钱！！  
  
最近开源的 AgentRun，能帮 Claude Code、Codex 这类 Agent 从以前做过的活里学习，并把经验存下来下次再用。  
  
那它是怎么工作的？⬇️  
  
比方说，一个 Agent 做项目时碰上了复杂的技术问题，试了好几轮才找到办法。  
  
AgentRun 会把这些经验记下来、整理好：  
  
- 把已经解决的技术问题，整理成能用的笔记  
- 把成功的方法和解决方案存成 Skills  
- 后面做项目时，可以直接用上以前的经验  
  
但最有意思的是这一段：  
  
一个 Skill 被用过三次后，系统会尝试把它变成 Workflow。  
  
也就是说，Agent 不用每次从零开始再走一遍解题路径，可以直接用一套已经跑通过的现成流程。  
  
结果是什么？  
  
- 少做重复的试错  
- 不用再把已经解决过的问题重新查一遍  
- 省 Token  
- 把成功的经验拿来再用  
- 把零散的经验变成可重复的 Workflow  
  
实际上，AgentRun 就是想把每个项目的经验，变成后面项目能用的资产。
