# 黎晓星 (@Peck1605129109)

我把每天用的 Agent 工作台，改成了只适合我一个人的样子  
  
最近每天打开最多的软件是 Herdr。它是一个 Agent 工作台，可以把 Claude Code、Codex 这些 coding agent 接进来，在一个窗口里同时管好几个会话。  
  
这类工具不少，比如 T3 Code。但 Herdr 和它们不太一样的地方，我觉得是几乎所有东西都能自己改。改起来也很简单，它自带了 skill，我想要什么就直接跟 Claude Code 说，它去改。  
  
这段时间我陆陆续续改了不少地方。先是把侧边栏和右侧的文件展示，按我习惯的方式重新排了一遍。然后加了一个看代码改动的 diff 面板，这样 Agent 改完代码，我也不用切到别的 App，直接在旁边看一眼就能决定收不收。再后来我又加了一个 todo 面板，早上把当天要做的事列进去，做完一件勾一件。最后加了一个随手对话的小窗口，有临时的问题，不用专门开一个新会话。快捷键也全是我自己定的，主题也换成了我看着比较舒服的颜色。  
  
这些功能单拿出来都不稀奇，别的软件里也都有。但以前它们散在四五个 App 里，我每天要在中间跳来跳去，每跳一次还得回想一下刚才在干嘛。现在它们全在一个窗口里，按我的顺序摆好。每天用下来，最明显的感受是摩擦少了很多，效率确实上去了。  
  
而整个过程，我只是跟 Agent 说了几句话。  
  
所以我在想，以后的软件会变成什么样呢。  
  
以前的软件基本都是标准化的。产品团队调研很多用户，取一个大家都能接受的中间值，做出来给所有人用。哪里不顺手，要么忍着，要么换个 App。因为改软件得写代码，而写代码是很贵的。  
  
但现在不管是写界面还是写功能，Agent 都已经做得挺好了。那软件有没有可能反过来，厂商只提供一个底座，把能改的地方都开放出来，剩下的交给每个用户和他自己的 Agent 去折腾。快捷键、主题、布局，甚至要不要加某个功能，都由用的人自己决定。每个人手里用的都是自己想要的那一版，软件也就从标准化慢慢变成个性化。  
  
感觉 DeepSeek 最近做的 DeepSeek Harness 好像也在往这个方向走。我觉得这一步挺有远见的。只要用户能自己动手改，大家改出来的东西就能互相分享，慢慢会长出一个插件生态，长出来的功能可能比官方自己做的还多。  
  
当然，这对做软件的人来说肯定也是个难题，得想清楚哪些地方必须稳定，哪些可以放开。但至少站在用户这边，我感觉自己已经有点回不去了。
