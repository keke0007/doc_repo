# AI探路者Tim (@AIExplorerTim)

shadcn/ui 的作者只让最聪明的 AI 模型做规划，写代码交给便宜模型。  
  
他的技能叫 /improve：  
- 最强模型先审查整个代码库  
- 按值得修的程度排序：bug、速度、安全、测试  
- 给每个问题写一份分步修复计划  
- 把计划交给更便宜的模型去执行  
- 合并前先审查便宜模型的产出  
  
贵的模型只花在"想"上。  
  
怎么用：  
1. npx skills add shadcn/improve  
2. 在项目里打开你的 coding agent  
3. 输入 /improve（想更省钱就用 /improve quick）  
4. 回复"plan 1, 3 and 5"，再运行 /improve execute 001  
  
支持任何带 skills 的 agent。
