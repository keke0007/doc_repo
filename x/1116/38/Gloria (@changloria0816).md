# Gloria (@changloria0816)

周末刚好抽空把 LinkedIn 上的 AI Engineer 岗位翻了下，发现几乎每个 JD 要的都是同一件事：  
  
证明你能让 AI 在生产环境里跑起来，而不只是在 notebook 里跑通  
  
如果想让简历加分，有下面这 15 个项目值得做：  
  
1. 基于 1000+ 份真实文档的 RAG 问答，回答带出处  
2. 能调真实接口完成预订、取消、改期的 Agent  
3. 给现有代码库自动写测试的 AI 编程助手  
4. 能接电话、记录每通对话的语音 Agent  
5. 模型路由：简单问题走便宜模型，难题走强模型  
6. 基于真实商品目录的语义搜索  
7. 把乱七八糟的 PDF 转成干净 JSON 的提取器  
8. 微调一个小模型，在窄任务上打败大模型  
9. LLM 成本追踪，看清每个用户、每个功能花了多少钱  
10. 缓存层，减少重复调用和延迟  
11. Agent 记忆系统，跨会话记住用户  
12. 每次部署前自动跑的评测集，提前抓到效果退步  
13. 追踪面板，看清 Agent 每一步做了什么  
14. 兜底机制：自动重试、切换模型，不让用户看到报错  
15. 红队脚本，专门尝试越狱自己的应用  
  
不用全部做，挑 2-3 个感兴趣的给真正上线的用户用，再把成本、速度、准确率的数据写出来，拿去投简历最起码有点东西写
