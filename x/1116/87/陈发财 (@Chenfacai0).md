# 陈发财 (@Chenfacai0)

我老早就好奇那些专业提示词究竟是怎么琢磨出来的，直到遇见了 Prompt Master。  
  
它能把我随手敲下的一句话，打磨成一份专业的 Prompt。  
  
打个比方，我只说一句：  
  
“帮我做一张高级感的产品海报。”  
  
它会结合你所用的工具，把画面构图、视觉风格、光线、细节要求以及限制条件都补全，整理成一段拿来就能复制的提示词。  
  
不光生图，写代码、做视频、生成网页、复杂的 Agent 任务，它都能针对不同工具产出专业提示词，市面上大部分 AI 基本都能套用。  
  
在我看来最顶用的是它的 Prompt 修复功能。  
  
直接把一段效果拉胯的提示词丢进去，让它挑出哪里表述含糊、缺了哪些条件，甚至还能给编程 Agent 补上文件修改范围和停止条件。  
  
当然，它并不是让 AI 本身变聪明了，只是让喂给 AI 的输入更专业，从而更容易被 AI 理解。
