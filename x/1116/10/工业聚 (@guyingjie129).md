# 工业聚 (@guyingjie129)

Agent 开发背后还是软件开发，很多之前的软件开发范式仍然有效，只不过以不同的面貌和说法示人。  
  
如 Single Source Of Truth 之于上下文工程，避免多拷贝/多来源，以减少冗余和不一致。  
  
如 Do'nt block the main thread 之于 Super Agent、Session Management，让交付会话功率最大化  
  
如不要过度抽象之于最终交付物导向，每个中间岗位、中间材料，都是一个工作交付上的抽象层。  
  
LLM/Agent 让微观编程无关紧要的同时，让宏观编程成为新的显学；人们之前把这类活动叫——架构/管理。
