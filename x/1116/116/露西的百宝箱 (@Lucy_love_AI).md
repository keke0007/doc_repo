# 露西的百宝箱 (@Lucy_love_AI)

1930年，英国语言学家 C.K. Ogden 做了一件很偏执的事：他把整个英语词汇表研究了一遍，然后问，如果只能留下最核心的词，英语还能不能用？  
  
他的答案是：850个词，够了。  
  
这不是随便选的，是他穷尽分析后筛出来的“语言骨架”，分成5类：  
  
1. 100个操作词：这、那、是、有、做，让句子转起来的胶水词  
2. 400个普通事物：名词里最高频、最基础的那层  
3. 200个可描绘事物：能画出来的具体东西，比如 door、fire、river  
4. 100个性质词：描述世界的形容词，比如 clear、simple、important  
5. 50个反义词：成对出现，学一个等于学两个  
  
他把这套体系命名为 Basic English。  
  
丘吉尔在二战期间公开赞扬过它，认为这是盟国推广英语教育的最佳基础。H.G. 威尔斯把它写进了《世界大战》的续集设定，当作未来世界通用语言的蓝图。乔治·奥威尔没有赞扬，但《1984》里那套压缩语言“新话”的灵感，正来自他对 Basic English 的警惕——他担心语言被缩减之后，人的思想也会跟着被缩减。  
  
支持者觉得它是桥梁，批评者觉得它是枷锁，这场争论持续了将近一百年。  
  
但真正值得注意的是：这850个词，对今天的英语学习者意味着什么。  
  
大多数人学英语，是被一本本厚词汇书和无尽考纲压着学的。CET-4、CET-6、托福、雅思，每个证书背后都是几千个词的暴力记忆，背了忘，忘了背，从来没有真正“用”过。  
  
Ogden 的逻辑相反：不是多，而是深。  
  
这850个词，每一个都是高频中的高频，每一个在日常表达里都有不可替代的位置。真正学透，不只知道意思，还知道用法、知道近义词在什么场景该用哪一个，比背了5000个词却只认识中文意思要扎实得多。  
  
根扎得够深，枝才能生得够远。  
  
有人据此做了一个网站：[ogden.munch.love](http://ogden.munch.love)，免费，不用注册，不收集信息。  
  
原版 Ogden 的资料是一本黑白PDF，排版像上个世纪。这个网站把它变成了能直接用来学习的东西：  
  
每个词一张卡片，上面有中文释义、用简单英语解释英语的英文定义、一句真实语境下的例句，以及2到3个同义词。五个类别各有自己的颜色，一眼就知道在学哪个区域的词汇。  
  
每个词都能听发音，接的是有道词典的语音接口，默认英式，可切美式，语速比正常稍慢，适合跟读。  
  
同义词那部分花的心思最多。很多人背单词时，同义词只是“差不多的意思”。但真正用英语的时候，difference 和 distinction 不一样，speak 和 talk 不一样，simple 和 easy 不一样。差在哪里，什么场景该用哪个，这里做了区分。  
  
如果你身边有正在学英语的人，或者觉得自己英语学了很多年但还是用不好，可以发给他们看看。  
  
也许这850个词，是一个值得重新开始的起点。
