# 【科技产业链的隐形冠军06】机器人只是开始，工业自动化真正的核心是这7个环节！

*By LaoC (@AISparkGarden)*

![Banner](<【科技产业链的隐形冠军06】机器人只是开始，工业自动化真正的核心是这7个环节！.assets/image-01.jpg>)

# 很多人谈工业自动化，首先想到的是工业机器人。

但真正决定一条生产线能不能高效、稳定、精准运行的，远不只是机器人本身。

从控制器、PLC，到伺服驱动器、电机，再到机器视觉和工业软件，这些看起来不起眼的设备和技术，构成了现代智能工厂的底层基础。

随着制造业设备更新、国产替代，以及AI与工业生产融合，工业自动化正在从单一设备升级，走向整套智能制造系统升级。

这条产业链上，哪些企业值得研究？

## 一、先看懂工业自动化产业链

工业自动化可以简单理解为五个层级：

**1. 控制层：**

相当于工厂设备的大脑。

主要包括PLC、PAC、DCS、运动控制器、工业控制系统等，负责接收指令、处理逻辑、协调设备运行。

**2. 驱动层：**

负责让电机按照要求运行。

主要包括伺服驱动器、变频器、步进驱动器等。

**3. 执行层：**

负责真正完成运动和动作。

包括伺服电机、步进电机、直线电机、精密传动装置等。

**4. 感知层：**

负责让设备看得见、测得准。

包括工业相机、视觉传感器、光源、测量系统和各类工业传感器。

**5. 软件与系统层：**

将设备、生产线和工厂连接起来。

包括工业软件、MES、工业互联网、数字孪生和工业AI解决方案。

这五层不是完全独立的。未来真正有竞争力的企业，往往不只是卖一个零部件，而是能够提供软硬件结合的整体解决方案。

## 二、7家值得关注的产业链企业

1. 汇川技术（300124）

**产业位置：工业自动化综合平台型企业**

如果只选择一家代表中国工业自动化产业链，汇川技术是绕不开的企业。

公司覆盖变频器、伺服系统、PLC、HMI、工业电机及运动控制等产品，同时布局新能源汽车动力系统、机器人和数字能源。

它的优势不只是单一产品，而是多品类产品组合、行业解决方案、客户服务和规模化交付能力。

2026年前三季度，公司营业收入约379.56亿元，同比增长19.88%；归母净利润约43.98亿元，同比增长3.38%。

其中，工业自动化与数字化业务收入约199亿元，同比增长27%；通用自动化业务收入约159亿元，同比增长33%。

**研究重点：** 伺服系统、变频器、PLC的市场份额和盈利能力，以及机器人和数字能源新业务的商业化进展。

特别注意：公司总收入还包括新能源汽车动力系统业务，不能把全部收入都当成工业自动化收入。前三季度扣非净利润仅增长约0.49%，利润增长明显低于收入增长。

2. 雷赛智能（002979）

**产业位置：运动控制核心部件**

运动控制是工业自动化的核心环节之一。

设备要实现精准定位、速度控制、多轴协同，就需要运动控制器、驱动器和电机之间紧密配合。

雷赛智能主要布局控制技术、步进系统和伺服系统，应用于自动化设备、半导体、光通信、高端机床等领域。

2026年前三季度，公司营业收入约19.09亿元，同比增长46.77%；归母净利润约2.99亿元，同比增长86.80%。

其中，伺服系统收入约10.08亿元，同比增长58.64%。

公司还在泛人形机器人领域拓展无框力矩电机、灵巧手、关节模组等核心零部件。

**研究重点：** 伺服系统收入增长、半导体和高端机床客户拓展，以及机器人相关产品能否从订单突破转化为稳定收入。

3. 禾川科技（688320）

**产业位置：伺服系统、PLC与工业控制**

禾川科技的特点，是围绕工业自动化核心部件构建产品体系。

主要包括伺服驱动器、伺服电机、PLC、变频器、工业机器人及运动控制产品。

公司重点覆盖锂电、CNC、激光、半导体等高端装备行业。

2026年前三季度，公司营业收入约10.37亿元，同比增长41.61%；归母净利润约2305万元。

但需要注意，前三季度扣非归母净利润约464万元，第三季度单季扣非净利润为负。

公司披露，锂电、CNC、激光等下游行业订单增长，是收入提升的重要原因。

**研究重点：** 高端伺服产品放量、PLC国产替代、盈利能力修复，以及人形机器人核心部件能否形成实际商业收入。

特别注意：营收增长不等于利润同步增长，禾川科技目前仍需要观察盈利质量。

4. 伟创电气（688698）

**产业位置：变频器、伺服系统与电机驱动**

伟创电气主要产品包括变频器、伺服系统、运动控制产品，并向机器人及具身智能相关产品拓展。

变频器主要解决电机调速和节能控制问题；伺服系统则更加关注位置、速度和转矩的精准控制。

公司2026年前三季度营业收入约15.95亿元，同比增长18.15%；归母净利润约1.75亿元，同比下降22.15%。

其中，工业自动化产品收入约14.07亿元，同比增长11.64%；具身智能产品收入约4789万元，同比增长215.01%。

**研究重点：** 海外市场拓展、伺服产品结构、具身智能产品商业化，以及收入增长能否重新带动利润增长。

特别注意：具身智能业务增速较高，但目前规模相对有限，不能把高增长率直接理解为已经形成主要利润来源。

5. 鸣志电器（603728）

**产业位置：步进电机、运动控制与精密电机**

工业自动化设备要完成精准运动，离不开电机和驱动系统。

鸣志电器长期布局步进电机、伺服电机、运动控制器、无框电机、空心杯电机及直线运动产品。

其优势在于电机产品种类丰富，并拥有海外市场和客户基础。

2026年前三季度，公司营业收入约24.80亿元，同比增长21.40%；归母净利润约1.00亿元，同比增长101.05%；扣非归母净利润约9269万元，同比增长110.26%。

经营活动现金流净额约1.39亿元，同比增长24.42%。

**研究重点：** 高端运动控制产品、空心杯电机和无框电机的市场拓展，以及机器人相关产品能否贡献持续性收入。

需要注意，公司业务还包括智能照明等其他板块，不能把全部收入都归入工业自动化。

6. 奥普特（688686）

**产业位置：机器视觉与工业感知**

如果说伺服和电机负责让机器动起来，那么机器视觉负责让机器看得见。

奥普特主要提供工业相机、工业镜头、光源、视觉软件、3D视觉和测量系统等产品。

这些产品广泛用于工业检测、定位、测量、识别和自动化生产线。

2026年前三季度，公司营业收入约13.86亿元，同比增长36.95%。

其中，半导体行业收入约2.02亿元，同比增长257.47%；AI系统解决方案收入约3.01亿元，同比增长157.02%。

**研究重点：** 半导体和汽车行业客户拓展、AI视觉解决方案收入增长、产品标准化，以及从单一视觉部件向系统解决方案升级。

但需要区分：AI系统解决方案收入不等于全部来自AI制造，也不能直接理解为AI服务器业务收入。

7. 中控技术（688777）

**产业位置：流程工业自动化与工业AI**

前面几家公司更多关注设备、运动控制和机器视觉。

中控技术则更偏向大型工业生产过程的自动化控制。

它的核心产品包括DCS集散控制系统、SIS安全仪表系统、PLC、工业软件和工业AI解决方案。

典型应用场景包括石化、化工、电力、制药等流程工业。

2026年前三季度，公司营业收入约55.06亿元，同比下降2.62%；归母净利润约1.46亿元，同比下降66.26%；经营活动现金流净额约-8.47亿元。

值得关注的是，公司披露2026年前三季度工业AI业务实现收入约6.19亿元。

**研究重点：** 工业AI收入能否形成持续增长、DCS和SIS核心产品竞争力、项目交付效率，以及应收账款和经营现金流改善。

这家公司特别值得提醒：工业AI有成长空间，但目前财务数据仍然承压，不能只看新业务概念。

## 三、真正的技术壁垒在哪里？

工业自动化不是简单地把零件组装起来。

真正的竞争壁垒主要体现在五个方面：

**1. 控制算法**

伺服控制、多轴协同、实时控制和运动规划，直接影响设备精度和稳定性。

**2. 核心部件自主能力**

电机、驱动器、编码器、控制芯片等核心部件的自主研发能力，决定产品性能和成本控制能力。

**3. 行业工艺理解**

同样是伺服系统，用在锂电设备、半导体设备和数控机床上，应用要求可能完全不同。

**4. 客户验证与长期运行**

工业客户更重视设备稳定性、兼容性、维护成本和长期服务能力。进入客户供应链只是第一步，长期稳定运行更重要。

**5. 软硬件一体化**

未来竞争不只是卖控制器、驱动器和电机，而是提供完整的自动化解决方案。

## 四、研究这7家公司，重点看5个指标

1. **核心产品收入：** 伺服、PLC、变频器、视觉等业务是否真正增长？
2. **国产替代：** 是否进入高端设备客户供应链？是否能够持续批量交付？
3. **客户质量：** 是否形成长期合作，而不只是单次项目？
4. **盈利质量：** 毛利率、扣非净利润和经营现金流是否同步改善？
5. **新业务兑现：** 机器人、工业AI等业务是否形成真实收入和利润？

## 五、最后一个判断

工业自动化不是一个短期题材，而是制造业长期升级的基础设施。

AI、机器人、半导体设备、新能源制造，都需要更高精度、更高效率、更智能的自动化系统。

但这并不意味着所有工业自动化企业都能同步受益。

有些企业已经拥有成熟产品和规模化客户，有些仍处于新产品拓展阶段；有些收入增长较快，有些利润和现金流还在承压。

**真正值得长期跟踪的，是那些能够把技术、产品、客户和行业工艺结合起来，并持续转化为利润的企业。**
