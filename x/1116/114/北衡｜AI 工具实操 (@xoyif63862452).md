# 北衡｜AI 工具实操 (@xoyif63862452)

飞书生态，终于有一份官方给人和 Agent 共用的命令行了。  
  
larksuite/cli，MIT，GitHub 约 1.8 万星。不是第三方封装，是飞书团队自己维护的官方 CLI。  
  
以前让 Agent 操作飞书，要么自己抠开放平台文档，要么东拼西凑几个 MCP。现在装好就能让它管日程、文档、表格和消息。  
  
核心能力：  
覆盖日历、消息、文档、多维表格、邮件、会议等 18 个业务域  
200+ 条命令，人和 Agent 都能直接调用  
26 个开箱即用的 Agent Skill（日历、文档、审批、会议纪要…）  
三层调用：快捷命令、平台 API、以及 2500+ 原始接口  
命令按真实 Agent 测过，默认结构化输出  
钥匙存在系统钥匙串，支持用户/机器人身份切换  
三分钟从安装到第一条命令  
  
真正有用的是：它把飞书从「人点来点去的办公套件」，变成了 Agent 能稳定调用的工具层。  
  
在飞书里写文档、排日程、管多维表格的，值得直接装上试。
