# 张立行 (@bylixing)

这期十字路口的年度复盘对谈还是有蛮多有意思的点，和 gpt 大聊特聊之后的一些想法：  
  
1. Eval 是判断 AI 多快覆盖一个领域的重要因素。  
  
我们知道，模型的进化本质上离不开目标函数。只要目标能被清晰定义，并且可以低成本地获得可靠反馈，就能通过强化学习、爬山算法之类的方式不断优化。  
  
访谈里给了一个很好的标准：客观、自动化、低成本。  
  
数学和 Coding 为什么这么快被扫到？我觉得很重要的一个原因，就是它们的 Eval 成本相对太低了。  
  
顺着这个逻辑，其实可以往外推很多东西。  
  
比如 AI for Medicine。AI 可以快速生成大量候选药物，但药效、安全性这些东西，最终还是得靠实验验证。模型跑得再快，也绕不开物理世界的成本。  
  
突然想到 TK 教主之前说的「低猴权优势」，虽然听起来有点黑色幽默，但背后确实是实验伦理、成本和效率之间的取舍。当然，实验便宜不代表结果一定可靠。  
  
这个框架对个人择业也挺有启发。  
  
一方面，如果想最大化 AI 的杠杆，就可以去看哪些行业的 Eval 比较容易建设，或者下一阶段验证成本会大幅下降。  
  
另一方面，如果想尽量躲开这波浪潮，可能就要找那些 Eval 很难建设，同时物理执行也很复杂的领域。比如昨天聊到的非标蓝领，或者更复杂的辗转腾挪、攒局。  
  
当然，Eval 难不代表一定不会被替代，也不代表收入就高。但至少提供了一个新的观察角度。  
  
2. 多 Agent 协作，某种程度上就是面向 Agent 的组织管理学。  
  
这一点我自己感受还蛮深的。  
  
人和 Agent 在协作过程中，实际上会很快遇到传统组织演变过程中出现的各种问题。  
  
比如分工、授权、验收、资源分配、信息传递，以及管理者自身的偏见。  
  
你越用，感觉会越深。  
  
所以访谈里从开源社区的 BDFL（仁慈的独裁者），聊到审美偏好，再聊到《大明王朝1566》和《万历十五年》，我觉得还挺有意思。  
  
因为人类组织和 Agent 组织，在某些方面确实存在同构。  
  
当然，也不能完全照搬人类管理学。  
  
有些问题的根源是人的注意力有限、信息不对称。这些在 Agent 系统里同样存在。  
  
但有些问题来自人的欲望、情绪、利益和专业身份，当前 Agent 并没有这些东西。  
  
甚至还有个挺有意思的反差：  
  
人类组织里，管理者可能担心员工不听话；Agent 组织里，有时候反而要担心 Agent 太听话，把一个有问题的目标执行得非常彻底。  
  
而且 Agent 组织还有个优势，很多管理制度可以直接变成代码，比如权限隔离、审计、交叉验证、回滚。  
  
所以，我们在学习人类的组织管理学的时候，要拆开看，哪些是基于人类心理做的管理，哪些是基于组织协作做的管理。  
  
3. UBI，以及 AI 时代人的经济自由。  
  
访谈里提到江西低保女孩去看演唱会，引发低保资格争议的事情。  
  
之前看到这个新闻，我其实没什么特别的想法。但放到 AI 时代的 UBI 语境下，突然觉得这个问题还挺现实的。  
  
诚然，低保和 UBI 不是一回事。前者需要资格审查，后者原则上是无条件的基本收入。  
  
但它们有一个相似的问题：当你的基本生活需要依赖某种分配机制时，你的自由会不会受到资源分配者的约束？  
  
你可以享受基本的物质生活，但如果想要更多，或者想做一些不被认可的事情，会不会受到各种条条框框的限制？  
  
更麻烦的是，随着 AI 能力增长，大部分人可能逐渐失去通过劳动获得更高收入的能力。  
  
以前你不满意，还可以换工作、提升技能，想办法获得更多收入。  
  
如果未来 AI 在绝大部分智力和体力工作上都比人强，那普通人还能靠什么获得经济自由？[zj1123581321.com/posts/260315-a…](https://zj1123581321.com/posts/260315-ai-%E6%97%B6%E4%BB%A3%E9%97%B2%E8%A8%80%E5%87%A0%E5%88%99-%E6%AD%A3%E6%96%87%E7%A8%BF/)  
  
当然，按劳分配也不意味着天然自由。真正的问题可能还是：AI 创造的财富归谁所有，谁掌握分配权，以及普通人有没有拒绝和退出的能力。  
  
4. 不做优绩主义者，给 AI 提供一些「糟糕的 Context」。  
  
这个第一眼看的时候，我都愣了一下。  
  
因为我之前一直在做的事情，就是尽可能给 AI 提供完整的 Context。  
  
日常对话、行为记录、身体数据、屏幕记录之类的，能收集的尽量收集。希望 AI 越来越了解我，进而更好地辅助自己的工作和生活。  
  
但我理解的赵晨阳这里的想法（不一定准确），某种程度上反过来了。  
  
既然 AI 未来可能比人更擅长做出最优决策，那人为什么还要执着于把自己活成一台追求最优解的机器？  
  
不如允许自己犯错，做一些不那么正确的决定，给 AI 提供一些「糟糕的 Context」。  
  
这又让我想起之前在 [x.com/bylixing/statu…](https://x.com/bylixing/status/2106757373834780723) 里提过的「闻过则喜」。  
  
所有错误都可以成为复盘和改进的材料。  
  
但再往前想一步，可能不是所有错误都需要纠正，也不是所有决定都需要优化。  
  
突然想到德州扑克。  
  
随着博弈论和各种求解器越来越成熟，顶尖选手的策略越来越接近数学意义上的最优解。  
  
长期收益可能更高了，但大家也越来越像机器人。过去一些非常有个人风格、激动人心的场景，可能反而越来越少。  
  
人生其实也类似。  
  
如果所有决定都让 AI 帮忙计算最优解，那最后是不是也会越来越像个机器人？  
  
（此处又想到了《极速风流》和延迟满足的张一鸣）  
  
所以这次倒是补充了一个新的思路：  
  
给 AI 提供完整的 Context，是为了让它更理解你，而不是让它把你的人生也优化成一个标准答案。  
  
有些事情确实需要最优解，有些事情可能只是自己想体验一下。  
  
5. 关于寿命，以及 Work-Life Balance。  
  
从目前生物学的发展来看，我自己倾向于认为，性价比很高的一件事就是尽可能保持健康，多活一段时间。  
  
因为未来医学可能会有很大的突破。  
  
如果能活到科技解决更多疾病的那一天，可能就有机会继续活得更久。  
  
当然，这件事有很多不确定性，前提也是你自己想活那么久。  
  
但反过来，如果为了未来可能发生的事情，把现在的生活全变成等待，好像也没什么意思。  
  
包括 Work-Life Balance，我觉得本质上也是个人取舍。  
  
有些团队工作和生活完全不 Balance，但人家可能就是享受工作，享受创造，享受折腾各种东西。  
  
只要自己觉得值，也没什么问题。  
  
毕竟每个人的目标函数都不一样。  
  
6. Computer Use，之前更多考虑能力，这次倒是注意到了成本。  
  
这个领域我之前一直在关注，包括怎么让 Linux 上的 Agent 远程操作 Windows、Mac、手机，完成自动化验证。  
  
但之前主要考虑的是能力和架构，没有太重视 Token 成本。  
  
这期访谈提到 KV Cache，倒是给了我一个提醒。  
  
如果每一步都通过截图，让模型重新理解整个屏幕，成本可能相当高。  
  
而如果能通过代码、系统 API、Accessibility Tree 等方式进行操作，很多时候可以减少视觉 Token 和重复推理。  
  
进一步则是能够把一系列操作写成脚本，直接执行，最后只返回关键结果。  
  
总体来说，真正值得优化的，可能是完成一次可靠的自动化验证，需要多少成本。  
  
这个点又和最开始聊的 Eval 联系起来了。
