# Ren (@Ryrenz)

🏫 想把 AI agent 真正做上线的看这里，Agentic System Course 用 22 章讲透生产级 agent 怎么设计、搭建和运维。  
  
Agentic System Course 的 fork 已经接近一百个，而且整套课是写给你和你的 AI 一起读的，仓库里同时放了 AGENTS.md 和 CLAUDE.md。  
  
以前学 agent 开发，要么跟着某个框架的教程一步步敲，换个技术栈就全废；要么零散看博客，记忆、多 agent 协作、成本控制各讲各的。  
  
这门课只给骨架：把记忆与状态、多 agent 协调、外部接口、可观测性、成本与延迟、安全运维这些承重的主题和取舍讲清楚，具体代码交给你的 AI 按你的技术栈去补。最后一章是一张设计画布，直接拿来设计你自己的 agent。  
  
还有个顺手的：仓库自带一个评审 skill，把你的 PRD、设计文档或 agent 代码丢给它，它先判断你做的是个人项目、团队工具还是面向客户的产品，再挑相关章节出报告，每条问题都带严重程度、证据、章节出处和修复建议。课程拿 OpenCode、Hermes Agent、OpenClaw、Paperclip 四个开源项目当参考实现。  
  
用 agent 学 agent，这个思路挺对味。
