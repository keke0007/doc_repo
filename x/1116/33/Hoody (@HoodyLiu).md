# Hoody (@HoodyLiu)

工业界现状就是 LLM 训练 recipe，尤其是 post-training 已基本成熟，算法创新越来越少，模型提升几乎全靠数据  
  
post-training 团队实际工作大量是在处理各类 RL 环境、轨迹、高质量数据等  
  
数据供应商除了一些知名的比如 Scale AI、Mercor 等还在雇佣真实专家标注，其余中小公司、个人几乎全做合成数据  
  
从技术视角看，数据生意没有门槛。门槛在于人脉关系，你能不能把这门生意做进去
