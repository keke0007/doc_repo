# porco (@SeanchenZ)

AI 发展越快，越多人陷入一种奇怪的焦虑：今天怕被 AI 取代，明天怕错过 Agent，后天又觉得必须学编程。收藏了几十张学习路线图，GitHub Star 了一堆项目，课程越买越多，方向却越来越模糊。最讽刺的是，每天都在接触新知识，却说不清自己究竟掌握了什么。  
  
看到这张 20 天 DevSecOps 学习路线图，我反而觉得，大多数人缺的不是学习资源，而是一个真实的问题。我最近在做 Knowledge OS，需要手机连接知识库、检索设备故障、记录现场反馈。遇到部署问题就研究 Docker，遇到数据问题就研究 PostgreSQL，想减少代码修改带来的故障，就学习 GitHub Actions。不是先学完所有技术再做项目，而是让项目暴露自己的知识缺口。  
  
学习应该像工程系统一样建立反馈闭环：问题 → 学习 → 实践 → 验证 → 修正。 不要用收藏量衡量知识储备，不要用课程完成率欺骗自己。AI 时代最危险的可能不是学得慢，而是一直在学习，却从来没有真正解决过一个问题。
