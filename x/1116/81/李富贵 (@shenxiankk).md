# 李富贵 (@shenxiankk)

Agent 已经能调用接口了，可后台那些老问题依旧摆在那儿：谁有权操作什么、有没有动过、出了岔子能不能查。  
  
ApeAdmin 是个基于 FastAPI + Vue3 的开源中后台，采用 MIT 协议，仓库里明确写了针对 Agent 调用做过适配，底座自带 RBAC、审计日志、菜单和部门管理。  
  
我自己没实际搭过。看上去它并非又一个纯 CRUD 的皮囊，而是想把权限与审计同 Agent 的出口放在一处。  
  
项目还比较新，坑多半出在文档和插件成熟度上，而不在宣传口号。  
  
已经有跑顺的后台、只差贴个聊天框的，没必要换。从零做带 Agent 的管理端、又想让权限先站住脚的，可以打开仓库看看。
