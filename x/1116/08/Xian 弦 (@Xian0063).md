# Xian | 弦 (@Xian0063)

周末给大家分享几个资源，如果你也想把产品做的更好看，这些网页和Demo快看看～  
  
覆盖了界面设计、交互动效、组件参考和视频制作。里面既有 Skills，也有能直接使用的组件库2👇  
  
1、[21st.dev](http://21st.dev) — 给 AI 一个明确的界面参考（[21st.dev](https://21st.dev)）  
  
可以浏览组件、模板和主题，再复制对应提示词交给 AI。比反复描述“高级感”，更容易表达清楚自己想要的样子。  
  
2、Impeccable — 给 AI 补上设计指导（[impeccable.style](https://impeccable.style)）  
  
提供排版、配色、布局和设计审查等能力。适合页面已经能跑，但视觉层级、留白和细节还需要打磨的时候。  
  
3、React Bits — 找到效果，再拿走源码  
（[reactbits.dev](https://reactbits.dev)）  
  
文字动画、动态背景、交互组件、微交互，都有可预览的效果。适合给产品首页、作品集和创意 Demo 增加记忆点。  
  
4、Motion — 把交互手感做细（[motion.dev/ai-kit](https://motion.dev/ai-kit)）  
  
支持布局过渡、滚动联动、拖拽和手势动画，适用于 React、Vue 和 JavaScript。适合让静态界面变得自然、连贯。  
  
5、Remotion Skills — 把产品演示做成视频  
  
官方为 AI 编程助手提供的视频制作 Skills。适合用代码制作产品介绍、动态图表和功能发布短片。  
  
6、[skills.sh](http://skills.sh) — 继续寻找适合自己的 Skills（（[skills.sh](https://skills.sh)））  
  
一个可以搜索和发现 Agent Skills 的目录。找到具体需求后，可以顺着作者和项目继续挖掘相关技能。  
  
如果一开始你不知道怎么做，可以先从一个简单的任务开始：（按照这个方法借鉴一下👇）  
需要组件参考 → [21st.dev](http://21st.dev)  
页面需要打磨 → Impeccable  
想加视觉动效 → React Bits  
想做好交互细节 → Motion  
要输出演示视频 → Remotion  
想继续找技能 → [skills.sh](http://skills.sh)
