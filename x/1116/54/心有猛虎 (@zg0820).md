# 心有猛虎 (@zg0820)

《LLM 到底是怎么被造出来的》｜Karpathy 1044 万播放的三小时深潜，中文地图  
  
Andrej Karpathy《Deep Dive into LLMs like ChatGPT》1044 万播放，3.5 小时讲完整训练栈。原视频：[youtube.com/watch?v=7xTGNN…](https://youtube.com/watch?v=7xTGNNLPyMI)  
  
我按「每一层解释了什么现象」重排，帮你决定哪几段值得看。  
  
**1. 预训练数据（01:00）与 tokenization（07:47）**  
先抓互联网语料，再切成 token。这一层解释了最反常识的一类问题：模型不会拼单词、数不清字母、对奇怪格式敏感——**根子在分词，不在「笨」**。  
动作：拿一段中文去数 token，理解为什么长文档会截断、为什么同样字数不同语言成本不同。  
  
**2. 神经网络 I/O 与内部（14:27–26:01）**  
输入 token 序列，输出下一个 token 的概率分布。它不「查答案」，是逐 token 预测。理解这一层，你就不会指望它给出确定事实。  
  
**3. 推理（26:01）与 base model（42:52）**  
基座模型只会续写，不会对话。让它变成助手的是下一层。  
  
**4. 后训练：对话数据（01:01:06）**  
用大量人类对话做微调，才有了「助手」人格。这也解释了为什么模型会顺着你说——它被训练成「像助手」，不是「像真相」。  
  
**5. 幻觉、工具、记忆（01:20:32）**  
幻觉来自「没有依据也要预测下一个 token」；工具调用和上下文是外挂的补救。**模型不是知道，是在生成。**  
  
**6. 模型需要 token 来思考（01:46:56）与锯齿智能（02:04:53）**  
让它一步步写，等于给它更多计算步；不给，就要它一步到位。所谓「锯齿智能」——能解竞赛题却数不清字符——是这套机制的必然副作用。  
  
**自测清单**：① 遇到拼写/计数翻车，你会怪分词还是怪模型？② 需要事实时，你给了检索工具还是让它硬答？③ 复杂问题你让它分步了吗？④ 你有没有把「像助手」当成「说得对」？  
  
**能带走的**：把 LLM 当成「被训练成助手的 token 预测器」，大多数怪现象都能解释，也就知道该在哪一层加护栏。
