# Su (@Sukiea1008)

腾讯开源了一个 AI 编程协作工作台：LoopForge。  
  
把需求丢给它，就可以在同一个工作流里安排 Codex、Claude Code 或 CodeBuddy 分工：写代码、跑脚本、检查结果，最后提交 PR。关键节点还可以停下来等人审核，不满意就退回重做。  
  
一次跑通的流程，也能保存成 SOP。以后遇到类似需求，不用每次从头指挥 AI，按流程再跑一遍就行。  
  
它不是另一个编程模型，而是给现有 Coding Agent 补上角色分工、沙盒、审核和交付记录。支持私有部署，也有适合个人使用的本地工作流。
