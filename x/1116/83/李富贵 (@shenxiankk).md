# 李富贵 (@shenxiankk)

过去想在本机微调大模型，往往得去租 A100 这类卡。  
  
现在 Unsloth 推出了桌面端 App，在消费级显卡上就能跑训练，速度差不多提升一倍，显存占用下降约七成，精度基本没有损失。  
  
主流模型它基本都覆盖到了，Qwen、Kimi、MiniMax、Gemma、DeepSeek、FLUX 都在支持之列。  
  
训练方式从轻量 LoRA、QLoRA 一直到全量微调，RL、GRPO、DPO、FP8 这些也都有。  
  
App 覆盖 Windows、macOS、Linux 三个平台，AMD 和 Intel 的显卡同样能用。  
  
训练完成后可以导出 GGUF 或 FP8，还能开启 OpenAI 兼容接口，直接作为本地后端接入 Claude Code、Codex。
