# Elara (@Elara200410)

别人还在手动刷闲鱼、回消息、盯订单的时候，有人已经用 AI 24 小时帮自己捡漏、接单、找货源了。  
  
GitHub 上这 6 个开源项目，每一个都能让闲鱼运营效率翻倍。  
  
1、ai-goofish-monitor — 实时监控 + AI 筛选  
基于 Playwright + AI 的闲鱼多任务监控系统。  
用自然语言创建监控任务，AI 自动分析商品质量。  
支持多任务并发、定时调度、企业微信/Telegram 多渠道通知。  
Docker 一键部署。  
→ [github.com/usagi-org/ai-g…](http://github.com/usagi-org/ai-goofish-monitor)（13K+ stars）  
  
2、XianyuAutoAgent — 智能客服机器人  
专为闲鱼打造的 7×24 小时 AI 值守方案。  
多专家协同决策：议价专家、技术专家、客服专家自动切换。  
支持阶梯降价策略、上下文感知对话。  
→ [github.com/shaxiu/XianyuA…](http://github.com/shaxiu/XianyuAutoAgent)  
  
3、xianyu-auto-reply-fix — 多账号运营神器  
一个功能完整的闲鱼管理系统。  
多账号管理、关键词回复、AI 自动回复、自动发货、商品管理。  
支持一键批量擦亮商品、定时擦亮。  
→ [github.com/GuDong2003/xia…](http://github.com/GuDong2003/xianyu-auto-reply-fix)  
  
4、xianyu_spider — 商品数据采集  
基于 FastAPI + Playwright 的闲鱼商品搜索接口。  
异步并发爬取，智能去重，数据持久化存储。  
适合做市场分析、找爆款、比价。  
→ [github.com/superboyyy/xia…](http://github.com/superboyyy/xianyu_spider)  
  
5、Playwright — 自动化基础设施  
微软出品的浏览器自动化框架。  
上面几个闲鱼项目底层都在用它。  
自己写自动化脚本的首选。  
→ [github.com/microsoft/play…](http://github.com/microsoft/playwright)  
  
6、Browser Use — AI 驱动的浏览器操控  
一句话让 AI 帮你操作浏览器。  
自动找货、筛选商品、整理信息。  
适合搭建闲鱼 Agent。  
→ [github.com/browser-use/br…](http://github.com/browser-use/browser-use)  
  
以前做闲鱼拼的是时间。  
现在拼的是自动化程度。  
  
别人熬夜蹲商品、回消息、盯订单的时候，你的 AI 已经在帮你干活了。
