## 一、决策树基础

### 1.1 决策树概述

决策树是一种有监督机器学习算法，模仿人类做决策的过程。决策树可处理非线性问题，具有强可解释性和高预测效率。

### 1.2 三大分裂准则

#### 1.2.1 ID3算法 - 信息增益

**信息熵公式：**
$$H(Y) = -\sum_{i=1}^{n} p(y_i) \log_2 p(y_i)$$

**信息增益（不考虑特征取值数量）：**
$$g(X,Y) = H(Y) - H(Y|X)$$

其中 $H(Y|X)$ 为条件熵，表示知道特征X后，Y的不确定性。

**缺点：** 偏向于选择取值较多的特征（因为多取值更容易降低熵）

#### 1.2.2 C4.5算法 - 信息增益率

**信息增益率（通过惩罚项修正）：**
$$gr(X,Y) = \frac{g(X,Y)}{Info(X)}$$

其中 **固有值** (intrinsic value)：
$$Info(X) = -\sum_{v \in values(X)} \frac{N(v)}{N} \log_2 \frac{N(v)}{N}$$

> ⚠️ **原文有误**：信息增益偏向于取值多的特征，而**C4.5通过加入惩罚项(分母)来修正这一缺陷**，不是单纯的信息增益

**优势：** 通过除以固有值，抑制多值特征的倾向

#### 1.2.3 CART算法 - 基尼系数和平方误差

**基尼系数（分类）：**
$$Gini(D) = 1 - \sum_{i=1}^{k} p_i^2$$

分裂后的基尼系数：
$$Gini_{split} = \frac{|D_L|}{|D|} Gini(D_L) + \frac{|D_R|}{|D|} Gini(D_R)$$

**平方误差MSE（回归）：**
$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

> ⚠️ **原文有误**：基尼系数与基尼指数混用。CART使用的是"**基尼系数**"（衡量纯度），而非"基尼指数"。基尼系数范围[0,1]，0表示完全纯，1表示完全混杂

**CART特点：**
- 生成**二叉树**（每个节点最多两个分支），而非多叉树
- 同时支持分类和回归

> ⚠️ **原文有误**：CART**必须是二叉树**，不能生成多叉树。选择每个特征的最优分裂点，使其成为最优二分特征

### 1.3 决策树剪枝

#### 1.3.1 预剪枝（Pre-pruning）
- 在构建过程中提前停止
- 参数：`max_depth`, `min_samples_split`, `min_samples_leaf`, `min_impurity_decrease`

#### 1.3.2 后剪枝（Post-pruning）
- 先完整构建，再自下而上删除子树
- **CCP(Cost Complexity Pruning) 代价复杂度剪枝：**

$$Obj = \frac{1}{|T|}\sum_{leaf} L(leaf) + \alpha |T|_{leaves}$$

其中 $\alpha$ 为复杂度参数，$|T|_{leaves}$ 为叶节点数

## 二、集成学习总览

### 2.1 误差分解：偏差-方差-噪声

对于任意学习器的泛化误差可分解为：
$$E = Bias^2 + Variance + Noise$$

- **偏差**：学习器预测的期望与真实值的偏差（欠拟合）
- **方差**：学习器预测的波动性（过拟合）
- **噪声**：数据本身的随机性（不可约）

### 2.2 Bagging vs Boosting

```
并行 vs 串行对比：

┌─────────────────────────────────────────────────────────────┐
│  Bagging (Bootstrap Aggregating)      │  Boosting (提升)     │
├──────────────────────────┼──────────────────────────────────┤
│  并行训练多个模型        │  串行训练，前向依赖               │
│  独立性好，降低方差      │  关注错分样本，降低偏差           │
│  所有学习器权重相等      │  学习器权重不同（好坏有别）      │
│  随机森林、极限森林      │  AdaBoost、GBDT、XGBoost        │
└──────────────────────────┴──────────────────────────────────┘
```

### 2.3 Bagging集成步骤

1. **Bootstrap**：有放回地随机抽样生成m个数据集
2. **训练**：用每个数据集训练基学习器
3. **聚合**：投票（分类）或平均（回归）

### 2.4 随机森林

```
随机森林构建流程：

                   ┌────────────────┐
                   │   原始数据集   │
                   └────────┬───────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
    ┌─────────┐         ┌─────────┐       ┌─────────┐
    │ 行采样  │         │ 行采样  │ ...   │ 行采样  │
    │ 列采样  │         │ 列采样  │       │ 列采样  │
    └────┬────┘         └────┬────┘       └────┬────┘
         │                   │                 │
         ▼                   ▼                 ▼
    ┌─────────┐         ┌─────────┐       ┌─────────┐
    │ Tree 1  │         │ Tree 2  │ ...   │ Tree N  │
    └────┬────┘         └────┬────┘       └────┬────┘
         │                   │                 │
         └───────────────────┼─────────────────┘
                             ▼
                      ┌─────────────────┐
                      │ 投票或平均聚合  │
                      └─────────────────┘
                             ▼
                         ┌─────────┐
                         │ 最终预测│
                         └─────────┘
```

**两层随机性：**
- **行采样**：有放回地从样本中抽取（Bagging）
- **列采样**：每个节点随机选择特征子集进行分裂

> ⚠️ **原文有误**：随机森林**同时进行行采样（样本随机）和列采样（特征随机）**，两者都是关键的随机化机制

**OOB(Out-of-Bag) 误差估计：**
- 每个样本约有1/3的概率不被选中（Out-of-Bag）
- 用OOB样本验证，无需额外划分测试集

## 三、AdaBoost算法

### 3.1 二分类AdaBoost

```
AdaBoost一轮迭代流程：

第m轮迭代：
┌──────────────────────────────────────────────┐
│ 1. 基于当前权重 w_m 训练弱学习器 g_m(x)     │
│    使用加权Gini系数或加权MSE               │
├──────────────────────────────────────────────┤
│ 2. 计算误差率                               │
│    e_m = Σ w_m[i] × I(g_m(x_i) ≠ y_i)     │
│    (加权错误数 / 总权重)                    │
├──────────────────────────────────────────────┤
│ 3. 计算弱学习器权重（话语权）               │
│    α_m = 1/2 × ln((1-e_m)/e_m)             │
│    误差越小 → α_m越大 → 话语权越大          │
├──────────────────────────────────────────────┤
│ 4. 更新样本权重（为下一轮准备）             │
│    w_{m+1}[i] = w_m[i] × exp(-α_m × y_i × g_m(x_i))  │
│    - 分类正确：指数项为负 → 权重下降        │
│    - 分类错误：指数项为正 → 权重上升        │
│    w_{m+1} ← w_{m+1} / Σw_{m+1}  # 归一化 │
└──────────────────────────────────────────────┘

最终预测：
f(x) = sign(Σ α_m × g_m(x))
     = +1 如果 Σα_m×g_m > 0
     = -1 如果 Σα_m×g_m < 0
```

> ⚠️ **原文有误**：AdaBoost弱学习器**不是简单平均**，而是**加权求和**，权重由各学习器的误差率决定。权重大的学习器在最终预测中的影响力更大

**指数损失函数推导：**

AdaBoost最小化指数损失：
$$L_{exp} = \sum_{i=1}^{n} \exp(-y_i f(x_i))$$

这导致了上述的权重更新规则。

### 3.2 多分类 SAMME 和 SAMME.R

**SAMME (Stagewise Additive Modeling with Multiclass Exponential loss)：**
$$\alpha_m = \frac{\text{learning\_rate}}{2} \ln\left(\frac{1-e_m}{e_m}\right) + \ln(K-1)$$

其中K为类别数，修正项 $\ln(K-1)$ 确保二分类退化为标准AdaBoost

**SAMME.R：** 使用概率输出而非硬分类，更新规则改变为：
$$\alpha_m = \text{learning\_rate}$$

权重更新直接基于概率输出，而非分类正确性

### 3.3 AdaBoost回归 (AdaBoost.R2)

**三种误差计算方式：**

1. **线性误差**：$e_{ki} = \frac{|y_i - \hat{y}_i|}{E_k}$ （最常用）
2. **平方误差**：$e_{ki} = \frac{(y_i - \hat{y}_i)^2}{E_k^2}$
3. **指数误差**：$e_{ki} = 1 - \exp\left(-\frac{|y_i - \hat{y}_i|}{E_k}\right)$

其中 $E_k = \max_i |y_i - g_k(x_i)|$ 为该轮最大误差

**权重更新：**
$$\beta = \frac{e_k}{1-e_k}$$
$$\alpha_k = \ln(1/\beta)$$
$$w_{k+1}[i] = w_k[i] \times \beta^{1-e_{ki}}$$

## 四、GBDT梯度提升决策树

### 4.1 GBDT回归（平方损失）

```
GBDT第t棵树构建流程 = 负梯度拟合的本质：

F_{t-1}(x) 已知（前t-1棵树的累积预测）
         ↓
计算残差（负梯度）：
  r_i = y_i - F_{t-1}(x_i)
         ↓
用g_t(x)拟合残差（最小化MSE）
         ↓
计算叶节点预测值（基于残差平均）
  c_j = avg(r_i | i∈叶节点j)
         ↓
更新累积预测（梯度下降）：
  F_t(x) = F_{t-1}(x) + learning_rate × g_t(x)
         ↓
重复第t+1轮
```

> ⚠️ **原文有误**：GBDT中的**残差只是平方损失下的特例**。一般GBDT使用**负梯度**而非残差。对于其他损失函数（如交叉熵），拟合的是负梯度，而非残差

**平方损失下的负梯度恰好等于残差：**
$$L = (y-f(x))^2$$
$$-\frac{\partial L}{\partial f} = 2(y-f(x)) \propto (y-f(x))$$

### 4.2 GBDT分类（对数损失）

**损失函数（交叉熵）：**
$$L = -y\ln(p) - (1-y)\ln(1-p)$$

其中 $p = \frac{1}{1+e^{-F(x)}}$ （sigmoid函数）

**初始值：**
$$F_0(x) = \ln\frac{\sum y_i}{\sum (1-y_i)}$$

**第m轮残差（负梯度）：**
$$\tilde{y}_i = y_i - \frac{1}{1+e^{-F_{m-1}(x_i)}}$$

**叶节点权重（二阶泰勒展开）：**

使用二阶泰勒展开近似损失函数，求导得到：
$$w_j^* = -\frac{\sum_{i \in I_j} \tilde{y}_i}{\sum_{i \in I_j} p_i(1-p_i) + \lambda}$$

其中 $p_i = \frac{1}{1+e^{-F_{m-1}(x_i)}}$

**多分类 Softmax：** 每个类别训练一棵树，使用Softmax概率输出

### 4.3 GBDT优化技巧

| 参数 | 作用 | 调整原则 |
|------|------|---------|
| `learning_rate` | 步长，控制每轮更新幅度 | 通常0.01-0.1，越小越稳定但需更多树 |
| `n_estimators` | 树的个数 | 与learning_rate反向：小lr需大n_est |
| `max_depth` | 树的深度 | 通常3-8，过深易过拟合 |
| `subsample` | 样本采样比例 | 0.5-1.0，降低方差防止过拟合 |
| `colsample_bytree` | 特征采样比例 | 0.5-1.0，增强正则化 |

## 五、XGBoost极端梯度提升

### 5.1 XGBoost vs GBDT核心区别

> ⚠️ **原文有误**：XGBoost**不是"用残差"的方法，而是用一阶+二阶梯度的方法**

| 特性 | GBDT | XGBoost |
|------|------|---------|
| 优化方式 | 一阶梯度（残差） | 二阶泰勒展开（一阶+二阶梯度） |
| 正则化 | 简单的树深度限制 | 显式的L1/L2正则项 + 叶节点数 |
| 分裂评分 | 基于MSE(MSE小=分裂好) | 基于Gain (收益函数) |
| 缺失值处理 | 不支持 | 自动化处理 |
| 并行化 | 串行(不支持) | 列块并行、近似分桶 |
| 防过拟合 | max_depth, subsample | eta, gamma, lambda, alpha等 |

### 5.2 XGBoost目标函数与二阶展开

**原始目标函数：**
$$Obj^{(t)} = \sum_{i=1}^{n} l(y_i, \hat{y}_i^{(t)}) + \sum_{i=1}^{t} \Omega(f_i)$$

其中 $\hat{y}_i^{(t)} = \hat{y}_i^{(t-1)} + f_t(x_i)$

**二阶泰勒近似：**

令：
- $g_i = \frac{\partial l}{\partial \hat{y}^{(t-1)}}$ （一阶梯度）
- $h_i = \frac{\partial^2 l}{\partial (\hat{y}^{(t-1)})^2}$ （二阶梯度/Hessian）

```
XGBoost二阶展开推导链：

原目标函数
  ↓ (泰勒展开)
Σ[g_i × f(x_i) + 1/2 × h_i × f²(x_i)] + Ω(f_t)
  ↓ (按叶节点分组)
Σ_j [G_j × w_j + 1/2(H_j + λ) × w²_j] + γT
  ↓ (求导令其为0)
最优叶权: w*_j = -G_j/(H_j + λ)
  ↓ (代入目标函数)
Gain = 1/2 × [G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] - γ
```

其中：
- $G_j = \sum_{i \in I_j} g_i$（叶节点j的一阶梯度和）
- $H_j = \sum_{i \in I_j} h_i$（叶节点j的二阶梯度和）

### 5.3 XGBoost分裂增益计算

**分裂前的目标函数值：**
$$Obj_{before} = -\frac{G^2}{H+\lambda} + \gamma$$

**分裂后的目标函数值：**
$$Obj_{after} = -\frac{G_L^2}{H_L+\lambda} - \frac{G_R^2}{H_R+\lambda} + 2\gamma$$

**增益（Gain）：** 分裂前后的改进量
$$Gain = \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda} - \gamma$$

增益越大，分裂收益越好。当Gain < 0时，应该剪枝。

### 5.4 XGBoost关键特性

**近似分桶（Approximate Split Finding）：**
- 将特征值分成多个桶，而非逐一扫描
- 大幅加速分裂搜索，特别是大数据集

**稀疏感知（Sparsity-aware Split Finding）：**
- 自动处理缺失值
- 为每个特征学习默认分裂方向

**列块并行（Column Block）：**
- 按列存储数据块
- 多线程并行读取不同列，加速分裂评估

### 5.5 XGBoost防过拟合参数

| 参数 | 含义 | 调整建议 |
|------|------|---------|
| `eta` (learning_rate) | 学习率，控制步长 | 默认0.3，常调为0.01-0.1，小值需增加树数 |
| `max_depth` | 树的最大深度 | 默认6，通常3-8，过深易过拟合 |
| `min_child_weight` | 叶节点最小权重和 | 默认1，增大值抑制过拟合 |
| `gamma` | 分裂所需的最小损失下降 | 默认0，增大值抑制分裂，减少过拟合 |
| `lambda` | L2正则化系数 | 默认1，增大值抑制权重，防过拟合 |
| `alpha` | L1正则化系数 | 默认0，与lambda类似但产生稀疏性 |
| `subsample` | 样本采样比例 | 默认1，0.5-1通常，降低方差 |
| `colsample_bytree` | 特征采样比例 | 默认1，0.5-1通常，增强正则化 |

> ⚠️ **原文有误**：**learning_rate与树数应反向调**。降低eta时应增加n_estimators以维持训练强度；提高eta时应减少树数。盲目调参会浪费计算资源

### 图2：信息增益计算示例
```
原始数据集: 10个样本, 类别分布 (6正, 4负)
H(Y) = -0.6×log2(0.6) - 0.4×log2(0.4) ≈ 0.971 bits

条件熵: H(Y|X) = 7/10×0.863 + 3/10×0.918 ≈ 0.879 bits

信息增益: g(X,Y) = 0.971 - 0.879 = 0.092 bits ✓
         (较好的分裂方案)
```

```
│                 └→ 学习器gm         │         └──→ ...                   │
│                                     │                                     │
│  最终: f = 1/m×Σgi (平均)          │  最终: f = sign(Σαi×gi)  (加权和)  │
│  可并行训练                         │  必须串行训练，互相依赖             │
│  降低方差(高偏差→低方差)             │  降低偏差(低偏差)                   │
│                                     │                                     │
└─────────────────────────────────────┴─────────────────────────────────────┘
```

### 图4：AdaBoost一轮迭代(权重更新→弱学习器→α)
```
第m轮迭代:

┌──────────────────────────────────────────────────────────────┐
│                  权重更新流程                                │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│ w_m (当前样本权重)                                            │
│    ├─ [0.1, 0.05, 0.15, ...]                                 │
│    │                                                          │
│    ▼                                                          │
│ 用w_m加权训练弱学习器g_m(x)                                   │
│ (按权重大小采样,或设置sample_weight)                         │
│    │                                                          │
│    ▼                                                          │
│ 计算预测结果 ŷ = g_m(X)                                      │
│    │                                                          │
│    ▼                                                          │
│ 计算误差率 e_m = Σ w_m[i]×I(y_i ≠ ŷ_i)                      │
│ (加权错误数)                                                 │
│    │                                                          │
│    ├─ 若 e_m > 0.5: 重新训练或丢弃此学习器                    │
│    │ 若 e_m ≤ 0.5: 继续                                       │
│    │                                                          │
│    ▼                                                          │
│ 计算学习器权重                                               │
│ α_m = 1/2 × ln((1-e_m)/e_m)                                  │
│ │                                                             │
│ ├─ e_m小(准) → α_m大 → 话语权大✓                            │
│ └─ e_m大(差) → α_m小 → 话语权小✓                            │
│    │                                                          │
│    ▼                                                          │
│ 更新样本权重 (关键!)                                          │
│ w_{m+1}[i] = w_m[i] × exp(-α_m × y_i × g_m(x_i))           │
│                                                               │
│ ├─分类正确(y_i=g_m(x_i)) → 指数项负 → 权重↓                │
│ ├─分类错误(y_i≠g_m(x_i)) → 指数项正 → 权重↑ ★             │
│ └─ w_{m+1} ← w_{m+1} / Σw_{m+1}  (归一化,保证Σ=1)          │
│                                                               │
└──────────────────────────────────────────────────────────────┘

最终聚合:
f(x) = sign(Σ_{m=1}^M α_m × g_m(x))
     = 加权多数投票
```

### 图5：GBDT第t棵树 = 负梯度拟合的流程
```
┌──────────────────────────────────────────────────────────┐
│ 已有: F_{t-1}(x) [前t-1棵树的累积预测]                   │
│      y [真实标签]                                        │
└────┬─────────────────────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────────────────────────┐
│ 计算负梯度(残差) r_i:                                    │
│                                                          │
│ 回归(平方损失): r_i = y_i - F_{t-1}(x_i)                │
│ 分类(对数损失): r_i = y_i - P(y_i|x_i)                  │
│                 其中P从sigmoid(F_{t-1})得出            │
│                                                          │
│ 本质: 指导树g_t(x)如何修正前面的错误                    │
└────┬─────────────────────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────────────────────────┐
│ 用g_t(x)拟合残差 {r_1, r_2, ..., r_N}:                   │
│                                                          │
│ 最小化: Σ(g_t(x_i) - r_i)²  (决策树回归)              │
│ 选择最优分裂条件(基于MSE)                              │
│                                                          │
│ ★ 关键: 不是拟合y,而是拟合residuals!                    │
└────┬─────────────────────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────────────────────────┐
│ 计算叶节点权重c_j (每个叶子的预测值)                    │
│                                                          │
│ 回归: c_j = Σ(r_i) / |叶子内样本数|                     │
│           (残差平均)                                    │
│                                                          │
│ 分类: c_j = Σ(r_i) / Σ(p_i(1-p_i)) + λ                 │
│           (加权平均,用二阶梯度)                        │
└────┬─────────────────────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────────────────────────┐
│ 梯度下降更新累积预测:                                   │
│                                                          │
│ F_t(x) = F_{t-1}(x) + learning_rate × g_t(x)           │
│        = 上一轮预测 + 学习率 × 本轮修正                │
│                                                          │
│ learning_rate ∈ (0,1]                                  │
│ ├─ 小(如0.01): 保守,防过拟合,需更多树                  │
│ └─ 大(如0.1):  激进,快速收敛,易过拟合                  │
└────┬─────────────────────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────────────────────────┐
│ 重复: t = t+1, 处理新的F_t的残差,构造g_{t+1}           │
└──────────────────────────────────────────────────────────┘
```

### 图6：XGBoost二阶展开推导链
```
原始目标函数:
Σ l(y_i, ŷ_i^(t-1) + f_t(x_i)) + Ω(f_t)
       ↓ (泰勒二阶展开)
Σ [g_i·f(x_i) + 1/2·h_i·f²(x_i)] + Ω(f_t)
       │ 其中:
       │ g_i = ∂l/∂ŷ^(t-1)  (一阶梯度)
       │ h_i = ∂²l/∂(ŷ^(t-1))²  (二阶梯度/Hessian)
       ▼
       │ 按叶节点分组 (样本i映射到叶j)
       │ I_j = {i | q(x_i) = j}
       ▼
Σ_j [G_j·w_j + 1/2(H_j+λ)·w²_j] + γT
   │ 其中:
   │ G_j = Σ_{i∈I_j} g_i  (叶j的梯度和)
   │ H_j = Σ_{i∈I_j} h_i  (叶j的Hessian和)
   │ λ = L2正则化系数
   │ γ = 节点分裂代价
   │ T = 叶子数量
   ▼
   │ 对w_j求导,令其为0
   │ ∂Obj/∂w_j = G_j + (H_j+λ)·w_j = 0
   ▼
最优叶权:
w*_j = -G_j / (H_j + λ)
       │
       ├─ 分子(G_j): 梯度累加 (方向和幅度)
       └─ 分母(H_j+λ): Hessian累加 (曲率)
       ▼
代入得最小目标值:
-1/2 · Σ_j G²_j / (H_j + λ) + γT
       ▼
分裂增益(Gain):
G_split = [G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] / 2 - γ
        │
        ├─ > 0: 分裂有益,继续分裂
        ├─ ≤ 0: 分裂无益,停止分裂/剪枝
        └─ Gain越大,分裂越优
```

### 图7：XGBoost分裂增益计算
```
初始节点 (包含所有样本):
┌─────────────────────────────────┐
│ G = Σg_i, H = Σh_i              │
│ 目标值 = -G²/(H+λ) + γ          │
└──────────────┬──────────────────┘
               │
       尝试按特征X分裂
               │
         ┌─────┴─────┐
         ▼           ▼
    左子集L      右子集R
    G_L, H_L    G_R, H_R
    │           │
    │ 分裂后目标:
    │ = -G_L²/(H_L+λ) - G_R²/(H_R+λ) + 2γ
    │
    └────────┬────────┘
             ▼
    分裂增益 (Gain):
    = [G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] / 2 - γ
                                      │
             ┌────────────────────────┼────────────────────────┐
             │                        │                        │
             ▼                        ▼                        ▼
          Gain > 0                Gain ≈ 0               Gain < 0
          (分裂有益)              (中立)                (分裂无益)
             │                        │                        │
             │                        │                        │
        选择该分裂✓              保持观察             不分裂/剪枝✓
        继续左右递归                                    停止
             │
             ▼
   比较所有特征的最优Gain
   选择Gain最大的特征进行分裂
```

## 八、常见纠错汇总

### 纠错1：信息增益与特征取值数量的关系

**误区：** 信息增益适用于任何特征

**正确：** 
- ID3信息增益**偏向于取值较多的特征**
- C4.5通过**惠益率**(Information Gain Ratio)修正：除以固有值
- 固有值大 → 分母大 → 信息增益率相对小 → 平衡了多值特征的优势

### 纠错2：基尼系数 vs 基尼指数

**误区：** 混用两个概念

**正确：**
- **基尼系数**：衡量纯度，$Gini = 1 - \sum p_i^2$ （范围[0,1]）
- **基尼指数**：有时指计量学中的收入分布指标（不同含义）
- CART决策树用的是**基尼系数**，不是基尼指数

### 纠错3：CART树结构

**误区：** CART可以生成多叉树

**正确：** 
- CART**必须生成二叉树**（Binary Decision Tree）
- 每个节点最多两个分支
- 对于多值离散特征，需要分成多次二分

### 纠错4：随机森林的随机性

**误区：** 只有样本随机

**正确：**
- **行随机**：Bagging有放回抽样（样本维度随机）
- **列随机**：每个节点分裂时随机选择特征子集（特征维度随机）
- 两层随机性共同降低方差，提高泛化能力

### 纠错5：AdaBoost弱学习器的聚合

**误区：** 弱学习器简单投票或平均

**正确：**
- AdaBoost**加权求和**：$f(x) = \sum \alpha_m \times g_m(x)$
- $\alpha_m = \frac{1}{2}\ln\frac{1-e_m}{e_m}$（取决于误差率）
- 误差率越低的学习器，权重α越大，话语权越大

### 纠错6：GBDT中的残差与负梯度

**误区：** GBDT总是拟合残差

**正确：**
- **一般GBDT**拟合的是**负梯度**，而非残差
- **平方损失**特例：$-\frac{\partial L}{\partial f} = 2(y-f) \propto \text{残差}$
- **交叉熵损失**：$-\frac{\partial L}{\partial f} = y - \sigma(f) \neq \text{残差}$
- 残差只是平方损失下的特殊情况

### 纠错7：XGBoost优化方式

**误区：** XGBoost用残差做一阶优化

**正确：**
- XGBoost使用**二阶泰勒展开**
- 需要**一阶梯度(g_i)和二阶梯度(h_i/Hessian)**
- 目标函数：$\sum [g_i f + \frac{1}{2}h_i f^2] + \Omega(f)$
- 而非简单的"用残差"

### 纠错8：learning_rate与树数的反向关系

**误区：** learning_rate高低与树数无关

**正确：**
- **learning_rate与n_estimators应反向调节**
- 降低learning_rate(如0.01)→ 需增加n_estimators(如1000)
- 提高learning_rate(如0.1) → 可减少n_estimators(如100)
- 否则模型训练不充分或浪费计算

## 九、速查表

### 算法特点速查

| 算法 | 类型 | 偏差-方差 | 并行 | 缺失值 | 最适用场景 |
|------|------|----------|------|--------|-----------|
| **决策树** | 单体 | 低偏差,高方差 | ✓ | ✓ | 小数据,可解释 |
| **随机森林** | 集成(Bagging) | 低偏差,低方差 | ✓ | ✓ | 通用,中等数据 |
| **AdaBoost** | 集成(Boosting) | 低偏差,低方差 | ✗ | ✗ | 多分类问题 |
| **GBDT** | 集成(Boosting) | 低偏差,低方差 | ✗ | ✗ | 回归/分类 |
| **XGBoost** | 集成(Boosting) | 低偏差,低方差 | ✓ | ✓ | 大数据,竞赛 |
| **LightGBM** | 集成(Boosting) | 低偏差,低方差 | ✓ | ✓ | 超大数据 |
| **CatBoost** | 集成(Boosting) | 低偏差,低方差 | ✓ | ✓ | 类别特征多 |

### 分裂准则速查

| 准则 | 算法 | 公式 | 适用 | 特点 |
|------|------|------|------|------|
| 信息增益 | ID3 | $g(X,Y) = H(Y) - H(Y\|X)$ | 分类 | 偏多值 |
| 增益率 | C4.5 | $gr = g(X,Y)/Info(X)$ | 分类 | 修正偏差 |
| 基尼系数 | CART | $Gini = 1-\sum p_i^2$ | 分类 | 运算快 |
| MSE | CART | $\frac{1}{n}\sum(y-\hat{y})^2$ | 回归 | 直观 |

### 参数调优顺序

1. **max_depth** (树深): 3-8, 防过拟合首选
2. **min_child_weight/min_samples_leaf**: 增加值→抑制分裂
3. **learning_rate**: 0.01-0.1, 小值需增加树数
4. **n_estimators**: 通常与learning_rate反向
5. **subsample/colsample**: 0.5-1, 降低方差
6. **gamma/min_impurity_decrease**: 分裂代价,越大越保守
7. **lambda/alpha**: 正则化,防过拟合

### 损失函数选择

| 任务 | 损失函数 | XGBoost参数 | 特点 |
|------|---------|-----------|------|
| 二分类 | 对数损失 | `binary:logistic` | 概率输出 |
| 多分类 | Softmax | `multi:softmax` / `multi:softprob` | 多类别 |
| 回归 | MSE/平方误差 | `reg:squarederror` | 对异常值敏感 |
| 回归 | MAE/绝对值误差 | `reg:linearerror` | 鲁棒性强 |

## 十、实战建议

### 何时选择哪个算法

**选择决策树：**
- 需要高可解释性
- 小数据集(<10K)
- 特征工程困难

**选择随机森林：**
- 中等规模数据(10K-100K)
- 需要快速baseline
- 特征重要性分析

**选择GBDT:**
- 中等规模数据
- 追求准确率
- 计算资源充足

**选择XGBoost:**
- 大规模数据(>100K)
- 竞赛/生产环境
- 需要调优空间

**选择LightGBM:**
- 超大规模数据(>1M)
- 内存受限
- 实时预测需求

**选择CatBoost:**
- 类别特征占比高(>30%)
- 需要特别防过拟合
- 可用计算资源充足

### 常见调参陷阱

1. **过度调参**：参数太多→过拟合→泛化差
   - 建议：先用默认参数,观察是否欠拟合/过拟合再调整

2. **混淆learning_rate和n_estimators**
   - 建议：同时调整，通常lr×n_est应保持相对稳定

3. **max_depth设置过小**
   - 症状：训练误差仍然很大（欠拟合）
   - 建议：逐步增加,直到训练误差满意

4. **忽视样本不均衡**
   - 建议：使用scale_pos_weight(XGBoost)或过采样欠采样

5. **只关注训练准确率**
   - 建议：使用交叉验证,监控验证集曲线

## 参考公式速查表

### 信息论
$$H(X) = -\sum_i p_i \log_2 p_i \quad \text{(信息熵)}$$
$$g(X,Y) = H(Y) - H(Y|X) \quad \text{(信息增益)}$$

### 纯度指标
$$Gini(D) = 1 - \sum_i p_i^2 \quad \text{(基尼系数)}$$
$$\text{MSE} = \frac{1}{n}\sum_i (y_i-\hat{y}_i)^2$$

### AdaBoost
$$\alpha_m = \frac{1}{2}\ln\frac{1-e_m}{e_m} \quad \text{(学习器权重)}$$
$$w_{m+1}[i] = w_m[i] \exp(-\alpha_m y_i g_m(x_i)) \quad \text{(权重更新)}$$

### GBDT
$$r_i = y_i - F_{m-1}(x_i) \quad \text{(残差/负梯度)}$$
$$F_m(x) = F_{m-1}(x) + \eta \cdot g_m(x) \quad \text{(累积预测)}$$

### XGBoost
$$Obj^{(t)} = \sum_i [g_i f(x_i) + \frac{1}{2}h_i f^2(x_i)] + \Omega(f)$$
$$w_j^* = -\frac{G_j}{H_j+\lambda} \quad \text{(最优叶权)}$$
$$\text{Gain} = \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda} - \gamma$$
