## 一、多元线性回归

### 1.1 模型形式

**多元线性回归模型**是有监督学习中的基础算法，用于预测连续值。

模型表示：
$$\hat{y} = w_1x_1 + w_2x_2 + \ldots + w_nx_n + b$$

或矩阵形式：
$$\hat{y} = W^TX$$

其中：
- $X$ 为特征矩阵（包含常数项1）
- $W$ 为权重向量
- $\hat{y}$ 为预测值

### 1.2 最小二乘法与正规方程

**目标函数（MSE损失函数）**：
$$J(\theta) = \frac{1}{2}\sum_{i=1}^{n}(h_\theta(x^{(i)}) - y^{(i)})^2 = \frac{1}{2}(X\theta - y)^T(X\theta - y)$$

**正规方程解**：
$$\theta = (X^TX)^{-1}X^Ty$$

#### 推导关键步骤

1. **矩阵形式展开**
2. **对$\theta$求偏导**：$\frac{\partial J}{\partial \theta} = X^T(X\theta - y)$
3. **令导数为0**：$X^TX\theta = X^Ty$
4. **求逆解**：$\theta = (X^TX)^{-1}X^Ty$

> ⚠️ **原文有误**：当说线性回归"无解"时，实际指的是 $X^TX$ **奇异（不可逆）**。常见原因：
> - 特征维度过高（样本数 < 特征数）
> - 特征之间存在完全共线性
> - 处理方法：正则化（Ridge/Lasso）或特征选择

### 1.3 X^T X不可逆处理

**问题诊断**：Hessian矩阵 $X^TX$ 的秩不满足满秩条件

**解决方案**：
1. **Ridge回归**（L2正则）：$\theta = (X^TX + \lambda I)^{-1}X^Ty$
2. **Lasso回归**（L1正则）：加入 $L_1$ 惩罚项
3. **特征选择**：移除共线特征
4. **降维**：使用PCA等方法

### 1.4 几何解释

```
    Loss函数等值线（椭圆）
           /\
          /  \
         /    \
        |  *   |  * 为最优解
         \    /
          \  /
           \/
```

- **一维情况**：Loss是关于 $\theta$ 的抛物线，最低点为最优解
- **多维情况**：Loss是超参数空间中的**凸函数**，梯度下降可找到全局最优
- **几何含义**：预测平面与实际数据点误差平方和最小

### 1.5 评估指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **MSE** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 均方误差（对异常值敏感） |
| **RMSE** | $\sqrt{\text{MSE}}$ | 均方根误差（与y同量纲） |
| **MAE** | $\frac{1}{n}\sum\|y_i - \hat{y}_i\|$ | 平均绝对误差（对异常值鲁棒） |
| **R²** | $1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}}$ | 拟合度（越接近1越好） |

> ⚠️ **原文有误**：最小二乘法**假设**噪声独立同分布（i.i.d）且**方差恒定**。若违反此假设（异方差性），应使用加权最小二乘法（WLS）。

### 1.6 共线性诊断

**多重共线性问题**：特征之间高度相关

**诊断方法**：
1. **相关系数矩阵**：检查特征间相关系数
2. **VIF方差膨胀系数**：$VIF_j = \frac{1}{1-R_j^2}$，VIF > 10表示严重共线性
3. **条件数**：$\kappa = \frac{\lambda_{\max}}{\lambda_{\min}}$，>30为高共线性

**处理方式**：
- 移除冗余特征
- 岭回归/Lasso正则化
- 主成分分析（PCA）

### 1.7 特征工程

**升维**：创建新特征以提高模型表达能力
$$x_1, x_2 \rightarrow x_1, x_2, x_1^2, x_2^2, x_1x_2$$

**特征缩放**：确保数值型特征处于同一量级（见第二部分）

## 二、梯度下降

### 2.1 批量vs随机vs小批量

```
对比图示：
┌─────────────────┬──────────────┬──────────────┬──────────────┐
│   特性          │   BGD        │     SGD      │    MBGD      │
├─────────────────┼──────────────┼──────────────┼──────────────┤
│ 每次使用样本数  │   全部(n)    │      1       │  batch_size  │
│ 迭代次数        │     少       │      多      │     中等     │
│ 内存消耗        │    大        │      小      │      中等    │
│ 计算速度        │    慢        │      快      │      快      │
│ 收敛曲线        │    平滑      │    波动大    │    相对平滑   │
│ 数据并行化      │    好        │      否      │      一般    │
└─────────────────┴──────────────┴──────────────┴──────────────┘
```

#### 正规方程 → 梯度下降的演进链

```
凸函数存在全局最优
        ↓
正规方程求解（时间复杂度O(n³)）
        ↓
特征数量过多 → 需要迭代算法
        ↓
梯度下降法（时间复杂度O(n²)）
        ↓
BGD批量 → 迭代次数少，计算慢
    ↓
    SGD随机 → 迭代次数多，单次快
    ↓
    MBGD小批量 → 平衡折中
```

### 2.2 批量梯度下降（BGD）

**参数更新公式**：
$$\theta_j := \theta_j - \eta \sum_{i=1}^{n}(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

**优点**：方向准确，收敛曲线平滑，利于并行计算  
**缺点**：样本数大时每次迭代慢

### 2.3 随机梯度下降（SGD）

**参数更新公式**（每次取单个样本）：
$$\theta_j := \theta_j - \eta(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

**优点**：单次迭代快，内存开销小  
**缺点**：收敛曲线波动大，容易陷入局部最优

> ⚠️ **原文有误**：SGD**不一定**比BGD收敛快。当数据量n很大时，SGD虽然单次迭代少但**噪声大**，可能需要更多总迭代次数达到精度要求。

### 2.4 小批量梯度下降（MBGD）

**参数更新公式**（batch_size个样本）：
$$\theta_j := \theta_j - \eta \sum_{i \in \text{batch}}(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

**特点**：兼顾收敛稳定性和计算效率，推荐用于深度学习

### 2.5 学习率与收敛判断

**学习率 $\eta$ 的影响**：

```
     Loss
      ↑
      │     ╱╲    η过大→振荡发散
      │    ╱  ╲
      │   ╱    ╲___
      │  ╱         ╲____   η合适→平稳收敛
      │ ╱
      │╱_____________    η过小→收敛缓慢
      └─────────────→ iteration
```

**常用学习率**：0.1, 0.01, 0.001, 0.0001（根据情况调整）

**收敛判断准则**：
1. 损失函数变化量 < 阈值（如1e-4）
2. 参数变化量 < 阈值
3. 达到预设迭代次数

### 2.6 特征缩放必要性

**问题**：不同维度数值量级差异大导致梯度下降方向不一致

```
     w2
      ↑
      │  ╱╱╱╱╱  未缩放：收敛缓慢
      │ ╱╱╱╱
      │╱╱╱____→ w1
      
      w2
      ↑     缩放后：收敛快速
      │  •←─┐
      │  ↓  │
      └────→ w1
```

### 2.7 归一化vs标准化

| 方法 | 公式 | 输出范围 | 适用场景 |
|------|------|---------|---------|
| **Min-Max归一化** | $\frac{x-x_{\min}}{x_{\max}-x_{\min}}$ | [0, 1] | 对异常值敏感，需要有界范围 |
| **Z-score标准化** | $\frac{x-\mu}{\sigma}$ | (-∞, +∞) | 符合正态分布，对异常值鲁棒 |

> ⚠️ **关键区别**：
> - **归一化** = 平移+缩放到[0,1]，有界
> - **标准化** = 标准差变换，无界但可正可负
> - 梯度下降中，标准化表现更佳（允许双向更新）

## 三、梯度下降优化

### 3.1 动量法（Momentum）

**核心思想**：累积历史梯度方向，加速收敛

**速度向量合成示意图**：

```
      当前梯度 ↓
          \│/
    ─────→•←─── 历史动量
           │
           ↓ 合成速度（加快下降）
```

**参数更新**：
$$v_t = \beta v_{t-1} + (1-\beta)\nabla J(\theta)$$
$$\theta := \theta - \eta v_t$$

典型参数：$\beta = 0.9$（累积90%历史）

### 3.2 NAG（Nesterov Accelerated Gradient）

**改进**：先按历史动量移动，再计算该位置梯度

$$v_t = \beta v_{t-1} - \eta \nabla J(\theta - \beta v_{t-1})$$

**优势**：比Momentum收敛更快、更稳定

### 3.3 AdaGrad（Adaptive Gradient）

**思想**：为每个参数维度自适应学习率

$$\theta_j := \theta_j - \frac{\eta}{\sqrt{G_j + \epsilon}} \cdot \nabla J(\theta)_j$$

其中 $G_j = \sum_{t=1}^{T} (\nabla J(\theta)_j^{(t)})^2$

**缺点**：学习率单调递减，后期可能过小导致收敛停滞

### 3.4 RMSProp（Root Mean Square Propagation）

**改进**：使用指数加权移动平均替代累积

$$E[g^2]_t = \beta E[g^2]_{t-1} + (1-\beta)(\nabla J(\theta))^2$$
$$\theta := \theta - \frac{\eta}{\sqrt{E[g^2]_t + \epsilon}} \cdot \nabla J(\theta)$$

**优势**：避免学习率过早衰减

### 3.5 Adam（Adaptive Moment Estimation）

**原理**：Momentum + RMSProp的结合

$$m_t = \beta_1 m_{t-1} + (1-\beta_1)\nabla J(\theta)$$
$$v_t = \beta_2 v_{t-1} + (1-\beta_2)(\nabla J(\theta))^2$$
$$\hat{m}_t = \frac{m_t}{1-\beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1-\beta_2^t}$$
$$\theta := \theta - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t$$

典型参数：$\beta_1 = 0.9, \beta_2 = 0.999, \eta = 0.001$

> ⚠️ **原文有误**：Adam**不是普适最优**算法。虽然在许多任务表现好，但对某些问题（如精细调优）SGD+Momentum仍优于Adam。选择需根据具体任务。

### 3.6 AdamW（Adam with Weight Decay）

**改进**：修复Adam的L2正则化问题

原Adam中权重衰减与学习率耦合，AdamW解耦：

$$\theta := \theta - \eta_{\text{weight\_decay}} \theta - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t$$

**优势**：正则化效果更清晰可控

### 3.7 学习率衰减策略

| 策略 | 公式 | 用途 |
|------|------|------|
| **指数衰减** | $\eta_t = \eta_0 \cdot \lambda^t$ | 平滑衰减 |
| **多项式衰减** | $\eta_t = \eta_0(1 - \frac{t}{T})^p$ | 灵活控制 |
| **分段衰减** | $\eta_t = \eta_0 / (\lfloor t/k \rfloor + 1)$ | 周期性调整 |
| **逆时衰减** | $\eta_t = \frac{\eta_0}{1+\lambda t}$ | 缓慢衰减 |

**应用**：初期保持大学习率以快速逼近，后期减小学习率以精细调优。

## 四、逻辑回归（分类算法）

### 4.1 逻辑回归的本质

> ⚠️ **原文有误**：逻辑回归**是分类不是回归**。虽然名字含"回归"，但核心是将线性回归输出映射到[0,1]作为概率进行分类。

**模型形式**：
$$h_\theta(x) = \frac{1}{1+e^{-\theta^Tx}} = \sigma(\theta^Tx)$$

其中 $\sigma$ 是Sigmoid函数

### 4.2 Sigmoid函数

**函数表达**：
$$\sigma(z) = \frac{1}{1+e^{-z}}$$

**关键性质**：
$$\sigma'(z) = \sigma(z)(1-\sigma(z))$$

```
    σ(z)
      ↑
      │     ╱╱╱╱╱ → 1
      │    ╱╱╱
      │   ╱╱
      │  ╱ 
      │ •  (0, 0.5)
      │ ╱
      │╱ → 0
      └──────→ z
```

**性质**：
- 值域 [0, 1]，可解释为概率
- $\sigma(0) = 0.5$，分类边界
- 可微，导数范围 [0, 0.25]

> ⚠️ **原文有误**：Sigmoid输出**不严格等于概率**。严格意义上，$h_\theta(x)$ 是预测为正类的**条件概率估计**（在伯努利分布假设下）。

### 4.3 决策边界

**二分类情况**：

$$\hat{y} = h_\theta(x) = \frac{1}{1+e^{-\theta^Tx}} = 0.5 \Rightarrow \theta^Tx = 0$$

```
    x2
    ↑
    │   ╱╱ △ (positive)
    │  ╱╱╱╱ ─────←决策边界θ^Tx=0
    │ ╱╱╱╱╱
    │╱╱╱╱╱ ○ (negative)
    └────────→ x1
```

**线性vs非线性**：逻辑回归是线性分类器（决策边界为直线/超平面）

### 4.4 对数损失函数

**推导**：基于Bernoulli分布最大似然估计

单个样本似然：
$$P(y|x;\theta) = h_\theta(x)^y (1-h_\theta(x))^{1-y}$$

整体似然：
$$L(\theta) = \prod_{i=1}^{n} h_\theta(x^{(i)})^{y^{(i)}} (1-h_\theta(x^{(i)}))^{1-y^{(i)}}$$

对数似然：
$$l(\theta) = \sum_{i=1}^{n}[y^{(i)}\ln(h_\theta(x^{(i)})) + (1-y^{(i)})\ln(1-h_\theta(x^{(i)}))]$$

**对数损失**（负对数似然）：
$$J(\theta) = -\frac{1}{n}\sum_{i=1}^{n}[y^{(i)}\ln(h_\theta(x^{(i)})) + (1-y^{(i)})\ln(1-h_\theta(x^{(i)}))]$$

### 4.5 最大似然推导链

```
伯努利分布
    ↓
二分类似然函数 L(θ) = ∏ p(y|x)
    ↓
取对数：l(θ) = Σ log p(y|x)
    ↓
引入负号变最小化问题
    ↓
对数损失函数 J(θ)
    ↓
求导得更新公式（与线性回归同形）
    ↓
梯度下降迭代求解
```

**参数更新**（与线性回归形式相同）：
$$\theta_j := \theta_j - \eta \sum_{i=1}^{n}(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

### 4.6 多分类方法

#### OvR（One-vs-Rest）

**思路**：K个类别 → K个二分类器

```
类别1(△)  vs 其他      ┐
类别2(□)  vs 其他  →   ├ K个二分类器
类别3(×)  vs 其他      ┘
                    ↓
                取概率最大的类别
```

**优点**：通用、高效（k个分类器）  
**缺点**：样本不平衡，不适合类别太多

#### OvO（One-vs-One）

**思路**：两两对比

- 2类：1个分类器
- 3类：3个分类器
- K类：$\binom{K}{2} = \frac{K(K-1)}{2}$ 个分类器

**优点**：样本平衡  
**缺点**：分类器数多，计算复杂度高

#### Softmax多分类

**概率输出**：
$$P(y=k|x;\theta) = \frac{e^{\theta_k^Tx}}{\sum_{j=1}^{K}e^{\theta_j^Tx}}$$

**性质**：
- 概率和为1
- $K=2$时退化为Sigmoid
- 参数共K个线性模型

**损失函数**（交叉熵）：
$$J(\theta) = -\sum_{i=1}^{n}\sum_{k=1}^{K}y_k^{(i)}\ln(P(y=k|x^{(i)};\theta))$$

### 4.7 L1/L2正则与稀疏性

#### L1正则化（Lasso）

**损失函数**：
$$J_L = J_0(\theta) + \alpha \sum_{j}|w_j|$$

**几何解释**：

```
        w2
        ↑
        │  ○ J₀等值线（椭圆）
        │ ╱╱╱
        │╱╱╱
        ╋━━━→ 菱形 L1约束
        │
```

等值线与L1菱形的顶点相切，顶点在坐标轴上 → **稀疏解**

> ⚠️ **原文有误**：L1正则在 $w_i=0$ 处**不可导**，需用**次梯度**处理：
> $$\partial |w_i| = \begin{cases} \{+1\} & w_i > 0 \\ [-1,+1] & w_i = 0 \\ \{-1\} & w_i < 0 \end{cases}$$

#### L2正则化（Ridge）

**损失函数**：
$$J_L = J_0(\theta) + \alpha \sum_{j}w_j^2$$

**几何解释**：

```
        w2
        ↑
        │  ○ J₀等值线
        │ ╱╱╱
        │╱╱╱
        ╋━━━→ 圆形 L2约束
        │
```

等值线与L2圆形相切于平滑处 → **分布式缩减**（无稀疏性）

#### L1 vs L2对比

| 特性 | L1 | L2 |
|------|----|----|
| 约束形状 | 菱形 | 圆形 |
| 相切位置 | 顶点(坐标轴) | 平滑处 |
| 稀疏性 | 强（产生0系数） | 无（系数全非0） |
| 可导性 | 否（0处）| 是 |
| 特征选择 | 自动选择 | 全部保留 |
| 共线性处理 | 随机选择 | 均衡分配权重 |

### 4.8 参数C的含义

在sklearn中，LogisticRegression使用参数 **C**（不是 $\alpha$）

**关系**：$C = \frac{1}{\alpha}$（正则强度的倒数）

> ⚠️ **原文有误**：sklearn中的 **C是正则强度的倒数**。
> - C值小 → 正则强 → 模型简单 → 更易欠拟合
> - C值大 → 正则弱 → 模型复杂 → 更易过拟合

典型值：C = [0.01, 0.1, 1, 10, 100]（需通过交叉验证选择）
