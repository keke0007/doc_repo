# 函数的作⽤

1.命令合集，完成特定功能的代码块

2.函数必须先定义才可以使⽤，如果定义不调⽤则不被执⾏

3.使代码模块化，避免重复代码，加强可读性，便于复⽤

# 1.定义函数

定义函数的⽅法如下

```javascript
//方式一
函数名() {
    函数要实现的功能代码
}
//方式二
function 函数名 {
    函数要实现的功能代码
}
```

# 2.调⽤函数

调⽤函数⾮常简单, 只需要在脚本中写⼊函数的名称即可

//调⽤函数

function_name	即可调⽤函数

//函数传参

fun	$1		传⼊脚本后第⼀个参数

fun	$*		接收所有参数的传递

# 3.函数返回

```shell
#!/bin/bash
fun2() {
read -p "enter num: " num
return $[2*$num]
}
fun2
echo "fun2 return value: $?" 
```

# 位置参数

```shell
#!/usr/bin/bash
if [ $# -ne 3 ];then
    echo "usage: `basename $0` par1 par2 par3"
    exit
fi
fun3() {
    echo "$(($1 * $2 * $3))"
}
result=`fun3 $1 $2 $3`
echo "result is: $result" 
```
