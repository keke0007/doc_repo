# JVM故障排查思路

1.jps获取java进程的PID。

2.jstack pid >> java.txt 导出CPU占⽤⾼进程的线程栈。

3.top -H -p PID 查看对应进程的哪个线程占⽤CPU过⾼。

4. echo "obase=16;989"|bc 将线程的PID转换为16进制。

5.在第⼆步导出的java.txt中查找转换成为16进制的线程PID。找到对应的线程栈。

6.分析负载⾼的线程栈都是什么业务操作。优化程序并处理问题。
