# HTML 知识点学习梳理

本文根据 `html/day01` 到 `html/day05` 的讲义内容整理，目标是把零散知识点重组为一份适合复习、查漏补缺的学习文档。

---

## 1. 这套 HTML 内容主要讲了什么

项目中的 HTML 学习内容大致分为 5 个层次：

1. 认识前端、网页、网站、浏览器
2. 认识 HTML 及第一个网页
3. 掌握 HTML 文档的基础结构
4. 学习常见 HTML 元素和属性
5. 补充路径、URL、字符实体、语义化、SEO 等扩展知识

如果你是初学者，可以把它理解成一句话：

`HTML 负责网页的内容和结构，CSS 负责样式，JavaScript 负责交互。`

---

## 2. 哪些知识点是必须掌握的

下面这些内容是你写网页时最常用、最基础、最应该优先掌握的。

### 2.1 HTML 的作用

**必须掌握**

- HTML 用来描述网页内容和结构
- HTML 不是编程语言，是标记语言
- 浏览器会解析 HTML 标签，并把内容展示出来

**应用场景**

- 写新闻页面
- 写博客页面
- 写商品详情页
- 写后台管理系统页面结构

**学习示例**

```html
<h1>欢迎学习 HTML</h1>
<p>HTML 用来描述网页的内容结构。</p>
```

---

### 2.2 HTML 文档的基本结构

**必须掌握**

- `<!DOCTYPE html>`：声明这是 HTML5 文档
- `<html>`：整个页面的根元素
- `<head>`：页面配置，不直接显示主要内容
- `<body>`：页面真正显示给用户看的内容
- `<meta charset="UTF-8">`：设置字符编码，避免乱码
- `<title>`：浏览器标签页标题

**学习示例**

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>Hello HTML</h1>
    <p>这是一个基础页面。</p>
  </body>
</html>
```

**应用场景**

- 新建任何 HTML 页面时都要先写这个结构
- 企业官网、活动页、管理系统页面都离不开它

---

### 2.3 标签、元素、属性

**必须掌握**

- 标签：如 `<p>`、`<a>`、`<img>`
- 元素：开始标签 + 内容 + 结束标签组成完整元素
- 属性：给元素补充说明信息，如 `href`、`src`、`alt`、`class`
- 双标签元素：`<p></p>`、`<div></div>`
- 单标签元素：`<img>`、`<br>`、`<meta>`

**学习示例**

```html
<a href="https://example.com" target="_blank">访问网站</a>
```

这里：

- `a` 是标签
- 整段内容是一个元素
- `href`、`target` 是属性

**应用场景**

- 任何 HTML 编写都离不开元素和属性
- 后续学 CSS、JavaScript 时也要依赖 `class`、`id` 等属性

---

### 2.4 标题和段落：`h1-h6`、`p`

**必须掌握**

- `h1` 到 `h6` 用来表示不同层级的标题
- `p` 用来表示段落
- 不要只为了“变大变粗”而乱用标题标签，标题有结构含义

**学习示例**

```html
<h1>HTML 学习指南</h1>
<h2>第一章：基础结构</h2>
<p>先掌握文档结构，再学习常见元素。</p>
```

**应用场景**

- 文章页
- 课程页
- 文档页
- 后台模块标题

**为什么必须掌握**

- 页面结构清晰
- 便于阅读
- 对 SEO 和语义化有帮助

---

### 2.5 图片：`img`

**必须掌握**

- `src`：图片地址
- `alt`：图片说明，图片加载失败或无障碍场景下很重要
- 网页路径中统一使用 `/`

**学习示例**

```html
<img src="./images/html-logo.png" alt="HTML 标志" />
```

**应用场景**

- 商品图
- 头像
- banner 图
- 文章配图

**必须注意**

- `src` 必写
- `alt` 建议养成必写习惯

---

### 2.6 超链接：`a`

**必须掌握**

- `href`：跳转地址
- `target="_self"`：当前页面打开
- `target="_blank"`：新标签页打开
- 可以链接网页、图片、压缩包、邮箱、锚点位置

**学习示例**

```html
<a href="https://developer.mozilla.org/" target="_blank">查看 MDN 文档</a>
```

**锚点示例**

```html
<a href="#chapter1">跳转到第一章</a>

<h2 id="chapter1">第一章</h2>
```

**应用场景**

- 导航栏跳转
- “查看更多”
- 页面内目录定位
- 下载链接

---

### 2.7 容器元素：`div` 和 `span`

**必须掌握**

- `div`：块级容器，常用于划分页面区域
- `span`：行内容器，常用于包裹局部文字

**学习示例**

```html
<div class="card">
  <h2>课程标题</h2>
  <p>课程简介</p>
</div>

<p>HTML 是 <span class="highlight">前端基础</span>。</p>
```

**应用场景**

- 页面布局分区
- 卡片结构
- 局部文字高亮
- 给 CSS 和 JavaScript 提供操作目标

**初学建议**

- `div` 和 `span` 很常用，但不要滥用
- 能用语义化标签时，优先用语义化标签

---

### 2.8 全局属性：`id`、`class`、`title`、`style`

**必须掌握**

- `id`：页面中应唯一
- `class`：可重复，用于样式和脚本选择
- `title`：提示信息
- `style`：内联样式，了解即可，实际开发不推荐大量使用

**学习示例**

```html
<h1 id="main-title" class="title" title="页面主标题">HTML 笔记</h1>
```

**应用场景**

- CSS 选中元素
- JavaScript 获取元素
- 锚点跳转

---

### 2.9 注释

**必须掌握**

- 注释格式：`<!-- 注释内容 -->`
- 注释不会显示在页面中
- 用于解释结构、标记模块、临时调试

**学习示例**

```html
<!-- 头部区域 -->
<header>
  <h1>我的网站</h1>
</header>
```

**应用场景**

- 团队协作
- 结构说明
- 暂时屏蔽一段代码进行排查

---

### 2.10 路径和 URL

**必须掌握**

- 相对路径：相对于当前文件
- 绝对路径 / 网络地址：完整 URL
- URL 常见出现场景：`a` 的 `href`、`img` 的 `src`、`iframe` 的 `src`

**学习示例**

```html
<img src="./assets/logo.png" alt="站点 logo" />
<a href="../day04/04_HTML常见的元素.md">上一份笔记</a>
<a href="https://www.example.com">官网</a>
```

**应用场景**

- 引入图片
- 页面跳转
- 跳转外部网站
- 资源引用

**为什么必须掌握**

- 很多初学者写不出效果，不是标签不会，而是路径写错了

## 3. 这些知识点也很重要，但可以分层学习

下面这些内容建议掌握到“理解并会查文档”的程度。

### 3.1 `iframe`

**建议掌握程度：理解**

作用：在当前页面中嵌入另一个页面。

**示例**

```html
<iframe src="https://www.example.com" width="600" height="400"></iframe>
```

**应用场景**

- 嵌入地图
- 嵌入第三方页面
- 嵌入视频播放页

**说明**

- 现代开发中会用到，但不属于 HTML 初学阶段最核心的内容

---

### 3.2 字符实体

**建议掌握程度：必须知道，常见的要记住**

当你想在网页中显示一些会被 HTML 误解析的字符时，需要用字符实体。

**常见实体**

- `&lt;` 表示 `<`
- `&gt;` 表示 `>`
- `&nbsp;` 表示空格
- `&amp;` 表示 `&`

**学习示例**

```html
<p>在 HTML 中，&lt;p&gt; 表示段落标签。</p>
```

**应用场景**

- 教学文档
- 展示代码片段
- 特殊字符显示

---

### 3.3 语义化

**建议掌握程度：必须理解**

语义化的核心是：

`用正确的标签做正确的事情。`

例如：

- 标题用 `h1-h6`
- 段落用 `p`
- 链接用 `a`
- 图片用 `img`

而不是全部都写成 `div`。

**应用场景**

- 团队协作时代码更容易读
- 更利于搜索引擎理解页面
- 更利于无障碍设备读取内容

**反例**

```html
<div>这是标题</div>
<div>这是正文</div>
```

**更好的写法**

```html
<h1>这是标题</h1>
<p>这是正文</p>
```

---

### 3.4 SEO 基础认知

**建议掌握程度：理解**

SEO 是搜索引擎优化。初学 HTML 时，不需要深挖算法，但要知道：

- 合理使用标题标签有帮助
- 页面标题 `title` 很重要
- 语义化结构更友好
- 图片 `alt` 有意义

**应用场景**

- 官网
- 博客
- 内容型网站
- 商品详情页

---

### 3.5 字符编码

**建议掌握程度：理解**

常见写法：

```html
<meta charset="UTF-8" />
```

作用：告诉浏览器网页文字使用什么编码方式，避免乱码。

**应用场景**

- 所有网页

**结论**

- 初学阶段直接统一使用 `UTF-8`

---

## 4. 初学 HTML 必须掌握到什么程度

如果你想进入下一阶段学习 CSS 和 JavaScript，HTML 至少要达到下面这个标准：

### 4.1 必须会默写

- HTML 基础文档结构
- `h1-h6`
- `p`
- `a`
- `img`
- `div`
- `span`
- 注释写法

### 4.2 必须会独立写

- 一个简单个人介绍页
- 一个新闻详情页
- 一个图文混排页面
- 一个带锚点跳转的目录页

### 4.3 必须能看懂并改动

- 别人写的基础 HTML 页面
- 图片路径
- 链接地址
- 标题层级
- `class` 和 `id`

---

## 5. 推荐学习顺序

建议按这个顺序学，效率更高：

1. HTML 是做什么的
2. HTML 基本文档结构
3. 标签、元素、属性
4. `h1-h6` 和 `p`
5. `a` 和 `img`
6. `div` 和 `span`
7. 注释、`class`、`id`
8. 路径和 URL
9. 字符实体
10. 语义化和 SEO 基础

## 6. 一组最实用的综合示例

下面这个例子把常见核心知识点串起来了：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>HTML 学习示例</title>
  </head>
  <body>
    <!-- 页面标题 -->
    <h1 id="top">HTML 学习示例</h1>

    <!-- 导航 -->
    <p>
      <a href="#intro">看简介</a>
      <a href="#image">看图片</a>
      <a href="https://developer.mozilla.org/" target="_blank">查文档</a>
    </p>

    <!-- 简介 -->
    <h2 id="intro">课程简介</h2>
    <p>
      HTML 负责网页的<span class="highlight">内容和结构</span>。
    </p>

    <!-- 图片 -->
    <h2 id="image">示例图片</h2>
    <img src="./assets/html.png" alt="HTML 示例图片" />

    <!-- 返回顶部 -->
    <p><a href="#top">返回顶部</a></p>
  </body>
</html>
```

这个示例涉及：

- 文档结构
- 标题
- 段落
- 链接
- 锚点
- 图片
- `id`
- `class`
- 注释

如果你能自己写出这个页面，说明 HTML 基础已经比较稳了。

## 7. 每个知识点的典型应用场景速查

| 知识点 | 典型场景 |
| --- | --- |
| `h1-h6` | 文章标题、模块标题、页面标题 |
| `p` | 正文段落、说明文字、简介内容 |
| `a` | 页面跳转、下载链接、站内导航 |
| `img` | 商品图、头像、插图、宣传图 |
| `div` | 页面分区、布局容器、卡片容器 |
| `span` | 局部高亮、价格、关键词强调 |
| `id` | 锚点定位、唯一标识 |
| `class` | CSS 样式复用、JS 选择器 |
| 注释 | 模块说明、团队协作、调试 |
| 字符实体 | 展示代码、特殊字符显示 |
| URL/路径 | 资源引用、页面跳转 |
| 语义化 | SEO、可维护性、无障碍 |

## 8. 给你的学习建议

### 8.1 第一阶段：先会写

不要一开始追求“全记住”，而是先能写出页面。

建议先反复练这几类小页面：

- 个人简介页
- 新闻详情页
- 商品介绍页
- 图文混排页

### 8.2 第二阶段：边写边记

常用标签写多了自然会记住，不常用的及时查 MDN 文档即可。

### 8.3 第三阶段：建立语义化意识

从一开始就养成习惯：

- 标题就用标题标签
- 段落就用 `p`
- 链接就用 `a`
- 图片就用 `img`

这会直接影响你后面写 CSS、JavaScript 的质量。

---

## 9. 最后总结

如果只用一句话概括 HTML 初学阶段最重要的任务，那就是：

`先学会用正确的标签，把网页内容有结构地表达出来。`

优先掌握下面这些内容：

- HTML 文档基础结构
- 标签、元素、属性
- `h1-h6`、`p`
- `a`、`img`
- `div`、`span`
- `id`、`class`
- 注释
- 路径和 URL
- 字符实体
- 语义化基础

这些内容掌握后，你就已经具备继续学习 CSS 和 JavaScript 的 HTML 基础了。
