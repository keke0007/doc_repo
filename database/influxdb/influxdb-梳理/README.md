## 笔记体例

- **就地标注**:正文里发现讲义错误时用 `⚠️` 标注当前位置
- **章末勘误小结**:每个主题最后一节是表格汇总所有错误,方便回看
- **ASCII 流程图**:跨组件/跨文件的数据流都用 ASCII 图描述
- **`⚠️` vs `💡` vs `✅`**:
  - `⚠️` 注意点 / 讲义错误
  - `💡` 补充经验
  - `✅` 讲义说法正确
