## 一、Matplotlib 核心体系

### 1.1 四层架构与对象关系

Matplotlib 采用分层设计，从高到低分为四个层级：

```
┌─────────────────────────────────────────────────────────┐
│ Layer 1: pyplot(状态机接口) - plt.plot()等快速函数     │
├─────────────────────────────────────────────────────────┤
│ Layer 2: Figure/Axes 对象模型 - 面向对象 API           │
│         ┌──────────────┐                                 │
│         │ Figure       │ (整个图表容器)                 │
│         ├──────────────┤                                 │
│         │ Axes(多个)   │ (坐标系/绘图区域)              │
│         └──────────────┘                                 │
├─────────────────────────────────────────────────────────┤
│ Layer 3: Axis/Spines/Ticks/Grid - 坐标轴元素           │
│         ├─ XAxis/YAxis (数值轴)                        │
│         ├─ Spines (上下左右框线)                        │
│         └─ Tick (刻度)                                 │
├─────────────────────────────────────────────────────────┤
│ Layer 4: Artist/Line2D/PathPatch - 图形绘制原语        │
│         └─ 所有可见元素的基类                           │
└─────────────────────────────────────────────────────────┘
```

### 1.2 两种 API 对比

#### 状态机 API (pyplot 接口)
```python
import matplotlib.pyplot as plt
# 隐式创建 Figure 和 Axes，维护全局状态
plt.figure(figsize=(9,6))
plt.plot([1,2,3], [1,4,9])
plt.xlabel('X轴')
plt.show()
```

#### 面向对象 API (推荐)
```python
import matplotlib.pyplot as plt
# 显式创建对象，更灵活
fig, ax = plt.subplots(figsize=(9,6))
ax.plot([1,2,3], [1,4,9])
ax.set_xlabel('X轴')
plt.show()
```

> ⚠️ **原文有误**：plt.figure() 不返回 Axes 对象，只返回 Figure 对象。要获取 Axes 需调用 plt.gca()、plt.subplot() 或使用 fig.add_subplot()。

### 1.3 绘图调用流程

从用户代码到最终渲染的流转过程：

```
┌─────────────────────────────────────┐
│ 用户代码                             │
│ ax.plot([1,2,3], [1,4,9])           │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│ Axes 层                              │
│ - 创建 Line2D Artist 对象            │
│ - 设置坐标系范围                     │
│ - 维护子 Artist 列表                 │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│ Artist 层                            │
│ - Line2D 对象包含路径数据           │
│ - 颜色、线型、线宽等属性            │
│ - draw() 方法准备渲染                │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│ Renderer 层                          │
│ - 选择后端 (Agg/PDF/PS等)          │
│ - 栅格化/矢量化路径                 │
│ - 输出到文件/屏幕                    │
└─────────────────────────────────────┘
```

### 1.4 subplot 与 GridSpec 布局

#### 方法 1：subplot() 网格划分
```python
ax1 = plt.subplot(2, 3, 1)  # 2行3列的第1个
ax2 = plt.subplot(2, 3, 2)
# 缺点：只支持规则网格
```

#### 方法 2：GridSpec 灵活跨越
```python
import matplotlib.gridspec as gridspec
fig = plt.figure()
gs = gridspec.GridSpec(3, 3)
ax1 = fig.add_subplot(gs[0, :])      # 占第1行所有列
ax2 = fig.add_subplot(gs[1:, :2])    # 占第2-3行前2列
ax3 = fig.add_subplot(gs[1:, 2])     # 占第2-3行第3列
```

## 二、Seaborn 高级可视化

### 2.1 Seaborn 与 Matplotlib 的关系

```
Seaborn (高级接口)
    ↓
  基于 Matplotlib
    ↓
更好的美学 + 统计图表 + 调色板
```

Seaborn 是 Matplotlib 的上层包装，提供：
- 更美观的默认主题
- 整合统计计算
- 多变量关系图表
- 简化的调色板管理

### 2.8 多图组合 (FacetGrid/PairGrid/JointGrid)

#### FacetGrid - 数据切分多图

```
┌─────────────────────────────────────┐
│ 输入数据集                           │
├─────────────────────────────────────┤
│ FacetGrid(data, col='day', row='sex')
├─────────────────────────────────────┤
│ 1. 按 col/row 切分数据              │
│ 2. 为每个子集创建 Axes              │
│ 3. 同一行共享 Y轴，同一列共享 X轴   │
├─────────────────────────────────────┤
│ .map(sns.scatterplot, x='x', y='y')│
│ 4. 在每个 Axes 绘制                 │
│ 5. 统一坐标范围                     │
└─────────────────────────────────────┘
```

```python
g = sns.FacetGrid(data=df, col='time', row='day', height=4)
g.map(sns.scatterplot, 'total_bill', 'tip')
```

#### PairGrid - 成对变量矩阵
```python
g = sns.PairGrid(df[['total_bill', 'tip', 'size']])
g.map_upper(sns.scatterplot)
g.map_lower(sns.regplot)
g.map_diag(sns.histplot)
```

#### JointGrid - 联合分布
```python
g = sns.JointGrid(data=df, x='total_bill', y='tip', kind='hex')
# kind: 'scatter', 'hex', 'kde', 'reg' 等
```

> ⚠️ **原文有误**：jointplot() 是便捷函数返回 JointGrid 对象，与 JointGrid 类区别在于 jointplot() 直接绘制，JointGrid 需显式 .plot()。

## 三、常见错误纠正总结

| 错误 | 正确做法 |
|------|--------|
| plt.figure() 返回 Axes | plt.figure() 仅返回 Figure，需用 gca()/subplot() 获取 Axes |
| plt.plot() 作用到全局状态 | 推荐使用 ax.plot() 面向对象 API |
| distplot() 仍可用 | distplot() 已废弃，改用 displot()/histplot() |
| jointplot() 等同 JointGrid | jointplot() 是便捷函数，JointGrid 是类，功能和返回值不同 |
| color_palette() 改变全局 | set_palette() 改全局，color_palette() 仅返回列表 |
| tight_layout 与 constrained_layout 混用 | 两者冲突，选一种使用 |
| figure() 不返回 Axes | 需显式 gca() 或用 subplots() |
| Seaborn displot 自动绘制 | 若不显示，检查 plt.show() 或运行环境 |
