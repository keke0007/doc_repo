# python3 List 和 Tuple 知识点梳理

> 原文档:`python/Article/PythonBasis/python3/List.md`、`tuple.md`
> 整理对象:列表(list)与元组(tuple)的本质区别、增删改查、内置方法

---

## 一、List 列表

### 1. 本质

- 可变(mutable)、有序、可重复、元素类型可异质的序列。
- 用方括号包围,逗号分隔:`[1, 2, 'a', [3, 4]]`。
- 空列表:`[]` 或 `list()`。

### 2. 索引与切片

- 索引从 `0` 开始,**负数从右往左数**:`name[-1]` 是最后一个。
- 切片 `name[start:stop:step]`:**左闭右开**,可省略任一参数。

```python
name = ['一', '二', '三', '四', '五']
name[2]        # '三'
name[-1]       # '五'
name[0:2]      # ['一', '二']
name[:]        # 全切片,得到副本(浅拷贝)
name[::-1]     # ['五','四','三','二','一'] 反转
name[::2]      # ['一','三','五'] 步长 2
```

### 3. 增删改查方法对照

| 操作 | 写法 | 备注 |
|------|------|------|
| 末尾追加 | `lst.append(x)` | 加 1 个元素;若 `x` 是序列,整体当 1 个元素 |
| 批量追加 | `lst.extend(seq)` | 把 `seq` 的元素挨个加入,等价于 `lst += list(seq)` |
| 任意位置插入 | `lst.insert(i, x)` | `i` 越界时夹到首/尾,不报错 |
| 索引赋值 | `lst[i] = x` | 越界报 `IndexError` |
| 索引删 | `del lst[i]` 或 `lst.pop(i)` | `pop` 返回被删元素,`pop()` 默认删末尾 |
| 按值删 | `lst.remove(x)` | 只删 **第一个** 匹配,不存在报 `ValueError` |
| 清空 | `lst.clear()` | 等价 `del lst[:]` |
| 排序 | `lst.sort(key=None, reverse=False)` | **原地修改**;非破坏性用 `sorted(lst)` |
| 反转 | `lst.reverse()` | 原地反转;非破坏性用 `reversed(lst)`(返回迭代器) |
| 查找 | `lst.index(x)`、`x in lst` | `index` 找不到抛错;`in` 返回 bool |
| 计数 | `lst.count(x)` | 出现次数 |
| 长度 | `len(lst)` | — |
| 最大/最小/求和 | `max/min/sum(lst)` | 元素需可比较 |

### 4. 列表运算符

- `+` 连接,返回 **新列表**(不修改原列表)。
- `*` 重复,返回新列表。
- `in` / `not in` 成员检测,O(n)。

> ⚠️ 原文错误一(`List.md` 表第 225 行)
> 原文写 `for x in [1, 2, 3]: print x,` 这是 **Python 2 的 print 语句**。
> **Python 3 写法**:`for x in [1, 2, 3]: print(x)`。

> ⚠️ 原文错误二(`List.md` 第 235 行)
> 原文写 `list(seq) | 将元组转换为列表`。
> **正确说法**:`list()` 接收 **任意可迭代对象**(iterable),不仅限元组。例如 `list('abc')` → `['a','b','c']`,`list(range(3))` → `[0,1,2]`。

> ⚠️ 原文错误三(`List.md` 第 244 行)
> 原文 `list.sort([func])` 的描述沿用 Python 2 的 `cmp` 函数风格。
> **Python 3 正确签名**:`list.sort(*, key=None, reverse=False)`。**`cmp` 参数已删除**。需要自定义比较时用 `functools.cmp_to_key(cmp_fn)` 包装后传给 `key`。

### 5. 列表的"浅拷贝陷阱"

```python
a = [[0]*3] * 2
# a == [[0,0,0],[0,0,0]] 看起来正常
a[0][0] = 9
# 但 a == [[9,0,0],[9,0,0]],两行竟然一起变!
```

原因:`*` 重复时把 **同一个** 内层 list 引用复制了多份。正确写法是 list comprehension:

```python
a = [[0]*3 for _ in range(2)]
```

## 二、Tuple 元组

### 1. 本质

- **不可变(immutable)、有序的序列**。
- 优势:可作为 `dict` 的 key、`set` 的元素;同样的数据比 list 更省内存、CPython 还有缓存优化。

### 2. 创建陷阱

| 写法 | 结果 |
|------|------|
| `()` | 空元组 |
| `(1,)` 或 `1,` | 单元素元组 |
| `(1)` | **不是元组**,就是整数 1 |
| `1, 2, 3` | `(1, 2, 3)` —— 元组的本体其实是 **逗号** 决定的,括号只是分隔 |
| `tuple([1,2,3])` | `(1, 2, 3)`,接收任意可迭代对象 |

### 3. "不可变"的真正含义

`tuple` 不可变 = **每个槽位指向哪个对象不可变**,**不是说指向的对象本身不可变**。

```python
t = (1, [2, 3])
t[1].append(4)
# t 变成 (1, [2, 3, 4])
# 因为列表自己是可变的,而 t 仍然指向同一个列表
```

#### ASCII:tuple 的"指向不变,内容可变"

```
t = (1, [2, 3])              修改 t[1].append(4) 后:

      ┌───┐                       ┌───┐
 t ─▶ │ • │ ─▶ int 1              │ • │ ─▶ int 1
      ├───┤                       ├───┤
      │ • │ ─▶ list[2,3]    t ─▶  │ • │ ─▶ list[2,3,4]  ← list 本身改了
      └───┘                       └───┘
       ↑                           ↑
       两个指针指向不变            两个指针仍然指向同一对象
```

> 提示:正是这个特性导致 `tuple` 中包含可变对象时不能用作 `dict` key,因为 `hash(t)` 会直接报错。

### 4. 元组的解包与多返回值

Python 函数返回"多个值"的本质就是返回一个 tuple,自动解包:

```python
def divmod_(a, b):
    return a // b, a % b      # 实际返回 tuple (a//b, a%b)

q, r = divmod_(10, 3)         # q=3, r=1
```

### 5. 内置/方法

| 名称 | 说明 |
|------|------|
| `len(t)` | 元素数 |
| `max/min/sum(t)` | 同 list |
| `t.count(x)` | 计数 |
| `t.index(x)` | 找索引 |
| `tuple(iterable)` | 任意可迭代对象 → 元组 |

Tuple **没有** `append/insert/remove/sort/reverse` 等会修改自身的方法。

## 三、List vs Tuple 速查

| 维度 | List `[]` | Tuple `()` |
|------|-----------|------------|
| 可变性 | 可变 | 不可变 |
| 性能 | 略慢、占内存稍多 | 略快、更省内存 |
| 字面值 | `[1, 2, 3]` | `(1, 2, 3)` 或 `1, 2, 3` |
| 单元素 | `[1]` | `(1,)`(必须带逗号) |
| 作 dict key | ❌ | ✅(前提元素都可哈希) |
| 适用场景 | 一组同质数据、需要增删 | 异构记录、坐标、函数多返回值 |
