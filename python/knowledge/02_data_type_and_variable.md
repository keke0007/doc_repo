## 一、语法基本规则

| 规则 | 说明 |
|------|------|
| 缩进 | **强制 4 空格缩进**(不是装饰,缩进就是代码块边界) |
| 冒号 | `if / for / while / def / class / try / with` 等以 `:` 结尾,后续缩进块即语句体 |
| 大小写敏感 | `name` ≠ `Name` ≠ `NAME` |
| 注释 | `#` 单行;**Python 没有官方的块注释语法**,字符串字面值常被当作"块注释"实际是表达式语句 |
| 一行一语句 | 一行写一条;长行可用 `()` 隐式换行或 `\` 续行 |

> ⚠️ 原文错误一(`Grammar.md` 第 5 行)
> 原文写"编辑器或者解析器根据符合语法的程序代码转换成 CPU 能够执行的机器码"。
> **正确说法**:CPython 把源码先编成 **字节码(`.pyc`)**,再由 PVM 解释执行;字节码 ≠ CPU 机器码。

## 二、`print()` 函数

### 1. 基本形态

```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```

- 多个对象用逗号分开,默认空格分隔:`print('a', 'b')` → `a b`。
- 自定义分隔符:`print('a', 'b', sep='-')` → `a-b`。
- 自定义结束符:`print('a', end='')` 不换行。
- 重定向到文件:`print('msg', file=fp)`。
- 强制刷新缓冲:`print('x', flush=True)`(交互/日志场景常用)。

### 2. 单引号还是双引号

Python 中 `'abc'` 与 `"abc"` 完全等价,**只是写法不同,不是不同类型**。

## 三、基本数据类型

### 1. 数字

| 类型 | 字面值 | 说明 |
|------|--------|------|
| `int` | `1`、`-100`、`0xFF`、`0b1010`、`0o17` | **任意精度整数**,没有溢出 |
| `float` | `3.14`、`1e-5` | IEEE 754 64-bit 双精度 |
| `complex` | `1+2j`、`complex(1, 2)` | 复数 |
| `bool` | `True` / `False` | **是 `int` 的子类**,`True == 1`,`False == 0` |

> ⚠️ 原文错误二(`Type_conversion.md` 第 21 行)
> 原文写"在 Python 3 里,只有一种整数类型 int,**表示为长整型**"。
> **正确说法**:Python 3 中 `int` 就叫 `int`,**没有"长整型"概念**(那是 Python 2 的 `long`,3.0 起合并为单一的 `int`,任意精度)。

### 2. 字符串 str

- 三种引号:`'abc'`、`"abc"`、`'''abc'''`(也可以 `"""abc"""`),都是同一种 `str` 类型。
- **三引号** 允许跨行;单/双引号字符串内含同种引号要用 `\` 转义或换另一种引号。
- 字符串是 **不可变** 序列。

### 3. None

- 空值,**整个程序只有一个 `None` 对象**。判断写 `if x is None:`,不要写 `if x == None:`。

### 4. 布尔运算

- `and / or / not` 是 **短路求值**:`a and b` 在 `a` 为假时直接返回 `a`,不再求 `b`。
- 真值规则:`0`、`0.0`、`''`、`[]`、`{}`、`()`、`None`、`False` 都为假,其余为真。

### 5. 算术运算符

| 运算符 | 含义 | 例 |
|--------|------|----|
| `+ - * /` | 加减乘除 | `1/2 == 0.5`(总返回 float) |
| `//` | 整除(向下取整) | `7 // 2 == 3`;**`-7 // 2 == -4`**(向下,不是向零截断) |
| `%` | 取模 | 结果与除数同号:`-7 % 2 == 1` |
| `**` | 幂 | `2 ** 10 == 1024`;支持 `pow(2, 10, 1000)` 取模幂 |

### 6. f-string(3.6+,3.12 增强)

```python
name = '小明'; age = 18
f'{name}-{age}'             # 拼接
f'{name=}'                  # 3.8+ 自调试,输出 name='小明'
f'{3.14159:.2f}'            # 保留 2 位小数
f'{1234567:,}'              # 千分位
f'{0.875:.1%}'              # 87.5%
f'{name:>10}'               # 右对齐 10 列
```

3.12 起(PEP 701)允许内外引号相同,可在 `{}` 内写多行表达式、注释、反斜杠。

## 四、字符串编码

### 1. 历史脉络

```
ASCII (1B, 0~127) ──┐
GB2312 / GBK ───────┼─→  Unicode(统一码,只规定"码点")
ISO-8859-X 等本地 ──┘                │
                                     ├── UTF-8(变长,1~4 字节,兼容 ASCII,Web/源码默认)
                                     ├── UTF-16(2 或 4 字节)
                                     └── UTF-32(定长 4 字节)
```

### 2. Python 3 的核心规则

- **`str` 是 Unicode 码点序列**,内存中由 CPython 自动选最紧凑的 1/2/4 字节宽度(PEP 393)。
- **`bytes` 是字节序列**,用 `b'...'` 表示。
- 互转:`s.encode('utf-8')` → bytes;`b.decode('utf-8')` → str。
- 源文件默认 UTF-8(PEP 3120),**无需** `# -*- coding: utf-8 -*-`。

> ⚠️ 原文错误三(`Type_of_data.md` 第 9 行 / `StringCoding.md` 第 9 行)
> 原文写"Unicode 通常用两个字节表示一个字符"。
> **正确说法**:
> 1. **Unicode 本身只是"码点表",不规定存储格式**;存储靠 UTF-8 / UTF-16 / UTF-32 等编码。
> 2. 码点范围 `U+0000 ~ U+10FFFF`,需要 **21 位**,2 字节装不下。
> 3. "两个字节"是 90 年代早期的 UCS-2 假设(BMP 范围),早就过时。

> ⚠️ 原文错误四(`StringCoding.md` 第 19~22 行)
> `# -*- coding: utf-8 -*-` 在 Python 3 中 **无需** 再写,源文件默认就是 UTF-8(PEP 3120)。仅当确需非 UTF-8 编码才需要这行声明。

### 3. shebang

`#!/usr/bin/env python3` 是给 **Unix-like 系统的 shell** 看的,告诉它用 `python3` 执行该脚本(配合可执行权限 `chmod +x`)。Windows 忽略。

## 五、类型转换

| 函数 | 作用 | 注意 |
|------|------|------|
| `int(x)` / `int(s, base)` | 转 int | `int('88.88')` 报错;`int(88.88)` → 88(**向零截断**,非四舍五入) |
| `float(x)` | 转 float | `float('inf')`、`float('nan')` 合法 |
| `complex(r, i)` | 复数 | — |
| `str(x)` | 转 str | 调用 `__str__` |
| `repr(x)` | 调试字符串 | 调用 `__repr__`,通常更精确 |
| `bytes(s, enc)` / `s.encode(enc)` | str → bytes | 必须指定编码 |
| `list(it)` / `tuple(it)` / `set(it)` / `dict(it)` | 序列/可迭代对象互转 | — |
| `chr(i)` | 码点 → 单字符 | `chr(0x4e2d)` → '中' |
| `ord(c)` | 单字符 → 码点 | `ord('中')` → 20013 |
| `hex(n)` / `oct(n)` / `bin(n)` | 进制转字符串 | 返回带 `0x/0o/0b` 前缀的字符串 |
| `eval(s)` | 执行表达式字符串 | **危险**,绝对不要对不可信输入用 |

> ⚠️ 原文错误五(`Type_conversion.md` 第 16 行)
> 原文列了 `unichr(x)`。
> **正确说法**:`unichr` 是 **Python 2 专属**,Python 3 已经合并为 `chr()`。本表不应再出现 `unichr`。

> ⚠️ 原文错误六(`Type_conversion.md` 第 77 行)
> 原文写 `int(88.88)` "做取整处理,只取整数部分。所以输出的结果为 88"。
> **正确说法**:`int(浮点)` 是 **向 0 截断**,不是数学意义的取整。`int(-88.88)` 结果是 `-88` 而不是 `-89`。需要"向下取整"用 `math.floor`,需要"四舍六入"用 `round`。

## 六、变量

### 1. 命名规则

- 由字母、数字、下划线组成,**不能以数字开头**。
- 不能使用关键字(`for`、`class`、`import` 等)。
- **Python 3 允许 Unicode 字符做标识符**(PEP 3131),所以 `名字 = '小明'` 合法。但工程实践仍然推荐英文。

> ⚠️ 原文错误七(`Variable.md` 第 5 行)
> 原文说"变量名必须是 **大小写英文、数字和下划线** 的组合"。
> **正确说法**:Python 3(PEP 3131)起,标识符允许 Unicode 字母(如中文)。"必须是英文"已不准确,但 **强烈建议** 工程上仍然只用 ASCII。

### 2. 动态类型 vs 强类型

- **动态**:变量本身没有类型,只有它当前指向的对象有类型,可随时重指向其他类型。
- **强**:类型不会被隐式转换。`'1' + 1` 直接 `TypeError`,与 JavaScript 不同。

### 3. 变量的"指向"模型(关键)

Python 中赋值 **不是复制对象**,而是把名字绑定到对象。理解如下图:

```
代码:                    内存:
a = 'Hello Python'       ┌──────────────────┐
                  a ───▶ │ str:'Hello Python'│
                         └──────────────────┘

b = a                    ┌──────────────────┐
                  a ───▶ │ str:'Hello Python'│ ◀─── b
                         └──────────────────┘

a = 123                  ┌──────────────────┐
                  b ───▶ │ str:'Hello Python'│
                         └──────────────────┘
                         ┌──────┐
                  a ───▶ │ int:123│
                         └──────┘
```

最后 `print(b)` 输出 `Hello Python`,因为 b 仍然指向原字符串对象。

### 4. 多重赋值与解包

```python
a = b = c = 1             # 三个名字绑同一对象
a, b, c = 1, 2, 'x'       # 元组解包
a, b = b, a               # 交换,无需中间变量
first, *mid, last = [1,2,3,4,5]   # *捕获中间,得到 first=1, mid=[2,3,4], last=5
```

### 5. 可变 vs 不可变

| 类别 | 类型 |
|------|------|
| **不可变** | int / float / str / tuple / bool / bytes / frozenset / None |
| **可变** | list / dict / set / bytearray / 大多数自定义对象 |

可变对象的赋值/函数传参会影响所有引用者(详见 python6 函数传值)。
