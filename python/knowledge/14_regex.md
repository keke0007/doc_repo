## 一、模块与入口

```python
import re
```

### 1. 常用顶层函数

| 函数 | 行为 |
|------|------|
| `re.match(p, s)` | 从 **开头** 尝试匹配,匹配不到返回 None |
| `re.search(p, s)` | 扫描 **整个** 字符串,返回 **第一个** 匹配 |
| `re.findall(p, s)` | 返回 **所有** 匹配子串组成的列表 |
| `re.finditer(p, s)` | 返回 **迭代器**,每项是 Match 对象,适合大数据 |
| `re.fullmatch(p, s)` | 整个字符串都要匹配才返回 Match,部分匹配返回 None |
| `re.sub(p, repl, s, count=0)` | 替换 |
| `re.subn(p, repl, s)` | 替换并返回 `(新串, 替换次数)` |
| `re.split(p, s)` | 按模式切分 |
| `re.compile(p, flags=0)` | **编译** 为模式对象,反复使用同一模式时强烈推荐 |
| `re.escape(s)` | 把字符串中的元字符全部转义 |

### 2. `re.compile` 与缓存

```python
PHONE = re.compile(r'\d{3}-\d{4}-\d{4}')
PHONE.findall(text)
PHONE.search(text)
```

- 同一模式被多次使用时,`re.compile` 一次,后续直接 `.method()`,显著快。
- `re` 模块内部有自动缓存(最近 512 条),但显式 compile 仍然更清晰、性能更稳。

## 二、模式语法

### 1. 普通字符 vs 元字符

元字符:`. ^ $ * + ? { } [ ] ( ) | \`,需要表示字面值时用反斜杠转义。
**所有正则字符串都建议写成 raw 字符串 `r'...'`**,避免 Python 字符串自身的 `\` 转义把模式吃掉。

### 2. 字符集 `[]`

- `[abc]` —— a 或 b 或 c。
- `[a-z]` —— 任意小写字母。
- `[0-9a-fA-F]` —— 十六进制字符。
- `[^abc]` —— **非** abc;但必须匹配到 **一个** 字符。

### 3. 概括字符集

| 元字符 | 含义 | 等价(默认 ASCII 模式) |
|--------|------|----------------------|
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 单词字符 | `[A-Za-z0-9_]` |
| `\W` | 非单词字符 | `[^A-Za-z0-9_]` |
| `\s` | 空白 | `[ \t\n\r\f\v]` |
| `\S` | 非空白 | `[^ \t\n\r\f\v]` |
| `.` | 任意字符 | 默认不匹配 `\n`(除非 re.DOTALL) |

> ⚠️ 原文遗漏(`2.md` 全章)
> 原文示例 `re.findall('\d', a)`,`\d` 在普通字符串中 **会出现 DeprecationWarning(3.12+ 可能直接报错)**,因为 `\d` 不是 Python 字符串的有效转义。
> **正确写法**:总是用 raw 字符串 `r'\d'`。这是工程必备习惯。

### 4. 数量词

| 写法 | 含义 |
|------|------|
| `?` | 0 或 1 次 |
| `*` | 0 次或更多 |
| `+` | 1 次或更多 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

### 5. 贪婪 vs 非贪婪 vs 占有

| 写法 | 模式 |
|------|------|
| `*` / `+` / `?` / `{m,n}` | 贪婪(默认):尽量多匹配 |
| `*?` / `+?` / `??` / `{m,n}?` | 非贪婪(惰性):尽量少匹配 |
| `*+` / `++` / `?+` / `{m,n}+` | **占有(possessive),Python 3.11+ 才支持**(PEP 657 / `re` 模块更新),匹配后不回溯 |

> ⚠️ 原文遗漏
> 原文只讲了贪婪和惰性,没提 **占有量词**。在写复杂正则防止"灾难性回溯"时非常关键,Python 3.11+ 起可用。

### 6. 边界

| 元字符 | 含义 |
|--------|------|
| `^` | 字符串开头(多行模式下每行开头) |
| `$` | 字符串末尾(多行模式下每行末尾) |
| `\A` | 仅整串开头 |
| `\Z` | 仅整串末尾 |
| `\b` | 单词边界(`\w`/`\W` 交界) |
| `\B` | 非单词边界 |

### 7. 分组

| 写法 | 含义 |
|------|------|
| `(abc)` | 捕获分组,自动编号 1,2,3... |
| `(?:abc)` | **非捕获** 分组,只分组不留编号 |
| `(?P<name>abc)` | 命名分组,可用 `m.group('name')` 访问 |
| `(?P=name)` | 反向引用同名分组 |
| `\1`, `\2` ... | 数字反向引用 |
| `(?=abc)` | 正向前瞻(lookahead),不消费字符 |
| `(?!abc)` | 负向前瞻 |
| `(?<=abc)` | 正向后顾(lookbehind),固定宽度 |
| `(?<!abc)` | 负向后顾 |

### 8. flags 修饰符

| 标志 | 别名 | 作用 |
|------|------|------|
| `re.IGNORECASE` | `re.I` | 忽略大小写 |
| `re.MULTILINE` | `re.M` | `^`/`$` 匹配每行 |
| `re.DOTALL` | `re.S` | `.` 也能匹配换行 |
| `re.VERBOSE` | `re.X` | 允许多行书写、加注释、空白忽略 |
| `re.ASCII` | `re.A` | `\w \d \s` 只匹配 ASCII |
| `re.UNICODE` | `re.U` | 默认开启(Python 3) |

```python
phone = re.compile(r'''
    \b
    (\d{3})        # 区号
    -
    (\d{4})        # 中段
    -
    (\d{4})        # 末段
    \b
''', re.VERBOSE)
```

## 三、Match 对象

```python
m = re.search(r'<(\w+) src="(.+?)">', html)
if m:
    m.group(0)       # 整个匹配
    m.group(1)       # 第一组
    m.groups()       # ('img', 'http://...')
    m.start(), m.end()
    m.span()         # (start, end)
```

> ⚠️ 原文错误一(`6.md` 例子 `<img src="(.*)">`)
> 原文用 **贪婪 `.*`**,如果一行里有多个 `<img>` 会把它们全部吞掉。
> **正确做法**:用 **非贪婪 `.*?`**,或排除 `>`:`<img src="([^"]+)">`。

## 四、`re.sub` 替换

```python
re.sub(r'\*', '&', 'a*b*c')             # 替换所有 *
re.sub(r'\*', '&', 'a*b*c', count=1)    # 只替换第一个
re.sub(r'[\*-]', lambda m: {'*':'&','-':'|'}[m.group()], 'a*b-c')
```

`repl` 可以是字符串(支持 `\1` `\g<name>` 回引),也可以是函数(参数是 Match 对象)。

## 五、性能与陷阱

### 1. raw 字符串

```python
re.compile(r'\b\d+\b')         # ✅
re.compile('\\b\\d+\\b')       # ✅ 但难读
re.compile('\b\d+\b')          # ❌ \b 被 Python 解析成 \x08 退格符
```

### 2. 灾难性回溯

`(a+)+b` 类形式遇到不匹配字符串会指数级回溯。修复:
- 化简为非嵌套量词:`a+b`。
- 用占有量词(3.11+):`(a++)+b` 不回溯。
- 用 `regex` 第三方包(支持更多扩展)。

### 3. 编译一次,反复使用

热路径上避免每次都传字符串模式,先 compile。

### 4. `findall` 与分组的反直觉行为

如果 `pattern` 中包含分组:
- 一个分组:`findall` 返回 **分组列表**。
- 多个分组:返回 **元组列表**。
- 没有分组:返回 **整体匹配列表**。

```python
re.findall(r'(\d+)-(\d+)', '1-2, 3-4')   # [('1','2'), ('3','4')]
```

## 七、常见模式速查

| 用途 | 模式 |
|------|------|
| 中国大陆手机号 | `r'^1[3-9]\d{9}$'` |
| 邮箱(粗匹配) | `r'^[\w.+-]+@[\w-]+(\.[\w-]+)+$'` |
| URL(粗匹配) | `r'^https?://[\w./?%&=:#\-+]+$'` |
| IPv4 | `r'^(?:(?:25[0-5]\|2[0-4]\d\|[01]?\d?\d)\.){3}(?:25[0-5]\|2[0-4]\d\|[01]?\d?\d)$'` |
| 中文字符 | `r'[一-鿿]'` |
| 18 位身份证 | `r'^[1-9]\d{5}(18\|19\|20)\d{2}(0[1-9]\|1[0-2])(0[1-9]\|[12]\d\|3[01])\d{3}[\dXx]$'` |
| 整数 | `r'^-?\d+$'` |
| 浮点 | `r'^-?\d+(\.\d+)?$'` |

**注意**:任何"业务级"的校验都不要只靠正则,**最稳的还是配合具体业务规则**(例如手机号实际段位、邮箱发送验证邮件、身份证位验校验和等)。
