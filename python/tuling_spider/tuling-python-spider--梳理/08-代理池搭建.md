# 第 8 章 代理池搭建 — 知识点梳理

> 对应 8.1 ~ 8.2。代理池涉及"采集 → 校验 → 入库 → 取用"四个角色协作,附流程图。

---

## 1. 为什么需要代理

- 突破单 IP 频控/封禁(最主要原因)。
- 隐藏真实出口 IP。
- 切换地理位置访问区域受限内容。

⚠️ 原文"代理可提高访问速度,因为有缓存命中"——这是**正向代理 ≠ 加速器**。普通匿名代理不会加速,反而多了一跳;CDN/缓存代理才是加速场景,不要混淆。

---

## 2. 代理类型

| 类型 | 来源 | 稳定性 | 用途 |
|---|---|---|---|
| 开放/扫描代理 | 全网 nmap 扫端口 | 很差,90%+ 不可用 | 学习、压测 |
| 私密代理 | 服务商租机房/拨号 | 中高 | 中小爬虫 |
| 独享代理 | 私密的"专属"版 | 高 | 长期稳定/敏感业务 |
| 隧道代理 | 一个固定入口,出口 IP 服务端自动轮换 | 高,客户端只需配置一次 | 现代主流(推荐) |

按匿名度:**高匿(Elite) > 匿名(Anonymous) > 透明(Transparent)**。爬虫只用**高匿**——透明代理会在 `X-Forwarded-For`/`Via` 里暴露真实 IP。

## 3. 代理池架构 / 流程图

```
            ┌──────────────────┐
            │  采集器 fetcher  │  scrapy/requests 扒免费代理网或调付费 API
            └────────┬─────────┘
                     │ 原始 IP:PORT
                     ▼
            ┌──────────────────┐
            │  校验器 checker  │  并发请求 httpbin/anyip/目标站
            │  - 超时 < N 秒   │  - 检查匿名度(X-Forwarded-For)
            └────────┬─────────┘
                     │ 可用 IP+延迟+协议
                     ▼
            ┌──────────────────┐
            │  存储 Redis ZSET │  score = 可用度评分,定时衰减
            │  key: proxy:pool │
            └────┬─────────┬───┘
                 │         │
            取用 │         │ 定时复检
                 ▼         ▼
       ┌──────────────┐  ┌──────────────┐
       │ 业务爬虫使用 │  │  validator 巡检 │
       │ requests/.. │  └──────────────┘
       └──────────────┘
```

要点:**存储用 Redis ZSET**(`ZADD proxy:pool score member`),按分数取最稳的;失败 `-1`,成功 `+1`,跌到 0 删除。

## 4. 免费代理采集示例(可参考思路,**不建议生产用**)

```python
import re, requests

def get_kuaidaili(page):
    r = requests.get(f'https://www.kuaidaili.com/free/inha/{page}/',
                     headers={'User-Agent': '...'}).text
    data = re.findall(r'const fpsList = (.*?);', r)[0]   # 内嵌 JSON 字符串
    ips   = re.findall(r'"ip": "([\d.]+)"', data)
    ports = re.findall(r'"port": "(\d+)"', data)
    return list(zip(ips, ports))

def is_alive(ip, port):
    proxies = {
        'http':  f'http://{ip}:{port}',
        'https': f'http://{ip}:{port}',     # https 用 http 隧道(CONNECT)
    }
    try:
        return requests.get('http://httpbin.org/ip',
                            proxies=proxies, timeout=3).ok
    except Exception:
        return False
```

免费代理实际可用率往往 < 5%,**采集 1000 个能用 30 个就算高了**;不要靠免费 IP 跑生产爬虫。

## 5. 付费代理(推荐)

主流厂商:快代理、芝麻代理、青果、巨量、亮数据(Bright Data,海外)、Oxylabs(海外)。

两种交付方式:

```python
# A. API 取 IP 模式:每次提取若干 IP,自己维护
api = 'https://dps.kdlapi.com/api/getdps/?secret_id=...&num=1&pt=1&format=text&sep=1'
ip = requests.get(api).text.strip()
proxies = {'http': f'http://{ip}', 'https': f'http://{ip}'}

# B. 隧道代理:一个固定入口,服务端自动换出口
proxies = {
    'http':  'http://user:password@tunnel.host.com:15818',
    'https': 'http://user:password@tunnel.host.com:15818',
}
```

带认证的 socks5:`pip install requests[socks]`,然后 `socks5://user:pass@host:port`。

## 7. 校验:不仅要"通",还要"匿"

```python
r = requests.get('http://httpbin.org/get', proxies=p, timeout=5).json()
print(r['origin'])           # 出口 IP,应等于代理 IP
print(r['headers'].get('X-Forwarded-For'))  # 高匿应没有这个头
```

进阶:对目标网站测试(同样请求带与不带代理对比),因为有的网站会拒绝公共代理段。

## 8. 当当案例的关键设计模式(原文 8.2)

四队列流水线 + 多线程,本质是第 6 章生产者-消费者模型 + 代理池:

```
[fetch_proxy → ip_queue] ─▶ [request_worker(取ip+取url) → response_queue]
                                          │
                                          ▼
                                 [parse_worker → detail_queue]
                                          │
                                          ▼
                                       [save_worker]
```

关键 `stop_event = threading.Event()` 用于多线程协同退出。

## 9. 原文需要纠正/补充的点

| # | 原文 | 问题 | 正确做法 |
|---|------|------|---------|
| 1 | "代理可以提高访问速度,代理服务器会缓存" | 概念混淆:普通正向代理**不会**加速;只有 CDN/HTTP 缓存代理才加速 | 介绍代理时应只强调"突破频控/封禁、隐藏 IP",不要说提速 |
| 2 | 大量免费代理网站列出(西刺/快代理/66ip…) | 西刺 2021 已关停,多数免费源近年陆续下线 | 仅作历史参考,实际优先付费 |
| 3 | "私密代理…支持 Http/Https/**Scoks5**" | 拼写错误 | 应是 **SOCKS5** |
| 4 | 校验 url 只用 `http://httpbin.org/ip` | 该域名国内访问慢,且不能测匿名度 | 加 `https://httpbin.org/get` 或自建检测端点;读取 `X-Forwarded-For`/`Via` 判断匿名度 |
| 5 | 代理字典 `{'http': 'http://ip:port', 'https': 'http://ip:port'}` | OK,但容易困惑:**https 走 http 隧道(CONNECT)是正确写法** | 不要写成 `'https': 'https://...'`,除非代理本身就是 HTTPS 入口 |
| 6 | 免费代理示例直接保存可用 IP 到 `success_ip.txt` | 文件不利于并发取/淘汰 | 改 Redis ZSET 持续维护 |
| 7 | 当当案例 `self.ip_url` 暴露 secret_id/signature | 代码示例泄露真实凭证(原文为示意,但容易被照搬) | 实际应放环境变量/配置中心,不写进代码库 |
| 8 | 仅 try/except 笼统抓异常 | 看不出问题原因 | 区分 `Timeout`、`ProxyError`、`ConnectionError` 分别处理 |
| 9 | 未提到代理 **会话粘性**(sticky) | 大量场景(如京东加购物车)需要同一 IP 多请求 | 隧道代理选 sticky 模式或自管"一会话一 IP" |
| 10 | 无失败惩罚机制 | 烂 IP 不会被淘汰 | Redis ZSET 上分数失败 `-1`,达到阈值 `ZREM` 删除 |

---

## 10. 速记

- 代理只解封禁/限频,不要指望它"加速"。
- 高匿 = 不带 `X-Forwarded-For` 等头;校验是必修。
- Redis ZSET 是代理池存储的最优解(分数即可用度)。
- 免费代理用于学习,生产请用付费**隧道**代理。
- 凭证别硬编码,放 env / secret manager。
