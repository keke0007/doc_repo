## 1. 为什么用浏览器自动化

应对 **JS 渲染、Ajax 加密、复杂登录** 等场景:直接驱动真实浏览器执行 JS,绕过纯 `requests` 难以处理的反爬。

| 框架 | 定位 | 关键词 |
|---|---|---|
| Selenium | 老牌、跨语言、生态全 | WebDriver、CDP、需驱动 |
| DrissionPage | 国产、纯 Python、控浏览器+收发包合二为一 | ChromiumPage / SessionPage / WebPage |
| Playwright | 新一代,自带浏览器 | 异步、自动等待(本章未涉,推荐了解) |

## 3. 调用流程图(Selenium)

```
 ┌─────────────────────┐
 │ Python 脚本         │
 │ webdriver.Chrome()  │
 └──────────┬──────────┘
            │ 启动 chromedriver.exe(本地子进程)
            ▼
 ┌─────────────────────┐    JSON over HTTP(W3C WebDriver)
 │   chromedriver       │ ◀──────────────────────────────▶ Python(selenium 客户端)
 └──────────┬──────────┘
            │ Chrome DevTools Protocol
            ▼
 ┌─────────────────────┐
 │   Chrome 浏览器     │
 │   (真实渲染、执行JS)│
 └──────────┬──────────┘
            │ HTTP/HTTPS
            ▼
        目标网站
```

数据流:Python → driver → 浏览器 → 页面;命令走 W3C WebDriver,driver 翻译成 CDP 控制浏览器。

## 4. 基本使用

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

browser = webdriver.Chrome()
browser.get('http://www.baidu.com')
browser.save_screenshot('a.png')

browser.find_element(By.ID, 'kw').send_keys('java')
browser.find_element(By.ID, 'su').click()

print(browser.page_source)   # 渲染后的 HTML
print(browser.current_url)   # 经重定向后的真实 URL
print(browser.get_cookies()) # list[dict]
```

`close()` 关当前标签页;`quit()` 退出整个浏览器并清理 driver 进程(更推荐)。

## 5. 多标签页切换

```python
browser.execute_script("window.open('http://www.sogou.com')")
handles = browser.window_handles          # 所有句柄列表
browser.switch_to.window(handles[1])      # 切到第 2 个

# 更稳妥:按 title 或 url 切换,避免顺序错乱
for h in browser.window_handles:
    browser.switch_to.window(h)
    if '搜狗' in browser.title:
        break
```

要点:句柄顺序不一定 = 打开顺序(页面加载快慢可能调换),用 **title/URL 做识别**比索引可靠。

## 6. 元素定位

```python
from selenium.webdriver.common.by import By
```

| 单/多 | 方法 |
|---|---|
| 单元素(返回 WebElement,失败抛 `NoSuchElementException`) | `find_element(By.X, '...')` |
| 多元素(返回 list,空列表代表未匹配,不抛异常) | `find_elements(By.X, '...')` |

`By` 取值:`ID / NAME / XPATH / LINK_TEXT / PARTIAL_LINK_TEXT / TAG_NAME / CLASS_NAME / CSS_SELECTOR`。

⚠️ `By.CLASS_NAME` 只能传**单个类名**,不支持空格分隔的多类(`'a b'` 会报错);多类用 CSS 选择器 `'.a.b'`。

## 7. 取数据 / 取属性

```python
el.text                       # 显示文本(只有可见部分)
el.get_attribute('href')      # 任意属性,含 dataset、value
el.get_property('value')      # JS 属性(input 实时值用这个更准)
```

`text` 与 `innerText` 接近,**对隐藏元素返回空**;若要不渲染就拿文本,用 `get_attribute('textContent')`。

## 8. Cookie

```python
browser.get_cookies()                                  # list[dict]
browser.add_cookie({'name': 'k', 'value': 'v'})        # 必须先 get 同域页面
browser.delete_cookie('k')
browser.delete_all_cookies()
{c['name']: c['value'] for c in browser.get_cookies()} # 转 dict 给 requests 用
```

⚠️ `add_cookie` 必须先访问对应域的页面,否则报错;原文 demo 在 `https://baidu.com` 后 add 是 ok 的。

## 9. 显式等待(推荐)

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(browser, 10)
el = wait.until(EC.presence_of_element_located((By.ID, 'key')))
el = wait.until(EC.element_to_be_clickable((By.ID, 'btn')))
```

三种等待:

- **隐式等待** `driver.implicitly_wait(10)`:全局生效,只对 `find_element` 起作用;不建议与显式等待混用。
- **显式等待** `WebDriverWait + EC`:针对单个条件,精确。
- **强制等待** `time.sleep(...)`:粗暴但万能,仅做调试用。

## 10. 动作链 ActionChains


## 12. 反检测 / 隐身

```python
options = webdriver.ChromeOptions()
options.add_argument('--disable-blink-features=AutomationControlled')
options.add_experimental_option('useAutomationExtension', False)
options.add_experimental_option('excludeSwitches', ['enable-automation'])

# 禁图(提速)
options.add_experimental_option('prefs',
    {"profile.managed_default_content_settings.images": 2})

# 自定义 UA
options.add_argument('user-agent=Mozilla/5.0 ...')

# 代理
options.add_argument('--proxy-server=http://127.0.0.1:7890')

browser = webdriver.Chrome(options=options)
```

更彻底的反检测:**`undetected-chromedriver`** 或 **`selenium-stealth`** 库,会把 `navigator.webdriver` 等指纹改干净。原文方案只能糊弄入门级反爬。

## 14. DrissionPage 三大对象

| 对象 | 等价于 | 说明 |
|---|---|---|
| `ChromiumPage` | Selenium | 控制 Chromium 浏览器 |
| `SessionPage` | requests.Session | 纯收发数据包,无浏览器 |
| `WebPage` | 二者合体 | `d` / `s` 双模可切换;新版作者已不推荐 |

```python
from DrissionPage import ChromiumPage
page = ChromiumPage()
page.get('https://www.baidu.com')
page.ele('#kw').input('jk')             # 简洁选择器:#id / .cls / @attr=val / xpath:.../...
page.ele('xpath://input[@id="su"]').click()
page.eles('xpath:...')                  # 复数
page.quit()
```

亮点:

- **接口监听**:`page.listen.start('/api/xxx')` → `page.listen.steps(count=N)` 直接拿 XHR/Fetch 响应体,**省去 JS 逆向**。
- **自动等待**:`ele` 默认带 timeout,无需 `WebDriverWait`。
- **下载器**:`page.download.add(url, save_path)` 并发下载。

```python
page.listen.start('/api/web/document/list')
page.get(url)
for item in page.listen.steps(count=10):
    print(item.response.body)
```

## 15. 原文需要纠正/补充的点

| # | 原文 | 问题 | 正确做法 |
|---|------|------|---------|
| 1 | "驱动下载后移动到 miniconda3 安装目录" | 实际是要在 PATH 中,miniconda3 目录只是恰好在 PATH | 放进 PATH 的任意目录;或使用 Selenium Manager 自动管理 |
| 2 | Selenium 锁定 4.9.1 + 手动下驱动 | 4.6+ 已内置 Selenium Manager,可自动下载匹配驱动 | 新项目直接 `pip install selenium`,不传 `executable_path` 即可 |
| 3 | "`close()` 让浏览器退出(只有 1 个页面时)" | 准确但易误用 | 推荐用 `quit()` 关整个 driver,避免 chromedriver 进程残留 |
| 4 | `find_element(By.CLASS_NAME, '...')` 传多类名 | CLASS_NAME 只支持单个类名 | 用 `By.CSS_SELECTOR, '.a.b'` |
| 5 | 7.4 cookie 案例 `add_cookie` 之前已 `browser.get('http://www.baidu.com')` | OK,但未强调必须先访问同域页面 | 否则 `InvalidCookieDomainException` |
| 6 | 7.2 `browser.close()` 之后又 `browser.quit()` | close 后 session 还在,quit 才彻底 | 一般直接 quit 即可,无需先 close |
| 7 | 反爬绕过仅用 `--disable-blink-features=AutomationControlled` | 现在大站点会探 `navigator.webdriver`、`window.chrome`、字体指纹等多维 | 推荐 `undetected-chromedriver` / `selenium-stealth` |
| 8 | 唯品会案例 `cookies = {...}`(硬编码他人 cookie) | cookie 是会失效的会话凭证,且属于他人账号信息 | 实际工作中应自动登录获取,或用接口监听拿数据 |
| 9 | 7.4 强制等待都用 `time.sleep` | 不稳健 | 优先 `WebDriverWait + expected_conditions` |
| 10 | "presence_of_element_located 判定元素是否存在" | 完整说法是"DOM 中存在",**不保证可见/可点击** | 点击场景应用 `element_to_be_clickable`,可见场景用 `visibility_of_element_located` |
| 11 | 7.6 `page.ele('@value=百度一下')` 的简洁选择器规则未说明 | DrissionPage 自有的 mini-DSL | `#id` / `.class` / `@attr=val` / `tag:xxx` / `text=xxx` / `xpath:...` / `css:...` |
| 12 | WebPage `mode='d'` / `mode='s'` 双模 | 作者新版已"刻意淡化" | 选定一个 `ChromiumPage` 或 `SessionPage`,不要再依赖 WebPage |
| 13 | 小红书评论脚本 `ele('.cover ld mask')` 多个 class 用空格 | DrissionPage 简洁选择器中空格被当作 "**或**",可能拿到一堆元素 | 用 `css:.cover.ld.mask`(连写=且) |
| 14 | 项目实战里 `cls.browser.close()` 翻页失败时调 | 同上 close vs quit 问题 | 改 quit;另注意 `NoSuchElementException` 之外可能还会抛 `StaleElementReferenceException` |

## 16. 速记

- 真实浏览器 → Selenium / DrissionPage;能拿 API 就走 API,不要无脑驱动浏览器。
- 等待三件套:隐式(全局)、显式(`WebDriverWait`,推荐)、强制(`time.sleep`,慎用)。
- 找元素:`By.ID > CSS > XPATH`,稳定性优先;多类名用 CSS。
- DrissionPage 王牌技能:`page.listen` 直接捞 API,省 JS 逆向。
- 反检测要从指纹层做,不止 `--disable-blink-features`;考虑 undetected-chromedriver。
- 用完 `browser.quit()`,避免 chromedriver 残留。
