## 1. Python re 模块全家桶

| 函数 | 作用 | 返回 |
|---|---|---|
| `re.match(p, s)` | 从字符串**起始**匹配 | Match 或 None |
| `re.search(p, s)` | 找第一个匹配 | Match 或 None |
| `re.findall(p, s)` | 找所有匹配 | list(无分组→字符串列表;有分组→元组列表) |
| `re.finditer(p, s)` | 迭代器版 findall | iterator[Match] |
| `re.sub(p, repl, s)` | 替换 | str(repl 可为函数) |
| `re.subn(p, repl, s)` | 替换并返回次数 | (str, count) |
| `re.split(p, s)` | 按模式切分 | list[str] |
| `re.compile(p)` | 预编译,提高重复使用性能 | Pattern |

**强烈建议**:正则字符串前缀 `r'...'`(raw string),避免反斜杠双重转义。

## 2. 元字符总表

```
.  匹配除换行外的任意一个字符(DOTALL 下含换行)
\  转义
^  行首(单行模式=整串首,多行模式=每行首)
$  行尾
*  >=0 次
+  >=1 次
?  0 或 1 次,或将量词改为非贪婪
{n} {n,} {n,m}  精确次数
[]  字符集合;[^...] 取反
|  或(优先级最低)
() 分组(捕获);(?:...) 非捕获;(?P<name>...) 命名捕获;(?P=name) 反向引用
\d \D \s \S \w \W   数字/非数字/空白/非空白/单词/非单词
\b \B  单词边界 / 非边界
```

---

## 3. 贪婪 vs 非贪婪

默认贪婪:`*`、`+`、`?`、`{n,m}` 都尽量多吃。加 `?` 变非贪婪:`*?`、`+?`、`??`、`{n,m}?`。

```python
re.findall(r'<.*>',  '<a>x<b>')   # ['<a>x<b>']  贪婪
re.findall(r'<.*?>', '<a>x<b>')   # ['<a>', '<b>']  非贪婪
```

## 4. 模式标志(flags)

| 标志 | 简写 | 含义 |
|---|---|---|
| `re.IGNORECASE` | `re.I` | 忽略大小写 |
| `re.MULTILINE` | `re.M` | `^`/`$` 按行匹配 |
| `re.DOTALL` | `re.S` | `.` 匹配换行 |
| `re.UNICODE` | `re.U` | (Py3 默认开启) |
| `re.VERBOSE` | `re.X` | 允许多行 + 注释正则 |

多标志组合:`re.I | re.M`。

## 5. 分组与命名分组

```python
m = re.search(r'(\w+)@(\w+)', 'foo@bar')
m.group(0)   # 整体 'foo@bar'
m.group(1)   # 'foo'
m.group(2)   # 'bar'
m.groups()   # ('foo', 'bar')

# 命名分组
m = re.search(r'(?P<user>\w+)@(?P<host>\w+)', 'foo@bar')
m.group('user'), m.group('host')

# 非捕获分组,只分组不抓
re.findall(r'(?:\d{3})-(\d{4})', '010-1234')   # ['1234']
```

⚠️ `findall`:若正则有 1 个分组,返回该分组的字符串列表;有 ≥2 个分组,返回元组列表;**没有分组**才返回整体匹配的字符串列表。这是初学者最常踩的坑。

## 6. `sub` 替换 + 函数

```python
def repl(m):
    n = int(m.group(1)) + 6
    return f'/av{n}/'

re.sub(r'/av(\d+)/', repl, text)
```

`repl` 接收 `Match` 对象,返回值就是替换字符串。还支持 `\g<1>` / `\g<name>` 反向引用:

```python
re.sub(r'(\w+) (\w+)', r'\2 \1', 'hello world')   # 'world hello'
```

## 7. 常用预定义正则

| 需求 | 正则 |
|---|---|
| 整数 | `^-?\d+$` |
| 小数 | `^-?\d+(\.\d+)?$` |
| 中国手机号 | `^1[3-9]\d{9}$` |
| 邮箱(简易) | `^[\w.\-]+@[\w\-]+(\.[\w\-]+)+$` |
| IPv4 | `^(?:\d{1,3}\.){3}\d{1,3}$` |
| URL | `https?://[^\s"']+` |
| 中文 | `[一-龥]+` |
| 日期 YYYY-MM-DD | `^\d{4}-\d{2}-\d{2}$` |

## 8. 原文需要纠正/补充的点

| # | 原文 | 问题 | 正确版本 |
|---|------|------|---------|
| 1 | "在 `find_all` 方法中的字符串其实就是正则表达式"(4.1) | 拼写/概念混淆:`re.findall` 不是 `find_all` | 应明确是 **`re.findall`**(re 模块函数),`find_all` 是 bs4 的方法 |
| 2 | 4.3 大量代码块中 HTML 标签被 Markdown 渲染吃掉,导致很多正则示例(如 `<.*>`、`<.+?>`)在原文里看不到 | 转写损坏 | 实际写法应保留尖括号,如 `re.findall(r'<.*?>', source)` |
| 3 | `(?P...)` 缺写法 | 命名分组缺了 `<name>` | 正确为 `(?P<name>...)`,反向引用 `(?P=name)` |
| 4 | "`*` 前面不一定是 `.`,也可以是其他字符" | 描述模糊 | 强调 `*/+/?` 量词作用于**前一个原子**(字符、字符类、分组等) |
| 5 | "竖线 `|` 优先级最低" | 对的 | 补充:需要约束范围用括号,如 `(绿|橙)色` |
| 6 | 元字符列表 `. * + ? \ [] ^ $ {} | ()` 漏掉了 `-`(字符类内)、`/`(部分语言里) | Python 中常见 12 个元字符,加上 `-` 在 `[]` 内的范围意义 | 中括号内特殊:`^`(开头取反)、`-`(范围)、`]`(闭合)、`\`(转义) |
| 7 | 4.3 案例 "薪资提取" `r'([\d.]+)万/每{0,1}月'` | 写法对但啰嗦 | 等价于 `([\d.]+)万/每?月`,`{0,1}` ≡ `?` |
| 8 | `re.M` 解释为"多行模式 → ^/$ 按行" | 对,但要补充:`re.M` 不影响 `.` 的换行行为(那是 `re.S`) | 二者职责分离,不要混淆 |
| 9 | re.findall 返回字符串列表 | 仅在无捕获组时成立 | 见 §5 的坑点说明 |

---

## 9. 速记

- `re.S` 让 `.` 吃换行;`re.M` 让 `^$` 按行;两个标志独立。
- 贪婪 → 加 `?` 变非贪婪。
- 用分组就要意识到 `findall` 行为变化。
- 大量重复匹配先 `re.compile`。
- 提取 HTML **优先用 lxml/bs4**,正则只用于已经局部化的字符串。
