## 2. CSV 存储

```python
import csv

# 列表行
with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    w = csv.writer(f)
    w.writerow(['班级', '姓名'])
    w.writerows(rows)

# 字典行
with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    w = csv.DictWriter(f, fieldnames=['class_name', 'name'])
    w.writeheader()
    w.writerows(dict_rows)
```

### 必须强调的两个参数

- `newline=''`:Windows 下若不加,每行后多一个空行(原文代码不一致,有的加了有的没加)。
- `encoding='utf-8'`(或 `utf-8-sig` 让 Excel 正确识别 BOM)。

读取:`csv.reader` / `csv.DictReader`。

## 3. JSON 存储

```python
json.dump(obj, fp, indent=2, ensure_ascii=False)       # 写文件
data = json.load(fp)                                   # 读文件

# 仅做字符串
s = json.dumps(obj, indent=2, ensure_ascii=False)
obj = json.loads(s)
```

`ensure_ascii=False` 必加,否则中文变 `\uXXXX`。

## 4. MySQL(pymysql)基础

```python
import pymysql

db = pymysql.connect(host='127.0.0.1', port=3306,
                     user='root', password='root',
                     db='py_spider', charset='utf8mb4')   # 推荐 utf8mb4
cur = db.cursor()
cur.execute("INSERT INTO t(a,b) VALUES (%s,%s)", (1, 'x'))
db.commit()                # 写操作必须 commit
cur.close(); db.close()
```

要点:

- 占位符**永远用 `%s`**,**不要拼字符串**(防 SQL 注入);多参数用元组。
- 异常要 `rollback()`,然后回滚。
- 字符集用 `utf8mb4`(覆盖 emoji 与生僻字),不要用 `utf8`(MySQL 的 utf8 是 3 字节假 utf8)。

## 5. MySQL 连接池(DBUtils)

```python
from dbutils.pooled_db import PooledDB
import pymysql

pool = PooledDB(
    creator=pymysql,
    maxconnections=6,   # 池最大连接数
    mincached=2,        # 预先创建的空闲连接数
    maxcached=5,        # 池中最多空闲连接数
    blocking=True,      # 池满时是否阻塞等待
    host='127.0.0.1', port=3306,
    user='root', password='root',
    database='py_spider', charset='utf8mb4',
)

conn = pool.connection()      # 借连接(归还=close)
cur = conn.cursor()
cur.execute('SELECT * FROM t')
cur.close(); conn.close()     # 此 close 把连接还回池,不是真关闭
```

⚠️ 原文 `maxshared=3` + 注释"pymysql/mysqldb 不支持共享" — 对的;**maxshared 在这类驱动下设多少都无效**,知道即可。

## 6. MongoDB(pymongo)

```python
import pymongo

client = pymongo.MongoClient('mongodb://localhost:27017/')
db = client['py_spider']                  # 数据库
col = db['movies']                        # 集合
col.insert_one({'a': 1})
col.insert_many([{'a': 1}, {'b': 2}])
list(col.find({'a': 1}))
col.update_one({'a': 1}, {'$set': {'b': 9}})
col.delete_one({'a': 1})
```

集合无 schema、字段动态、文档即 dict;**主键 `_id`**(默认 ObjectId)。

## 7. 数据去重(Redis SET)

思路:对要入库的 dict 做 MD5,试塞 `SADD movie:filter <md5>`:返回 1 = 新加入(继续入库);返回 0 = 已存在(丢弃)。

```python
import hashlib, redis

r = redis.Redis(host='127.0.0.1', port=6379, db=0, decode_responses=True)

def md5(obj):
    return hashlib.md5(str(obj).encode('utf-8')).hexdigest()

def save(item):
    if r.sadd('movie:filter', md5(item)):    # 1=新加
        col.insert_one(item)
    else:
        pass  # 重复,丢弃
```

替代方案:

- Redis BloomFilter(`pip install redis[bloom]` 或 RedisBloom 模块):空间小、概率型。
- 直接用 MongoDB 唯一索引 + `try/except DuplicateKeyError`。

## 8. 综合存储调用流程(以"去重 + MongoDB 入库"为例)

```
   ┌──────────────┐      ┌────────────────┐
   │  目标 API    │ ───▶ │  requests.get  │
   └──────────────┘      └────────┬───────┘
                                  │ json
                                  ▼
                         ┌─────────────────┐
                         │   parse_data    │ 字段提取
                         └────────┬────────┘
                                  │ item(dict)
                                  ▼
                       ┌─────────────────────┐
                       │  md5(item)          │ hashlib
                       └────────┬────────────┘
                                ▼
                  ┌─────────────────────────┐
                  │  SADD movie:filter md5  │ Redis
                  └──────┬───────────┬──────┘
                返回 1   │           │   返回 0
                        ▼           ▼
              col.insert_one(item)  跳过(重复)
                        │
                        ▼
                    MongoDB
```

## 9. 原文需要纠正/补充的点

| # | 原文 | 问题 | 正确做法 |
|---|------|------|---------|
| 1 | CSV 示例 `open('test_1.csv', 'w')` 没有 `encoding` 与 `newline=''` | Windows 上会出现:中文乱码 + 每条记录之间多空行 | `open(..., 'w', encoding='utf-8-sig', newline='')` |
| 2 | `from dbutils.pooled_db import PooledDB` 但 pip 安装是 `DBUtils` | 大小写不一致易迷惑 | 包名 `DBUtils`(老)/ `dbutils`(新, 1.x 之后)。导入永远小写 |
| 3 | MySQL `connect(..., charset='utf8')` | utf8 ≠ 真正的 UTF-8 | 用 **`utf8mb4`** |
| 4 | `insert` SQL 通过字符串拼参数(原文用 `%s` 占位符,这点对);但例子中 `tx_work` 的 id 由 Python 维护 `work_id += 0` 没有 +1 | 主键不递增,首条之后将报主键冲突 | 应该 `work_id += 1` 或省略让 `auto_increment` 自动生成 |
| 5 | `cls.url.format(page)` 但 `cls.url` 里没有 `{}` 占位符 | 报 `IndexError` 或 silently 不替换 | URL 模板中应预留 `pageIndex={}`;或改用 `params={}` 参数字典 |
| 6 | `db.close()` 在 main 末尾;若异常会跳过 | 资源泄漏 | 用 `try/finally` 或上下文管理器(pymysql 支持 `with`) |
| 7 | MongoDB 文档"指定数据库与表" `client['students']` 直接当作集合 | 实际 `client['students']` 是数据库,集合应是 `client['db']['col']` | 见后文 5.5 案例已正确写法,但前面案例描述有误 |
| 8 | "哈希值是唯一的"(5.6) | 不严谨,MD5 存在碰撞风险 | 实践中作为指纹够用,但安全场景不能这样描述;严谨用 SHA-256 或唯一索引 |
| 9 | `redis.Redis()` 默认 `decode_responses=False`,返回 bytes | 与 print/str 比较时可能不直观 | 加 `decode_responses=True` 拿到 str |
| 10 | 5.5 案例中 `MongoClient(host=, port=)` 然后 `client['students']` 当 collection | 应该是 db,代码后面已经修正为 `client['students']['stu_info']` | 上下文略乱,统一推荐写法 `client['db']['col']` |

## 10. 速记

- 文本表格 → CSV(`newline=''` + `utf-8-sig`)。
- 结构化对象 → JSON(`ensure_ascii=False`)。
- 关系型查询 → MySQL(`%s` 占位 + `commit`/`rollback` + 连接池)。
- 嵌套文档/字段不固定 → MongoDB(集合无 schema)。
- 去重 → Redis `SADD`,或 Bloom Filter,或唯一索引。
- 字符集统一用 `utf8mb4`。
